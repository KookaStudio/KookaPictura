# The Window menu

The Window menu arranges documents, chooses a workspace and opens or closes
panels. See [Showing and hiding panels](panels-menu.md) for the panel list.

## Arrange

**Arrange** changes how document windows are laid out.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Cascade | `—` | Stacks the document windows. | [Guide](panels-menu.md) |
| Tile | `—` | Tiles the document windows. | [Guide](panels-menu.md) |
| Consolidate All to Tabs | `—` | Puts every floating document back into tabs. | [Guide](panels-menu.md) |
| Float in Window | `—` | Floats the active document in its own window. | [Guide](panels-menu.md) |
| Float All in Windows | `—` | Floats every document in its own window. | [Guide](panels-menu.md) |
| Match Zoom | `—` | Gives every document the active document's zoom. | [Guide](panels-menu.md) |
| Match Location | `—` | Gives every document the active document's view position. | [Guide](panels-menu.md) |
| Match All | `—` | Matches zoom and position in every document. | [Guide](panels-menu.md) |
| New Window For [file] | `—` | Opens a second window on the same document. | [Guide](panels-menu.md) |

## Workspace

**Workspace** switches between saved panel layouts. The four built-in
workspaces are Essentials, Painting, Photography and Typography.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Essentials | `—` | Switches to the Essentials workspace. | [Guide](panels-menu.md) |
| Painting | `—` | Switches to the Painting workspace. | [Guide](panels-menu.md) |
| Photography | `—` | Switches to the Photography workspace. | [Guide](panels-menu.md) |
| Typography | `—` | Switches to the Typography workspace. | [Guide](panels-menu.md) |
| New Workspace… | `—` | Saves the current layout as a workspace. | [Guide](panels-menu.md) |
| Delete Workspace… | `—` | Deletes a saved workspace. | [Guide](panels-menu.md) |
| Reset [Workspace] | `—` | Restores the current workspace's saved layout. | [Guide](panels-menu.md) |
| Keyboard Shortcuts & Menus… | `—` | Opens the shortcut and menu editor. | [Guide](panels-menu.md) |

## Window commands

The bottom of the Window menu holds the Options command and the UI size
controls. The menu also lists the open documents below them, so you can switch
to one directly.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Options | `—` | Shows or hides the Options bar. | [Guide](panels-menu.md) |
| UI Size: 100% | `—` | Shows the current UI size. | [Guide](panels-menu.md) |
| Enlarge UI Size | `Ctrl+Alt++` | Makes the interface larger. | [Guide](panels-menu.md) |
| Decrease UI Size | `Ctrl+Alt+-` | Makes the interface smaller. | [Guide](panels-menu.md) |
| Reset UI Size | `Ctrl+Alt+0` | Returns the interface to 100%. | [Guide](panels-menu.md) |
