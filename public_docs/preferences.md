# Preferences

**Edit ▸ Preferences** opens the settings dialog. Each page is listed on the
left; click a name to show it. A greyed name is a CS6 page that is listed but
not available yet. The Performance page is described in full at
[Performance settings](performance.md); the Agent Control page at
[Working with AI agents](agent-control.md).

Changes are saved as you make them. Most take effect at once; a language change
asks you to restart Pictura.

## General

- **Brightness** and **Theme** set the interface's lightness and its Dark or
  Light family.
- **Zoom Resizes Windows** makes a floating document window grow and shrink with
  the zoom.
- **Color Picker** chooses the built-in Adobe-style picker or the system picker.
- **History Log** writes a text log of the edits. The destination, detail and
  path are chosen here.
- **Settings** holds **Export Settings…**, **Import Settings…** and **Reset
  Preset Lists…**. See [Backing up and restoring settings](settings-backup.md).

## Interface

- **Use Shift Key For Tool Switch** makes the tool shortcuts require Shift.
- **Auto-Collapse Iconic Panels**, **Auto-Show Hidden Panels**, **Open
  Documents As Tabs** and **Enable Floating Document Window Docking** control
  how panels and document windows behave.
- **UI Size** scales the whole interface.
- **Language** chooses the interface language; **Import Translation…** loads a
  Qt translation file and **Restart Pictura** applies a pending language.

## File Handling

Not yet available. It is the CS6 page for background saving, recovery autosave,
PSD/PSB compatibility and Camera Raw sidecar settings.

## Performance

The memory limit, History States, Cache Levels, scratch disks and the graphics
processor. Every change applies at once with no restart, which differs from
Photoshop; Cache Levels defaults to 8, also different from Photoshop. See
[Performance settings](performance.md) for the full description.

## Cursors

Not yet available.

## Transparency & Gamut

Not yet available.

## Units & Rulers

- **Rulers** chooses the unit for rulers, grids and the Measure tool.
- **Point/Pica Size** chooses PostScript (72 points per inch) or Traditional
  (72.27).
- **Type**, **Column Size** and **New Document Preset Resolutions** show CS6's
  defaults and are disabled until Pictura reads them.

## Guides, Grid, & Slices

- **Guides** sets the guide colour and whether guides are lines or dashed
  lines.
- **Grid** sets the grid colour, style, spacing and subdivisions.
- **Smart Guides** and **Slices** show their defaults and are disabled for now.

## Plug-ins

Not yet available.

## Type

- **Show Asian Text Options**, **Middle Eastern**, **Enable Missing Glyph
  Protection** and **Fill New Type Layers With Placeholder Text** control the
  text tools. See [Text and the Typography workspace](text-and-typography.md).

## 3D

Not yet available.

## Agent Control

The permissions and limits for AI agents. See
[Working with AI agents](agent-control.md).

## Updates

Whether Pictura checks for updates automatically, the running version, and the
manual **Check for Updates…** control.

## Preference commands

Each page above is also a command in **Edit ▸ Preferences**.

| Command | Shortcut | What it does |
|---|---|---|
| General | `Ctrl+K` | Opens Preferences on the General page. |
| Interface | `—` | Opens Preferences on the Interface page. |
| File Handling | `—` | Not yet available. |
| Performance | `—` | Opens Preferences on the Performance page. |
| Cursors | `—` | Not yet available. |
| Transparency & Gamut | `—` | Not yet available. |
| Units & Rulers | `—` | Opens Preferences on the Units & Rulers page. |
| Guides, Grid, & Slices | `—` | Opens Preferences on the Guides, Grid, & Slices page. |
| Plug-ins | `—` | Not yet available. |
| Type | `—` | Opens Preferences on the Type page. |
| Agent Control | `—` | Opens Preferences on the Agent Control page. |
| 3D | `—` | Not yet available. |
