# The Select menu

The Select menu creates and edits selections. See
[Selections and masking](selections-and-masking.md) for the full workflow.
Quick Mask Mode is on the **View** menu.

## Selection commands

Selection commands: select all or part of the picture, change an existing
selection, and save or load it.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| All | `Ctrl+A` | Selects the whole canvas. | [Guide](selections-and-masking.md) |
| Deselect | `Ctrl+D` | Removes the selection. | [Guide](selections-and-masking.md) |
| Reselect | `Shift+Ctrl+D` | Restores the last deselected selection. | [Guide](selections-and-masking.md) |
| Inverse | `Shift+Ctrl+I` | Selects everything that is not selected. | [Guide](selections-and-masking.md) |
| All Layers | `Ctrl+Alt+A` | Selects every layer. | [Guide](selections-and-masking.md) |
| Deselect Layers | `—` | Deselects the layers. | [Guide](selections-and-masking.md) |
| Similar Layers | `—` | Selects layers similar to the active one. | [Guide](selections-and-masking.md) |
| Color Range… | `—` | Selects pixels by colour, sampled colours or a saved range. | [Guide](selections-and-masking.md) |
| Refine Edge… | `Ctrl+Alt+R` | Refines the selection edge with a preview. | [Guide](selections-and-masking.md) |
| Grow | `—` | Grows the selection to include similar nearby colours. | [Guide](selections-and-masking.md) |
| Similar | `—` | Adds similar colours to the selection. | [Guide](selections-and-masking.md) |
| Transform Selection | `—` | Transforms the selection outline. | [Guide](selections-and-masking.md) |
| Save Selection… | `—` | Saves the selection as a channel. | [Guide](selections-and-masking.md) |
| Load Selection… | `—` | Loads a saved selection channel. | [Guide](selections-and-masking.md) |

## Modify

**Modify** changes the shape of an existing selection: its border, smoothness,
size or feather.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Border… | `—` | Selects a border inside the selection edge. | [Guide](selections-and-masking.md) |
| Smooth… | `—` | Smooths the selection corners. | [Guide](selections-and-masking.md) |
| Expand… | `—` | Grows the selection. | [Guide](selections-and-masking.md) |
| Contract… | `—` | Shrinks the selection. | [Guide](selections-and-masking.md) |
| Feather… | `Shift+F6` | Softens the selection edge. | [Guide](selections-and-masking.md) |
