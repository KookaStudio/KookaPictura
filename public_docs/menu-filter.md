# The Filter menu

The Filter menu changes how a layer looks. Filters apply to the active layer or,
when a selection is active, to the selected pixels. Most dialogs preview on the
canvas; see [Filters](filters.md) for the family pages.

## Top of the Filter menu

The top of the Filter menu holds the larger tools and the repeat commands.
The families below it are listed with their commands.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Last Filter | `Ctrl+F` | Repeats the last filter with the same settings. | [Guide](filters.md) |
| Last Filter Settings… | `Ctrl+Alt+F` | Repeats the last filter and opens its dialog. | [Guide](filters.md) |
| Convert for Smart Filters | `—` | Converts the layer to a smart object so the filters stay editable. | [Guide](filters.md) |
| Filter Gallery… | `—` | Stacks several artistic filters in one dialog. | [Guide](filters.md) |
| Adaptive Wide Angle… | `—` | Straightens a wide-angle photo by drawing constraints. | [Guide](filter-adaptive-wide-angle.md) |
| Pictura Raw… | `—` | Develops a raw file's exposure, colour and detail. | [Guide](pictura-raw.md) |
| Lens Correction… | `Shift+Ctrl+R` | Corrects lens distortion, vignetting and perspective. | [Guide](filter-lens-correction.md) |
| Liquify… | `Shift+Ctrl+X` | Pushes and pulls pixels as if the picture were liquid. | [Guide](liquify.md) |
| Oil Paint… | `—` | Gives the picture a painted oil look. | [Guide](filter-oil-paint.md) |
| Vanishing Point… | `Alt+Ctrl+V` | Edits in perspective using a vanishing-point plane. | [Guide](filter-vanishing-point.md) |
