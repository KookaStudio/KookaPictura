# The Help menu

The Help menu opens the search, update, system-information and about
commands, plus the developer tools.

## Help commands

Search, updates, system information and the about commands.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Search… | `Shift+Space` | Opens the command, tool, panel and preference search. |  |
| Check for Updates… | `—` | Checks for a newer release. |  |
| System Info | `—` | Shows the system and build information. |  |
| Submit Issue | `—` | Opens the issue tracker. |  |
| About Kooka Pictura | `—` | Shows the version and licence. |  |

## Developer

**Developer** opens tools for developing Pictura itself.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Design System... | `—` | Opens the design-system reference (developer tool). |  |
| Pictura Metrics | `—` | Opens the Pictura Metrics tool window (developer tool). |  |

## Not yet available
