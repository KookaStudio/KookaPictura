# The File menu

The File menu opens, saves and exports documents. The commands at the top work on the
current document; the submenus gather imports, exports, automation and scripts.

## New, open, save and close

These commands create and open documents, save them, and close them. The
shortcut is shown beside each command; **Open Recent** fills in as you open
files.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| New… | `Ctrl+N` | Creates a new document; the New dialog sets its size, mode and background. | [Guide](opening-files.md) |
| Open... | `Ctrl+O` | Opens a document from disk. | [Guide](opening-files.md) |
| Browse… | `Ctrl+Alt+O` | Opens the file browser instead of the plain Open dialog. |  |
| Open As… | `Ctrl+Alt+Shift+O` | Opens a file with a chosen format when the extension is misleading. | [Guide](opening-files.md) |
| Open As Smart Object… | `—` | Opens the file as a smart object in a new document. | [Guide](opening-files.md) |
| Close | `Ctrl+W` | Closes the active document and asks about unsaved changes. |  |
| Close All | `Ctrl+Alt+W` | Closes every open document. |  |
| Save | `Ctrl+S` | Saves the document in its current format. | [Guide](opening-files.md) |
| Save As… | `Shift+Ctrl+S` | Saves the document under a new name or format. | [Guide](opening-files.md) |
| Save a Copy… | `—` | Saves a copy and keeps the current document and its path. | [Guide](opening-files.md) |
| Export As… | `—` | Exports a flattened copy as PNG, JPEG, TIFF, WebP or another format. | [Guide](opening-files.md) |
| Quick Export as PNG | `—` | Exports a PNG with the last-used settings, without a dialog. | [Guide](opening-files.md) |
| Save for Web & Devices… | `Ctrl+Alt+Shift+S` | Opens the Save for Web dialog for a compressed web image. | [Guide](opening-files.md) |
| Revert… | `F12` | Reloads the document from disk and discards unsaved changes. |  |
| Place… | `—` | Places another image as a smart object in the current document. |  |
| File Info… | `Ctrl+Alt+Shift+I` | Edits the document's title, author and other metadata. |  |
| Print… | `Ctrl+P` | Prints the document. |  |
| Print One Copy | `Ctrl+Alt+Shift+P` | Prints one copy with the last-used settings. |  |
| Exit | `Ctrl+Q` | Quits Kooka Pictura and asks about unsaved documents. |  |

## Import

**Import** brings data into the current document. Variable data sets read a
list of values for a template; WIA Support is a Windows scanner import that is
not available yet.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Variable Data Sets | `—` | Loads a data-set list for a template. | [Guide](opening-files.md) |

## Export

**Export** writes a copy in another form. **Export As** and **Quick Export as
PNG** are also on the top level; the submenu adds data sets, Zoomify and paths.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Data Sets As Files… | `—` | Writes one file for each data set. | [Guide](opening-files.md) |
| Zoomify… | `—` | Exports a zoomable image for the web. |  |
| Paths to Illustrator… | `—` | Writes the document's paths as an Illustrator file. |  |

## Automate

**Automate** runs a task over several files. Batch is the implemented one; the
other CS6 automation commands are listed as not yet available.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Batch… | `—` | Runs an action over a folder of files. |  |

## Scripts

**Scripts** run built-in tasks over the open documents or their layers.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Export Layers to Files… | `—` | Writes each layer to its own file. |  |
| Layer Comps to Files | `—` | Writes each layer comp to its own file. |  |
| Layer Comps to PDF | `—` | Writes the layer comps to a PDF. |  |
| Load Files into Stack… | `—` | Opens several files as one layered document. |  |
| Statistics… | `—` | Combines several images with a statistics stack mode. (Extended edition) |  |
