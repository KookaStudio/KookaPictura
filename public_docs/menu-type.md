# The Type menu

The Type menu controls text layers: their panels, anti-aliasing, orientation,
OpenType features, conversion and default styles. See
[Text and the Typography workspace](text-and-typography.md) for the full
workflow.

## Panels

**Panels** opens the text-related panels. See
[Text and the Typography workspace](text-and-typography.md).

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Character | `—` | Opens the Character panel. | [Guide](text-and-typography.md) |
| Paragraph | `—` | Opens the Paragraph panel. | [Guide](text-and-typography.md) |
| Character Styles | `—` | Opens the Character Styles panel. | [Guide](text-and-typography.md) |
| Paragraph Styles | `—` | Opens the Paragraph Styles panel. | [Guide](text-and-typography.md) |
| Glyphs | `—` | Opens the Glyphs panel. | [Guide](text-and-typography.md) |

## Anti-Alias

**Anti-Alias** sets how the selected text's edges are smoothed.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| None | `—` | Sets the selected text's anti-aliasing to None. | [Guide](text-and-typography.md) |
| Sharp | `—` | Sets the selected text's anti-aliasing to Sharp. | [Guide](text-and-typography.md) |
| Crisp | `—` | Sets the selected text's anti-aliasing to Crisp. | [Guide](text-and-typography.md) |
| Strong | `—` | Sets the selected text's anti-aliasing to Strong. | [Guide](text-and-typography.md) |
| Smooth | `—` | Sets the selected text's anti-aliasing to Smooth. | [Guide](text-and-typography.md) |

## Orientation

**Orientation** sets the text to run horizontally or vertically.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Horizontal | `—` | Sets the selected text to Horizontal. | [Guide](text-and-typography.md) |
| Vertical | `—` | Sets the selected text to Vertical. | [Guide](text-and-typography.md) |

## OpenType

**OpenType** turns the font's optional features on or off for the selected
text. A feature is only available when the font has it.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Standard Ligatures | `—` | Turns Standard Ligatures on or off for the selected text. | [Guide](text-and-typography.md) |
| Contextual Alternates | `—` | Turns Contextual Alternates on or off for the selected text. | [Guide](text-and-typography.md) |
| Discretionary Ligatures | `—` | Turns Discretionary Ligatures on or off for the selected text. | [Guide](text-and-typography.md) |
| Swash | `—` | Turns Swash on or off for the selected text. | [Guide](text-and-typography.md) |
| Oldstyle | `—` | Turns Oldstyle on or off for the selected text. | [Guide](text-and-typography.md) |
| Stylistic Alternates | `—` | Turns Stylistic Alternates on or off for the selected text. | [Guide](text-and-typography.md) |
| Titling Alternates | `—` | Turns Titling Alternates on or off for the selected text. | [Guide](text-and-typography.md) |
| Ornaments | `—` | Turns Ornaments on or off for the selected text. | [Guide](text-and-typography.md) |
| Ordinals | `—` | Turns Ordinals on or off for the selected text. | [Guide](text-and-typography.md) |
| Fractions | `—` | Turns Fractions on or off for the selected text. | [Guide](text-and-typography.md) |

## Type commands

Type-layer commands: conversion, warping, paths and shapes, and the default
type styles.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Convert To Point Text | `—` | Converts the text layer to point text. | [Guide](text-and-typography.md) |
| Convert To Paragraph Text | `—` | Converts the text layer to paragraph text. | [Guide](text-and-typography.md) |
| Warp Text… | `—` | Warps the text along a shape. | [Guide](text-and-typography.md) |
| Rasterize Type Layer | `—` | Converts the text layer to pixels. | [Guide](text-and-typography.md) |
| Create Work Path | `—` | Creates a work path from the text outline. | [Guide](text-and-typography.md) |
| Convert to Shape | `—` | Converts the text to a shape layer. | [Guide](text-and-typography.md) |
| Update All Text Layers | `—` | Updates every text layer after a font or style change. | [Guide](text-and-typography.md) |
| Replace All Missing Fonts | `—` | Replaces fonts that are not installed. | [Guide](text-and-typography.md) |
| Paste Lorem Ipsum | `—` | Pastes placeholder text into a text layer. | [Guide](text-and-typography.md) |
| Load Default Type Styles | `—` | Loads the default type styles. | [Guide](text-and-typography.md) |
| Save Default Type Styles | `—` | Saves the current type styles as the default. | [Guide](text-and-typography.md) |

## Font Preview Size

**Font Preview Size** sets how large the font name preview is in the font
menus.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| None | `—` | Sets the font menu preview to None. | [Guide](text-and-typography.md) |
| Small | `—` | Sets the font menu preview to Small. | [Guide](text-and-typography.md) |
| Medium | `—` | Sets the font menu preview to Medium. | [Guide](text-and-typography.md) |
| Large | `—` | Sets the font menu preview to Large. | [Guide](text-and-typography.md) |
| Extra Large | `—` | Sets the font menu preview to Extra Large. | [Guide](text-and-typography.md) |
| Huge | `—` | Sets the font menu preview to Huge. | [Guide](text-and-typography.md) |

## Language Options

**Language Options** chooses the OpenType language features for the selected
text.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Default features | `—` | Uses Default features for the selected text. | [Guide](text-and-typography.md) |
| Middle Eastern features | `—` | Uses Middle Eastern features for the selected text. | [Guide](text-and-typography.md) |
| East Asian features | `—` | Uses East Asian features for the selected text. | [Guide](text-and-typography.md) |
