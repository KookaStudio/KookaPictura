# The Layer menu

The Layer menu creates, groups, masks, styles and merges layers. Most commands
work on the selected layers; a greyed command is not available for the current
selection or layer kind. Layer comps are managed in the Layer Comps panel
(**Window ▸ Panels ▸ Layer Comps**).

## New

**New** adds a layer, group or background. A group keeps related layers
together; a layer via copy or cut takes the selected pixels with it.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Layer | `Shift+Ctrl+N` | Adds an empty pixel layer. | [Guide](layers.md) |
| Layer from Background… | `—` | Converts the Background layer to an ordinary layer. | [Guide](layers.md) |
| Group… | `—` | Adds an empty layer group. | [Guide](layers.md) |
| Group from Layers… | `—` | Puts the selected layers into a new group. | [Guide](layers.md) |
| Layer via Copy | `Ctrl+J` | Copies the selection to a new layer. | [Guide](layers.md) |
| Layer via Cut | `Shift+Ctrl+J` | Cuts the selection to a new layer. | [Guide](layers.md) |
| Background From Layer | `—` | Converts the selected layer to a Background layer. | [Guide](layers.md) |

## Layer commands

Layer-wide commands: duplicate, delete, content options and the commands that
act on the selected layers.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Duplicate Layer… | `—` | Duplicates the selected layer or group. |  |
| Delete Layer | `—` | Deletes the selected layer or group. |  |
| Delete Hidden Layers | `—` | Deletes every hidden layer. |  |
| Layer Content Options… | `—` | Edits the settings of a fill or adjustment layer. |  |
| Create Clipping Mask | `Ctrl+Alt+G` | Clips the layer to the layer below it. |  |
| Release Clipping Mask | `—` | Releases the clipping mask. |  |
| Copy Shape Attributes | `—` | Copies a shape's fill, stroke and style. |  |
| Paste Shape Attributes | `—` | Pastes the copied shape attributes. |  |
| Group Layers | `Ctrl+G` | Puts the selected layers into a group. |  |
| Ungroup Layers | `Shift+Ctrl+G` | Releases the selected groups. |  |
| Hide Layers | `—` | Hides the selected layers. |  |
| Select Similar Layers | `—` | Selects layers with a similar kind, name or style. |  |
| Link Layers | `—` | Links the selected layers so they move together. |  |
| Unlink Layers | `—` | Unlinks the selected layers. |  |
| Select Linked Layers | `—` | Selects every layer linked to the active one. |  |
| Lock All Layers In Group… | `—` | Locks every layer in the group. |  |

| Link | `—` | Links the mask to the layer so they move together. | [Guide](layer-masks.md) |
| Unlink | `—` | Unlinks the mask so it can move separately. | [Guide](layer-masks.md) |

| Edit Contents | `—` | Opens the smart object's source for editing. | [Guide](layers.md) |

## Smart Objects > Stack Mode

**Stack Mode** combines the frames of a smart-object stack. Each mode is a
statistic across the stack; None keeps the ordinary composite.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| None | `—` | Keeps the ordinary composite. (Extended edition) | [Guide](layers.md) |
| Entropy | `—` | Uses the entropy at each pixel. (Extended edition) | [Guide](layers.md) |
| Kurtosis | `—` | Uses the kurtosis at each pixel. (Extended edition) | [Guide](layers.md) |
| Maximum | `—` | Uses the brightest value at each pixel. (Extended edition) | [Guide](layers.md) |
| Mean | `—` | Uses the average value at each pixel. (Extended edition) | [Guide](layers.md) |
| Median | `—` | Uses the median value at each pixel. (Extended edition) | [Guide](layers.md) |
| Minimum | `—` | Uses the darkest value at each pixel. (Extended edition) | [Guide](layers.md) |
| Range | `—` | Uses the range between the darkest and brightest values. (Extended edition) | [Guide](layers.md) |
| Skewness | `—` | Uses the skewness at each pixel. (Extended edition) | [Guide](layers.md) |
| Standard Deviation | `—` | Uses the standard deviation at each pixel. (Extended edition) | [Guide](layers.md) |
| Summation | `—` | Adds the values at each pixel. (Extended edition) | [Guide](layers.md) |
| Variance | `—` | Uses the variance at each pixel. (Extended edition) | [Guide](layers.md) |

**Lock Layers** prevents a kind of change to the selected layers. A locked
pixel layer cannot be painted on; a locked position cannot be moved.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| All | `—` | Locks every property of the layer. | [Guide](layers.md) |
| Transparency | `—` | Locks transparent pixels so they cannot be painted. | [Guide](layers.md) |
| Image | `—` | Locks the pixels so they cannot be painted. | [Guide](layers.md) |
| Position | `—` | Locks the layer's position. | [Guide](layers.md) |

## Merge

**Merge** combines layers into one. Merging is permanent; keep a copy if you
may want the separate layers again.

| Command | Shortcut | What it does | More |
|---|---|---|---|
| Merge Layers | `Ctrl+E` | Merges the selected layers into one. | [Guide](layers.md) |
| Merge Visible | `Shift+Ctrl+E` | Merges the visible layers into one. | [Guide](layers.md) |
| Stamp Visible | `Ctrl+Alt+Shift+E` | Merges a copy of the visible layers into a new layer. | [Guide](layers.md) |
| Stamp Selected | `Ctrl+Alt+E` | Merges a copy of the selected layers into a new layer. | [Guide](layers.md) |
| Flatten Image | `—` | Flattens the document to one layer. | [Guide](layers.md) |
| Merge Clipping Mask | `—` | Merges the clipped layers into the base layer. | [Guide](layers.md) |

| Remove Black Matte | `—` | Removes a black fringe. | [Guide](layers.md) |
