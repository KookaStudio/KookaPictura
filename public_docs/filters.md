# Filters

Filters change how a layer looks. Kooka Pictura offers over a hundred, all in the
**Filter** menu.

## Applying a filter

1. Select the layer.
2. Optionally make a selection to limit the filter to part of the image.
3. Choose a filter from the **Filter** menu, adjust it in the dialog, and click OK.

Most dialogs show a live preview on the canvas. Zoomed far out, the preview is an
approximation, and it is exact at 100% and above.

## The Filter menu

![The Filter menu with the Blur submenu open](images/filter-blur-menu.png)

At the top are the larger tools: **Filter Gallery…**, **Pictura Raw…**,
**Lens Correction…** (`Ctrl+Shift+R`), **Liquify…** (`Ctrl+Shift+X`), **Oil Paint…**,
and **Last Filter** (`Ctrl+F`), which repeats the previous filter.

Below them are the filter families:

| Family | What it does |
|---|---|
| Artistic, Brush Strokes, Sketch, Texture | Painterly and drawn looks |
| Blur | Soften or smooth. See [Blur filters](filter-blur.md) |
| Blur Gallery | Field, Iris and Tilt-Shift blur. See [Blur Gallery](filter-blur-gallery.md) |
| Distort | Warp and bend the picture. See [Distort filters](filter-distort.md) |
| Noise | Add or reduce grain. See [Noise filters](filter-noise.md) |
| Pixelate | Mosaic, crystal and dot effects |
| Render | Create clouds, lighting and flares |
| Sharpen | Make detail crisper. See [Sharpen filters](filter-sharpen.md) |
| Stylize | Edge and relief effects |
| Video, Other | Specialist filters |

The **Filter Gallery** lets you stack several artistic filters at once. [Liquify](liquify.md)
pushes and pulls pixels, and [Oil Paint](filter-oil-paint.md) gives a painted look. **Pictura Raw** adjusts
exposure, colour and detail for a photo.

## Keep filters editable

Convert a layer to a smart object first. The filters then become **Smart
Filters** that stay editable: double-click one to change it, or hide it to
compare.
