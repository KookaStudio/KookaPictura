# Preset format evidence

The project generates its batch-test inputs from the layouts below. For the
independent CS6 check, create and export small examples locally through Edit >
Presets > Preset Manager, using original names and assets. Keep Adobe-generated
or third-party samples outside the repository.

| Format | Target layout and fixture recipe | Evidence |
|---|---|---|
| ACO | Big-endian v1 colors and optional v2 named table. Write two tables whose entries have the same CMYK, Lab, Gray and RGB components. V1-only files have no names. Quantization uses 16-bit RGB and CMYK, and 0.01 units for Gray and Lab. | [Adobe Color Swatches and Color Space IDs](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/) |
| ASE | `ASEF` 1.0. Generate length-delimited color blocks using RGB, CMYK, Lab and Gray floats, with a Unicode name and entry type. Adobe Lab lightness is scaled by 100 when read. Group wrappers delimit names in the source file and are flattened into the ordered Swatches list. | [Krita palette reader](https://invent.kde.org/graphics/krita/-/blob/master/libs/pigment/resources/KoColorSet.cpp), [GIMP palette format references](https://developer.gimp.org/core/standards/) |
| SHC | `8BFS` v1 container with v1 and v2 records. Generate an asymmetric curve with 0–255 coordinates, a corner flag in the v2 record, and an input range. | [Adobe Contours](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/) |
| CSH | `cush` v2, one named record with a Pascal ID, four signed bounds and standard 26-byte path records. Generate a closed path with at least one linked Bézier knot and unequal width and height. | [Michel Mariani's Custom Shapes layout](https://tonton-pixel.codeberg.page/photoshop-file-formats/custom-shapes-file-format.html) |
| GRD | `8BGR` v5 with a version-16 descriptor and a `GrdL` list. Generate a solid gradient with foreground/background stop references, a non-default color midpoint, and two opacity stops. | [Michel Mariani's Gradients layout](https://github.com/Investigamer/json-photoshop-scripting/blob/master/Documentation/Photoshop-Gradients-File-Format/README.md) |
| ASL | Version 2, `8BSL`, pattern subversion 3 and version-16 style descriptors. Generate a named style with a non-default drop shadow and optionally a referenced RGB pattern. | [Michel Mariani's Styles layout](https://tonton-pixel.codeberg.page/photoshop-file-formats/styles-file-format.html) |
| PAT | `8BPT` v1 with unframed RGB and Grayscale pattern records. Generate a small asymmetric tile with known component values and a unique ID, preserving its name. Version-3 virtual memory lists bound the records. | [Adobe PSD Pattern records](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/), [PatKit standalone layout](https://github.com/focale-editor/patkit/blob/main/docs/PAT.md) |
| ABR | 10.1 with `8BIM` `samp` and `desc` sections. Generate a raw 8-bit coverage mask and a descriptor pointing to it by ID. Use a name and diameter distinguishable from defaults. | [AbrKit ABR wire notes](https://github.com/focale-editor/abrkit/blob/main/docs/ABR.md) |
| TPL | `8BTP` v3, counted `8BIM` sections, count and Unicode name plus a version-16 Action Descriptor per tool in `tptp`. Generate a named Brush entry with different opacity and flow values. Embedded resources are reported separately. | [Public TPL sample from TPLParserJS](https://github.com/DavyJonesCodes/TPLParserJS/blob/main/sample.tpl) |
| CSF | `AsCs` version 2 with an ICC-style tag directory at offset 128. `prof` records carry embedded working profiles. `ui32` records carry Convert policy (`conv`), intent, black-point compensation and dither. Other tags and unknown policies round-trip as opaque records and are reported. Generate the envelope and tags independently and compare against a locally authored CS6 save with changed profile, policy, intent, black-point compensation and dither. | [Adobe CS6 Printing Guide](https://helpx.adobe.com/content/dam/help/en/indesign/pdf/CS6_PrintGuide.pdf), [public color-settings samples](https://www.screenprinting.com/pages/four-color-process-color-profiles) |
