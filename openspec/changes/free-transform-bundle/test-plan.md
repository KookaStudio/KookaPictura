# Test Plan

One row per spec scenario in this change. Coverage names the automated test
that proves the scenario, or `manual:` with the reason it cannot be automated.
Tests that do not exist yet are created by the tasks named in `tasks.md`.

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `distort_shortcut` | Begin a Free session on a raster layer; press a corner with Ctrl and drag by a two-axis delta | The corner moves by the delta, the other corners stay put, and the box's opposite edges are no longer parallel | `tst_transform_distort::ctrlCornerDistorts` |
| `distort_shortcut_commit` | Continue the Ctrl corner drag, release, and commit | The committed corner is at the dragged position and exactly one `Free Transform` state is added | `tst_transform_distort::ctrlCornerDistorts` |
| `skew_shortcut` | Begin a Free session; press a side handle with Ctrl+Shift and drag diagonally | The edge's endpoints move only along the edge's axis and the opposite edge stays put | `tst_transform_skew::ctrlShiftSideSkews` |
| `distort_shortcut_scale` | After a Ctrl corner drag, release and drag an edge handle without modifiers | The opposite edge stays fixed and the box keeps its non-parallel edges | `tst_transform_distort::plainDragScalesTheDistortedBox` |
| `distort_shortcut_type` | Begin a Free session on editable type; Ctrl-drag a corner | The drag scales the box and the box keeps its parallel edges | `tst_transform_distort::ctrlCornerOnTypeScales` |
| `skew_shortcut_type` | Begin a Free session on editable type; Ctrl+Shift-drag a side handle, then commit | The quad stays a parallelogram, the layer stays type, and one `Free Transform` state is added | `tst_transform_skew::ctrlShiftSideKeepsType` |
| The pivot starts at the source centre | Begin Free Transform on a layer whose content box is known | The pivot is the content box centre and the show flag is on | `tst_transform_options::fieldsSeedFromTheSession`, `tst_transform_options::pivotLocatorMovesTheReferencePoint` |
| A preset anchors on the live quad | Scale and rotate the box, then apply the top-left preset | The pivot equals the live quad's top-left corner | `tst_transform_options::pivotPresetUsesTheLiveQuad` |
| Moving the pivot leaves the image in place | Move the pivot to a new document position mid-session | The quad and the committed result equal the same session with the old pivot | `tst_transform_options::pivotLocatorMovesTheReferencePoint`, `tst_transform_options::pivotSetterUsesDocumentPosition` |
| `pivot_setter_document_position` | Translate and scale the box, then set the pivot to a document position | The marker is at that position, the stored source point is its inverse, and the quad is unchanged | `tst_transform_options::pivotSetterUsesDocumentPosition`, `pictura-app::pivot_setter_keeps_the_quad_and_moves_the_marker` |
| Rotating about a moved pivot keeps it fixed | Move the pivot, apply a rotation by the angle field and by a rotate-band drag | The pixel at the pivot's image position is unchanged and the marker stays at the rotation centre | `tst_transform_options::pivotStaysDuringRotation` |
| Relative X/Y is an offset from the origin | Turn relative positioning on and set X to 10 | The pivot's x equals the session origin's x plus 10 | `tst_transform_options::relativePositioningOffsetsFromTheOrigin` |
| Link applies one factor to both axes | Set W to 150 with the link on | Both the horizontal and vertical scale are 1.5 | `tst_transform_options::widthLinkScalesBothAxes` |
| H skew shears the layer | Set H to 30° and commit | The layer's vertical edges deviate 30° from vertical and one `Free Transform` state is recorded | `tst_transform_options::angleAndSkewSettersReachTheSession`, `pictura-app::h_shear_moves_the_left_edge` |
| `distort_pivot_carry` | Drag a Distort corner | The reference point moves with the box and keeps its position within it | `tst_transform_distort::pivotFollowsTheCorner`, `pictura-app::distort_carries_the_reference_point` |
| `perspective_pivot_carry` | Spread one edge of a Perspective box whose pivot is centred | The pivot stays at the average of the quad's corners | `tst_transform_perspective::pivotStaysAtTheCornerAverage` |
| `pivot_follows_move_and_scale` | Move the box, then scale it with a handle away from the pivot | The pivot keeps its source-frame place and its document position follows the box | `tst_transform_options::pivotFollowsMoveAndScale` |
| `pivot_follows_base_scale` | Give a Free session a projective base, then scale the box with a handle | The pivot moves with the box's projective map and keeps its relative place | `pictura-app::scale_base_carries_the_pivot` |
| `pivot_stays_during_rotation` | Rotate the box by dragging the rotate band | The pivot's document position is unchanged and remains the rotation centre | `tst_transform_options::pivotStaysDuringRotation` |
| `tsw_commit` | Drag the top-left warp anchor up and left, then Apply | The layer's rect starts at the dragged corner and one `Free Transform` state is added | `tst_transform_warp::anchorDragCommitsOneState` |
| `tsw_identity` | Enter Warp mode and commit without an edit | The history count is unchanged | `tst_transform_warp::identityWarpCommitsNothing` |
| `tsw_escape` | Pick a warp preset and press Escape | The document equals its pre-session value, the canvas holds no transform preview or grid, and the history count is unchanged | `tst_transform_warp::escapeRestoresAWarpedSession` |
| `tsw_cancel_overlay` | Pick a warp preset and click Cancel | The session ends, the canvas holds no transform preview or grid, the document equals its pre-session value, and no history state is added | `tst_transform_warp::cancelWarpLeavesNoOverlay` |
| `tsw_undo_live` | Begin a transform, edit it, and invoke Edit > Undo | The session ends, the canvas shows no transform preview, box, or grid, and the history moves back one state | `tst_transform_commands::undoCancelsAndClearsTheTransform` |
| `tsw_commit_retained` | Edit a warp, leave Warp, scale the box, and commit | The layer shows the warp and the scale and one `Free Transform` state is added | `tst_transform_warp::boxScaleCommitsWithTheWarp` |
| `tsw_menu` | Invoke `Edit > Transform > Warp` on a transformable layer | Warp mode is open with the `custom` style and the canvas shows four boundaries, four guides, and twelve points | `tst_transform_warp::menuOpensWarpMode` |
| `tsw_toggle` | Click the options-bar warp toggle twice | The first click enters Warp mode with the box unchanged, the second restores the box and its handles at the warped preview's bounds, and the warp stays in the session | `tst_transform_warp::toggleSwitchesBetweenBoxAndWarp` |
| `tsw_carry` | Rotate 30°, enter Warp mode, then leave it | The mesh's corners equal the rotated box's corners and leaving gives back the 30° box at the warped preview's bounds with the warp still applied | `tst_transform_warp::boxTransformCarriesIntoTheMesh` |
| `tsw_carry_projective` | Enter Warp on a perspective-box session | The grid's edges follow the box homography, interior points included, and the untouched preview shows the projective transform | `tst_transform_warp::perspectiveBoxWarpPreviews`, `pictura-app::the_grid_follows_a_perspective_box_exactly` |
| `tsw_release` | Drag a custom warp anchor and release it | The overlay holds no dragged handles after the release | `tst_transform_warp::releaseHidesTheDraggedHandles` |
| `tsw_retain` | Drag a custom warp anchor, leave Warp, and re-enter | The anchor is still displaced, the style is still `custom`, and the grid follows the same preview | `tst_transform_warp::reenteringWarpKeepsTheMesh` |
| `tsw_box_preview` | Leave Warp and drag a box handle | The preview shows the scaled warped layer, the canvas shows the box, not the warp grid, and the box stays on the preview bounds | `tst_transform_warp::boxDragKeepsTheWarpedPreview` |
| `tsw_box_numeric` | Leave Warp and set W to 200 | The preview width grows with the box, the canvas still shows the box, and the box stays on the preview bounds | `tst_transform_warp::numericBoxEditRefreshesTheWarpedPreview` |
| `tsw_box_exact` | Leave Warp and invoke Rotate 90° Clockwise | The preview rotates the warped layer with the box, the canvas still shows the box, and the box stays on the preview bounds | `tst_transform_warp::exactCommandRefreshesTheWarpedPreview` |
| `tsw_box_bounds` | Drag a custom warp anchor, leave Warp, and re-enter | The box equals the warped preview layer's document bounds, the preview pixels are unchanged, and re-entering Warp keeps the grid on the same preview | `tst_transform_warp::leavingWarpPutsTheBoxOnThePreviewBounds`, `pictura-app::a_post_frame_keeps_the_preview_quad_while_the_box_moves` |
| `tc_again` | Invoke Rotate 90° Clockwise, then Again | The layer is rotated 180° in total and the second state is `Transform Again` | `tst_transform_commands::againRepeatsTheLastTransform` |
| `tc_again_disabled` | Open a document with no committed transform | Again is disabled | `tst_transform_commands::againIsUnavailableBeforeATransform` |
| `tc_again_pivot` | Move the box, set the pivot at its moved top-left, commit, then invoke Again on the layer | The repeated transform keeps the pivot on the repeated box's top-left, with no extra shift from the carried pivot | `tst_transform_commands::againUsesTheSourcePivot`, `pictura-app::repeatable_transform_records_the_source_pivot` |
