# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `os_registry_stable` | Round-trip the frozen table through the Rust ABI representation and compare with literal values and keys | The ABI uses 32 bits and every published number and key is unique and stable | `pictura-error::operation_status_registry_is_stable` |
| `os_unknown_status` | Decode 106 and an unassigned nonzero value | Both retain their original number as unrecognized failures | `pictura-error::unknown_status_preserves_its_number` |
| `os_guard_results` | Invoke success, a typed error with a source, and an injected unwind through the Rust guard and exercise the panic case through an `extern "C"` test wrapper. Repeat success afterwards | Return the value for success and preserve the typed error source. The C-compatible return reports panic as 6 with no payload in its diagnostic. A following call succeeds | `pictura-error::guard_preserves_results_and_contains_panics` |
| `os_open_error_kinds` | Start two native opens with separate tokens. Hold one until the other is in flight. Use malformed PSD data and a valid path that fails on access after routing | The tokens complete once with codec and I/O respectively, each failure names the corresponding file, and both loading tabs disappear | `tst_loading_tab::nativeOpenReportsPerRequestErrorKinds` |
| `os_open_panic` | Keep a document active, inject a panic in the next native open worker, and await that open through the normal coordinator. Then open a valid PSD | The failed request completes once with panic status and safe feedback. Its tab disappears, the active tab stays intact and the cursor is restored. The next open succeeds | `tst_loading_tab::nativeOpenPanicCompletesAndAllowsRetry` |
| `os_open_cancel` | Hold a native open worker, close the loading tab, then release the worker to deliver a late panic result | One cancelled status is delivered, no failure appears, and the late result adds no tab or document | `tst_loading_tab::nativeOpenCancelDiscardsLateFailure` |
| `os_save_error_kinds` | Through the native save coordinator, inject a codec refusal and a stream write error before rename | Qt observes codec and I/O statuses respectively, both indicate pre-rename failure, and the original destination bytes remain | `tst_offthread_jobs::nativeSaveDistinguishesCodecAndIoErrors` |
| `os_save_panic_before_rename` | Save As to an existing destination and inject a panic after the temp file is created and writing begins | The result reports panic with pre-rename failure. The original file bytes, path, dirty state and recovery data match the baseline, and no temp file remains | `tst_offthread_jobs::nativeSavePanicBeforeRenameCleansUp` |
| `os_save_panic_after_rename` | Save a modified native document and inject a panic in the sync stage after rename. Reopen the destination independently, try to close the live document, then durably save it again | The result reports panic with uncertain publication. The destination holds the staged revision, while the live document retains its path, prompts on close and retains or creates recovery. The durable retry resolves the protection obligation | `tst_offthread_jobs::nativeSavePanicAfterRenameProtectsDocument` |
| `os_document_panic` | Dispatch Rotate on small and large fixtures, injecting a panic after a staged mutation. Record the visible pixels, geometry, history and dirty state first. Retry each fixture with a normal Rotate | Both failed actions return panic status, clear busy state and preserve the baseline. Each retry succeeds with one history state | `tst_document_jobs::rotationPanicLeavesDocumentAndHistoryIntact` |
| `os_document_refused` | Complete a valid shared command and then submit genuinely invalid arguments through a command preflight that runs before the shared helper | Qt receives invalid argument, no earlier result is visible, and document and history match the state after the first operation | `tst_document_jobs::validationRefusalClearsPreviousResult` |
| `os_document_cancel` | Start Flatten on a multi-layer document, hold its worker and cancel through the progress window | Qt receives cancelled status without failure feedback or a committed result. Pixel data, dirty state and history are unchanged | `tst_document_jobs::cancellingAFlattenChangesNothing` |
| `os_filter_panic` | Create undo and redo states plus a named snapshot. Inject a panic after filter history capture has begun, then exercise a separate adjustment engine panic. Inspect and use the saved history before a subsequent successful commit | Each attempt reports panic, restores the pre-preview display, retains the clean or dirty baseline and all history including the named snapshot. The next ordinary commit adds one state | `tst_offthread_jobs::filterAndAdjustmentPanicsPreserveUndo` |
| `os_filter_refused` | Apply a filter successfully, lock the target layer, and attempt another filter commit | Qt gets invalid argument and the layer-lock reason, busy state clears, and the attempted filter leaves the document, dirty flag and history as they were | `tst_offthread_jobs::lockedLayerReportsFilterRefusal` |
| `os_open_memory_concurrent` | Hold a memory-refused ControlServer native Open while an independent application or GUI open fails or is cancelled; exercise parked and synchronous completion adapters separately, using an adapter-level seam for synchronous completion if the wire parks, and await their request completions | Each response retains its own existing protocol code and status; cancellation wins over a late result | `tst_control_limits::nativeOpenMemoryRefusalIsPerRequest` |
| `os_save_replaced_panic` | Hold a native save after rename, inject a sync panic, replace its originating session through the generation test seam, then finish | Original attempt reports panic and uncertain publication; replacement path, dirty state, history and recovery remain unchanged | `pictura-app::native_save_replaced_session_panic` |
| `os_document_stale` | Hold an ordinary whole-document worker and make a newer edit; repeat with replacement before finishing | The old attempt is cancelled without failure feedback, and neither newer state nor newer status is overwritten | `tst_document_jobs::staleOrdinaryWorkerDoesNotPublish` |
| `os_adjustment_dialog_failure` | Open an adjustment dialog, inject a worker panic, and activate its real OK button | Operation-specific panic feedback excludes the payload and the original document and history remain intact | `tst_offthread_jobs::adjustmentDialogOkReportsPanic` |
| `os_copy_panic_after_rename` | Save a copy of a modified native document, inject a panic in directory sync after rename, and inspect the destination and source session | Panic with uncertain publication and copy-specific feedback; staged copy is present and source path, dirty state, history and recovery are unchanged | `tst_offthread_jobs::nativeSaveCopyPanicAfterRename` |
| `copy-nonmutating-raster` | Save a modified `a.psd` document as a copy to `b.png` | `b.png` holds the flattened composite; `a.psd` stays recorded, modified, and with the same history | `tst_save_gif_copy::saveCopyRasterLeavesDocument`, `pictura-app::copy_intent_skips_path_and_dirty` |
| `copy-psd` | Save a copy to `backup.psd` and reopen it | The copy is a layered PSD; the open document keeps its path and format | `tst_save_gif_copy::saveCopyPsdLeavesDocument` |
| `copy-pdf` | Save a copy to `print.pdf` through the PDF dialog driver | The PDF is written; the document keeps its path, format, and dirty state | `tst_save_gif_copy::saveCopyPdfLeavesDocument` |
| `copy-untitled` | Run Save a Copy on an untitled document through the save-path driver | The copy is written at the chosen path; the document stays untitled | `tst_save_gif_copy::saveCopyUntitledStaysUntitled` |
| `copy-gif` | Save an RGB document as a copy to `web.gif` | The file is GIF89a; the document keeps RGB mode, path, dirty state, and history | `tst_save_gif_copy::saveCopyGifLeavesRgb` |
| `copy-no-recorder` | Record an action and save a copy | The action gains no step | `tst_save_gif_copy::saveCopyNoRecorder` |
| `copy-failed` | Save a copy over an existing file with a failing write | Failure is reported; the old bytes and the document are unchanged; no partial file remains | `tst_save_gif_copy::saveCopyFailurePreservesPreviousFile` |
