# Test Plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| Renaming an applied paragraph style keeps it applied | Build a document with a paragraph style applied to a top-level type layer and to a type layer inside a group, rename the style with an attribute change through the document operation, then edit the renamed style again | Sheet holds the new name, both layer references point at it, and the second edit changes both layers' content | `pictura-render::renaming_an_applied_paragraph_style_keeps_nested_applications`, `tst_paragraph_styles_panel::renameKeepsApplied` |
| A rename and its attribute change are one undo step | Rename an applied paragraph style and change an attribute through the pinned bridge, undo once, redo once | One history state; undo restores name, references and content together; redo reapplies all three | `pictura-app::renaming_an_applied_paragraph_style_records_one_undoable_state`, `tst_paragraph_styles_panel::renameAndEditAreOneUndo` |
| A duplicate target name is refused | Request a rename to a name already used by another style of the same kind in the sheet | `StyleError::Duplicate`; sheet, references, content and history unchanged; the panel returns failure to its caller | `pictura-render::a_duplicate_target_name_is_refused`, `tst_paragraph_styles_panel::renameToExistingIsRefused` |
| A missing source style is refused | Request an edit or rename whose source name is absent from the sheet | `StyleError::NotFound`; sheet, references, content and history unchanged | `pictura-render::a_missing_source_style_is_refused` |
| Basic Paragraph is never renamed | Rename `Basic Paragraph` away, rename another style to `Basic Paragraph`, then edit `Basic Paragraph` under its own name | Both renames return `StyleError::Protected` and change nothing; the same-name attribute edit succeeds | `pictura-core::basic_paragraph_is_never_renamed`, `tst_paragraph_styles_panel::renamingBasicParagraphIsRefused` |
| Editing Basic Paragraph reaches the layers that apply another style | Edit `Basic Paragraph` under its own name after applying a paragraph style to a type layer, then inspect the layer | The layer keeps its applied style, that style's own attributes still win, and an attribute it inherits from `Basic Paragraph` changes in the rendered content | `pictura-render::editing_basic_paragraph_reaches_the_layers_that_apply_a_style` |
| Character styles share the same edit contract | Rename an applied character style with an attribute change, then request a missing-source and a duplicate-target edit | The rename keeps the layer reference and records one state; each refused request changes nothing and returns the matching error | `pictura-render::a_character_style_rename_keeps_applied_references`, `tst_character_styles_panel::renameKeepsApplied`, `tst_character_styles_panel::renameToExistingRestoresPreview` |
| Non-editable type content is left as it is | Rename a style in a document whose type layers cannot be re-set (not 8-bit RGB) | Sheet and the applying layers' references carry the new name; rendered type content stays unchanged | `pictura-render::renaming_in_a_non_editable_document_keeps_the_content` |
| Deleting the default style is refused | Select the `Basic Paragraph` row and invoke the delete action | Style remains and no history state is recorded | `tst_paragraph_styles_panel::createAndDelete` |
| Deleting another style removes it | Select a non-default style and invoke the delete action, then undo once | Style disappears from the list and one undo restores it | `tst_paragraph_styles_panel::createAndDelete` |
| Renaming an applied style keeps it applied | Apply a style to a type layer, open the options dialog, change the name and an attribute with Preview checked, accept | The layer still applies the style under its new name with the changed attribute, and one undo restores the old name and attribute | `tst_paragraph_styles_panel::renameKeepsApplied`, `tst_paragraph_styles_panel::renameAndEditAreOneUndo` |
| A refused rename leaves the style unchanged | Open an applied style, change attributes with Preview checked, change the name to an existing style (and separately to/from `Basic Paragraph`), accept | Panel returns failure to its caller, list still shows the original style, applying layers hold their pre-dialog attributes, and no history state is recorded | `tst_paragraph_styles_panel::renameToExistingIsRefused`, `tst_paragraph_styles_panel::renamingBasicParagraphIsRefused` |
