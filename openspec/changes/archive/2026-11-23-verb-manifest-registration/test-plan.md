# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| A new bridge needs no build-script edit | Add a scratch bridge source, add its header to a membrane, bless the bridge list | The bridge builds with no edit to `build.rs` | `pictura-app::build_script_derives_bridge_sources` |
| An unlisted bridge fails the gate | Add a bridge source without blessing the list, and separately name a non-bridge file in the list | Each case fails the drift test and names the offending file | `pictura-app::bridge_sources_match_the_tree` |
| A non-bridge source edit does not rerun the build script | Edit a body outside a bridge module, rebuild | The script does not rerun and no generated header mtime moves | manual: cargo/Ninja rerun observation, recorded in `design.md` |
| A verb's owning header is discoverable from the manifest | Read `verb_manifest.tsv` for one verb per membrane and compare the owner column with the membrane's includes | Each row names the membrane or adapter that includes the verb's generated header | `pictura-app::verb_manifest_names_owners` |
| A renamed verb is visible without reading generated headers | Read the rows for the verbs declaring `#[cxx_name]` | Each row carries the C++ name alongside the Rust name | `pictura-app::verb_manifest_names_renamed_verbs` |
| A verb added, removed, or renamed fails the drift test | Delete one manifest row, then edit one `cpp_name`, and run the test each time | The test fails and names the drifted row | `pictura-app::verb_manifest_matches_bridge_sources` |
| The manifest matches the tree when blessed | Regenerate with `PICTURA_WRITE_VERB_MANIFEST=1` and rerun the manifest tests | The drift test passes, and the row count equals the declared function count (1,465 today) | `pictura-app::verb_manifest_matches_bridge_sources`, `pictura-app::verb_manifest_counts_every_declared_function` |
| The manifest changes no runtime behavior | Hash the generated headers before and after the change, then run both self-test invocations | Headers are byte-identical and every self-test exit code is unchanged | manual: compare the exported generated-header hashes and both `./build/pictura --headless --self-test` exit codes; no test asserts header bytes |
| The small bridges are gone | Count exposed `extern "Rust"`/`extern "RustQt"` functions per bridge file | Every bridge with at least one exposed function declares more than two; import-only bridges exempt; count within the recorded budget | `pictura-app::no_small_bridge_files` |
| A folded verb keeps its call sites working | Build and run the Qt suites and both self-tests after swapping the bridge list | Same generated symbols; suites and exit codes unchanged | manual: run `bash scripts/verify-full.sh` and both self-test invocations; the Qt suites together cover the call sites and no single case proves the symbol set |
| A new direct generated include fails the gate | Feed the scanner a synthetic tree with a direct generated include | The scanner reports the offending file | `pictura-app::generated_include_scan_rejects_violation` |
| Bridge growth fails the gate | Count bridge files and check `cxxqt_object.rs` size | Bridge count `<= 74`; file `<= 1204` lines; `build.rs` names no bridge source inline | `pictura-app::bridge_count_within_budget` |
| bp_bridge_impl_no_rerun | Edit a body outside the bridge module, rebuild | The build script does not rerun and no generated header mtime moves | manual: cargo/Ninja rerun observation, recorded in `design.md` |
| bp_bridge_unlisted_source | Edit a Rust source with no bridge module, rebuild | The build script does not rerun and the generated header mtimes are unchanged | manual: cargo/Ninja rerun observation, recorded in `design.md` |
| bp_bridge_tracking | Change a shell C++ translation unit that no bridge includes, rebuild | The build script does not rerun and the generated headers keep their mtimes | manual: cargo/Ninja rerun observation, recorded in `design.md` |
| bp_bridge_header_tracking | Change a hand-written C++ header a bridge includes, rebuild | The build script reruns and the Rust static library is rebuilt | manual: cargo/Ninja rerun observation, recorded in `design.md` |
