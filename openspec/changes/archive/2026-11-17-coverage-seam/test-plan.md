# Test plan

All rows are automated. The coverage references below name std Rust tests written during apply before
the corresponding production changes. Their execution is deferred at the
user's request. Existing regression assertions remain unchanged. No manual rows or
golden-baseline changes are planned.

Build and run checks only after all code and test edits are complete. Prepare
flat reference data before measuring tiled reads, and use the existing isolated
materialization-guard pattern where process-global counters require it.

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `cov_sources` | Project a selection and alpha channel containing 0, 1, 64, 128, 254, and 255; project a real raster mask with an offset and gray exterior; exercise flat and tiled storage. Quick Mask's producer is also covered in `cov_quick_mask`. | Exact bytes and source dimensions/identity survive; raw mask projection adds no selection metadata and leaves actual mask fields unchanged. | `pictura-select::coverage_sources_preserve_selection_and_channel_bytes`, `pictura-core::raw_mask_projection_preserves_samples` |
| `cov_none_empty` | Run a destructive adjustment on identical fixtures with absent, empty, all-covered, and partially covered constraints. | Absent and all-covered constraints give the established unrestricted result, empty coverage leaves every pixel unchanged, and partial coverage has the established rounded result. | `pictura-render::coverage_constraints_distinguish_absent_and_empty` |
| `cov_quick_mask` | Enter Quick Mask without a selection; create an independent soft temporary selection; run a coverage edit; undo and redo through the session. Include both display interpretations and a tiled nonconstant Quick Mask source. | Only selected Quick Mask samples change, canonical source bytes remain correctly oriented, the independent clip is retained, and history restores exact coverage without source materialization. | `pictura-app::quick_mask_coverage_keeps_temporary_clip` |
| `cov_coordinates` | Sample an asymmetric small plane at positive and negative origins, every half-open edge, x beyond a row, and far outside, for exterior 0, 128, and 255. | Stored bytes map to their document pixels; exterior values are exact and x never wraps into another row. | `pictura-core::coverage_samples_document_coordinates` |
| `cov_rows` | Read spans crossing bounds and 256-pixel tile edges plus fully exterior rows into buffers initialized to an unrelated sentinel. | Every byte equals direct point sampling, no sentinel leaks, and no tiled plane materializes. | `pictura-core::coverage_rows_match_samples` |
| `cov_rebase` | Rebase a tiled selection for positive and negative mask origins; compare local samples with original document samples and inspect storage identity/sharing. | Samples and exterior values map exactly, the source geometry remains unchanged, and rebasing shares storage without copying or materializing coverage. | `pictura-core::coverage_rebase_shares_storage` |
| `cov_invalid` | Supply wrong flat lengths and tiled dimensions; request translations near signed-coordinate limits; include valid zero-area and constant coverage controls. | Invalid construction/rebase reports failure without panic or mutation; valid controls succeed and no coverage materializes. | `pictura-core::coverage_invalid_geometry_is_refused` |
| `cov_uniform` | Query covered bounds and uniform values on empty, uniform, mixed, entirely exterior, and partially exterior regions in flat and tiled forms; check constant coverage and tile classes. | Results agree and include exterior semantics; uniform/empty tiles stay constant, queries remain region-bounded, and materialization counts do not move. | `pictura-core::coverage_uniform_regions_preserve_tiles` |
| `cov_render` | Pass one shared soft coverage fixture into filter, adjustment, Apply Image, matting, filter proxy, selected-content move, Layer via Copy/Cut, and selection-driven mask creation; include offset layers and established refusal cases. | Each accepts the common interface and retains established expected pixels, alpha/lock rules, placement, and refusals; source coverage stays tiled. | `pictura-render::renderer_edits_share_coverage_input` |
| `cov_paint` | Use equivalent flat and tiled coverage for fill, gradient, bucket, eraser, brush clipping, and per-dab restoration; include offset/growing layers and a rebased mask-local target. | Results match fixed fractional expectations and the flat run, uncovered pixels remain unchanged, and uniform inputs retain their sparse processing without materialization. | `pictura-paint::paint_edits_share_coverage_input` |
| `cov_healing` | Run Patch source, destination, texture-only and content-aware modes and Content-Aware Move/Extend with the same soft coverage held flat and tiled; include empty, zero-drag, and locked controls. | Documents, damage, and refusal results match the established expectations and each other; only the existing bounded solver workspace is built, without materializing the coverage source. | `pictura-paint::healing_reads_shared_coverage` |
| `cov_clipboard` | Copy, Copy Merged, Clear, and Paste Into/Outside from an offset layer under small soft coverage in flat and tiled form; compare complete clips/masks; exercise Cut, refusals, undo, and redo at the session layer. | Clip bounds and alpha remain exact and small, pasted mask/exterior policies remain unchanged, locked/empty cases retain their refusals, and successful mutations keep their established single history states. | `pictura-render::clipboard_reads_shared_coverage`, `pictura-app::clipboard_coverage_preserves_history` |
| `cov_mask` | Construct real masks from coverage; render/edit masks with actual density, feather, link flags, disabled/missing-data state, gray exterior, off-canvas samples, and native mask data; compare metadata and established expected coverage. | Only explicit mask creation assigns defaults; existing raw-versus-refined and missing-data policies are preserved, feather/density are applied once, and unrelated metadata/native/off-canvas data survive. | `pictura-render::coverage_preserves_real_mask_semantics` |
| `cov_feather` | Build a sufficiently large rectangle across tile boundaries and apply real selection feather; assert empty, uniform, and dense tiles plus fractional edge bytes; copy reference bytes to flat storage before measurement, then run a filter and a paint edit through shared coverage. | Both operations match their flat result byte-for-byte, gray edge values affect the pixels, and the tiled runs report zero source materializations. | `pictura-render::feathered_sparse_coverage_matches_flat`, `pictura-paint::feathered_sparse_paint_matches_flat`, `pictura-render::feathered_selection_also_clips_paint_without_materialization` |
