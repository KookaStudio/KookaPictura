# Test Plan

One row per scenario in the change's delta specs under `specs/`. Coverage names
an automated Qt case; the new cases are written before the implementation.

| Scenario | Steps | Expected | Coverage |
| --- | --- | --- | --- |
| `lmk_row_link` | Show a linked raster-mask row and read the row image and link hit-target | A link glyph sits between the layer and mask thumbnails | `tst_canvas_mask_domain::maskModifierIndicatorsRemain` |
| `lmk_row_disabled` | Shift-click an enabled raster mask and read the row image | The mask is disabled and a red cross is drawn over its card | `tst_canvas_mask_domain::maskModifierIndicatorsRemain` |
| `lmk_row_link_click` | Click the raster-mask link glyph | The mask is unlinked and history gains one state | `tst_canvas_mask_domain::maskModifierIndicatorsRemain` |
| `lmk_row_shift` | Shift-click the raster-mask thumbnail | The mask's enabled state toggles in one undoable step | `tst_canvas_mask_domain::maskModifierIndicatorsRemain` |
| `lmk_row_shift_solo` | Alt-click a mask, then Shift-click it | The solo stays on while the enabled state toggles | `tst_canvas_mask_domain::maskModifierIndicatorsRemain` |
| `lmk_row_solo_exit` | Solo a mask, then select another layer | The solo ends and the composite returns | `tst_mask_edit::maskSoloFollowsLayerChange` |
| `lmk_row_activate` | Click the raster-mask thumbnail | The mask is the edit target, draws brackets and its black outline, and history is unchanged | `tst_canvas_mask_domain::maskThumbnailUsesOnlyBrackets` |
| `lmk_row_deactivate` | Click the layer/content thumbnail while the raster mask is the target | The target clears, the mask brackets go away, the content brackets appear, and an active vector stays selected | `tst_canvas_mask_domain::maskBracketsFollowRasterAndLayerClicks`, `tst_canvas_mask_domain::maskThumbCompanions` |
| `lmk_row_alt_solo` | Alt-click the raster-mask thumbnail | The row is selected, the mask is the target with brackets, the canvas shows the mask, and history is unchanged | `tst_canvas_mask_domain::maskModifierIndicatorsRemain` |
| `lmk_row_alt_restore` | Alt-click the same mask again | The composite returns and the mask stays the target | `tst_canvas_mask_domain::maskModifierIndicatorsRemain` |
| `lmk_row_alt_shift` | Alt+Shift-click the raster-mask thumbnail | Neither solo nor the enabled-state toggle takes effect | `tst_canvas_mask_domain::maskModifierIndicatorsRemain` |
| `lmk_row_modifiers_keep_selection` | Shift-click either mask, Ctrl-click the raster mask, and Alt+Shift-click the raster mask, on an active row and once on an inactive row | Only the enabled state, mask-coverage selection, or rubylith overlay changes; the companion and vector selection stay, except an inactive row defaults to content; Alt-clicking the raster mask still selects it as the companion and target | `tst_canvas_mask_domain::maskModifierIndicatorsRemain`, `tst_layers_panel::vectorMaskRowIndicators` |
| `vmk_row_vector` | Show a linked, enabled vector-mask row | A vector-mask card and its link glyph are drawn | `tst_layers_panel::vectorMaskRowIndicators`, `tst_canvas_mask_domain::allMaskCardsFollowDocumentAspect` |
| `vmk_row_vector_disabled` | Shift-click the vector thumbnail | The vector mask is disabled and a red cross is drawn | `tst_layers_panel::vectorMaskRowIndicators`, `tst_canvas_mask_domain::maskModifierIndicatorsRemain` |
| `vmk_row_vector_link_click` | Click the vector link glyph | The vector mask is unlinked in one state | `tst_layers_panel::vectorMaskRowIndicators` |
| `vmk_row_vector_shift` | Shift-click the vector-mask thumbnail | The vector mask's enabled state toggles in one undoable step | `tst_layers_panel::vectorMaskRowIndicators` |
| `mtp_black_outline` | Select a raster mask on a pixel row and a group row and read the card edges | The card has the black outline and white brackets, with no white rectangular outline | `tst_canvas_mask_domain::maskThumbnailUsesOnlyBrackets` |
| `mtp_other_layer` | Select a mask, then click another layer's raster/content thumbnail | Only the new content thumbnail has brackets; the old mask keeps its black outline only | `tst_canvas_mask_domain::maskBracketsFollowRasterAndLayerClicks` |
| `vmk_row_vector_selects_both` | On the active both-mask row, click the raster mask (target), then the vector thumbnail | Active thumb is raster+vector; both mask cards draw brackets; the raster stays the edit target and the mask colour pair | `tst_canvas_mask_domain::maskThumbCompanions`, `tst_panels_parity::thumbnailAdjacencyAndActiveThumb` |
| `vmk_row_vector_toggle_off` | Click the selected vector thumbnail again | Active thumb is raster only; the vector brackets clear; the raster target stays | `tst_canvas_mask_domain::maskThumbCompanions` |
| `lmk_row_raster_keeps_vector_state` | Click the raster-mask thumbnail with the vector selected, then repeat with the vector unselected | The raster becomes the target; the vector selection is unchanged in both clicks | `tst_canvas_mask_domain::maskThumbCompanions` |
| `vmk_row_vector_companion_content` | With raster+vector selected, click the content thumbnail | Active thumb is content+vector; the mask target clears; both cards draw brackets | `tst_canvas_mask_domain::maskThumbCompanions` |
| `vmk_row_vector_companion_mask` | With content+vector selected, click the raster-mask thumbnail | Active thumb is raster+vector; the raster is the target; content brackets clear | `tst_canvas_mask_domain::maskThumbCompanions` |
| `vmk_row_vector_only_companion` | On a layer with only a vector mask, click the vector thumbnail | Active thumb is content+vector; the mask target stays clear | `tst_canvas_mask_domain::vectorOnlyMaskThumbCompanion` |
| `vmk_row_inactive_content` | Make another layer active, then click the first layer's content thumbnail | The first layer becomes active with content only and no mask target | `tst_canvas_mask_domain::inactiveLayerThumbClicks` |
| `vmk_row_inactive_mask` | Make another layer active, then click the first layer's raster-mask thumbnail | The first layer becomes active with raster mask only, as the target, and no vector | `tst_canvas_mask_domain::inactiveLayerThumbClicks` |
| `vmk_row_inactive_vector` | Make another layer active, then click the first layer's vector thumbnail | The first layer becomes active with content+vector and no mask target | `tst_canvas_mask_domain::inactiveLayerThumbClicks` |
| `vmk_row_other_layer_clears` | Select raster+vector on a row, change layer through `window_->selectLayerPath`/`set_active_layer`, refresh, then click the first row's body | The first row has no mask/vector bits before the body click; the row-body click selects content only | `tst_canvas_mask_domain::otherLayerClearsThumbSelection` |
| `uip_layers_mask_adjacency` | Show a layer with a mask and a vector mask | The mask thumbnail is directly right of the image thumbnail and the vector mask directly right of the mask, each with a chain glyph | `tst_panels_parity::thumbnailAdjacencyAndActiveThumb` |
| `uip_layers_active_thumb` | Click a layer thumbnail to become the edit target | Brackets mark that thumbnail and a group row never shows brackets on its icon | `tst_canvas_mask_domain::maskThumbnailUsesOnlyBrackets`, `tst_canvas_mask_domain::layerRowClickDefaultsToContent` |
| `uip_layers_link_glyph` | Show a masked or vector-masked row, linked or unlinked | The chain glyph is two pixels larger than the slot and rotated a quarter turn, so its ink is taller than wide | `tst_layers_panel_fixes::linkGlyphRotatedAndLarger` |
| `lpr_thumb_adjustment_icon` | Show an Invert, Levels, or other adjustment row | Its thumbnail is a neutral card with the kind icon and no checkerboard | `tst_layers_panel_fixes::adjustmentThumbnailIsSquareWithoutOutline` |
| `lpr_thumb_fill_preview` | Show a Solid Color, Gradient, or Pattern fill row | Its thumbnail shows the fill's swatch, ramp, or tiled pattern instead of a generic checkerboard | `tst_layers_panel_fixes::fillThumbnailIsSquareWithOutline` |
| `lpr_thumb_pattern_fill_loaded` | Open a PSD with a Photoshop 24-slot pattern fill and a painted mask | The fill row shows the tiled pattern and a non-null mask thumbnail with light and dark coverage | `tst_layers_snapshot::patternFillThumbnailAndMask` |
| `lpr_thumb_adjustment_square` | Show an adjustment row in a non-square document | Its image card is 1:1 rather than letterboxed to the document | `tst_layers_panel_fixes::adjustmentThumbnailIsSquareWithoutOutline` |
| `lpr_thumb_fill_square` | Show a fill row in a non-square document | Its card and the supplied preview are square and fill the card without margin or distortion | `tst_layers_panel_fixes::fillThumbnailIsSquareWithOutline` |
| `lpr_thumb_mask_square` | Show an adjustment or fill row carrying a layer mask or vector mask | The mask and vector cards follow the document aspect while the content card stays square | `tst_layers_panel_fixes::maskThumbnailKeepsDocumentAspectOnSquareRows` |
