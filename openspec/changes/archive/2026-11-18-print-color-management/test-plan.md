# Test plan

New automated checks are named here for implementation. Use generated profiles
and project-generated PSD/PSB files. Keep local Adobe observation files outside
the repository. Run the Adobe checks with the same printer and proof profiles
installed on both systems.

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| Preview, orientation, and a PDF job | Open Print on a red image, inspect printer order and fit, toggle landscape and paper tint, cancel, then save a landscape PDF with two copies selected. Cancel the path chooser in a second run. | PDF is listed last, Letter orientation and centred image are visible, paper tints, the first cancel changes nothing, and a successful PDF write commits the settings. Cancelling the path chooser creates no job. | `tst_print::previewAndOrientation`, `tst_print::saveAsPdf` |
| The commands follow the document | Inspect both actions before and after creating a document and sample the flattened print source. | Ctrl+P opens Print, both commands follow document availability, and print uses the flattened content. | `tst_print::menuCommands` |
| `print_one_copy_settings` | Inject an eligible supported destination, valid output profile and a submission recorder. Load a document with distinct settings and a saved copy count of three. Invoke One Copy and repeat with PDF, a missing queue, and a queue blocked by preflight. | One native submission uses the document colour, proof and marks, and overrides only the submitted copy count. PDF and missing-queue cases open Print; a preflight-blocked queue opens it with an actionable reason. | `tst_print::printOneCopyUsesResolvedSettings` |
| `print_managed_pdf` | Print deterministic colour patches under Gray, RGB and CMYK ICC profiles with representative intents and BPC changes. Extract PDF image bytes and ICC data. Run the same source in printer-managed mode. | Channel count, ICC tag and device samples match the Little CMS reference within the contract tolerance. The printer-managed comparison receives no output-device transform. | `pictura-codec::print_pdf_preserves_icc_device_samples`, `tst_print::applicationManagedPdf` |
| `print_invalid_profile` | Try missing, malformed and ambiguous ICC selections in application-managed mode with a recorded submission attempt and a temporary PDF destination. | An actionable error appears, the choice is retained, and the destination receives no job or file. | `tst_print::invalidManagedProfileBlocksOutput` |
| `print_managed_cups` | Inject validated, unknown, observably changed and unverifiable configurations, including changes in output profile, colour space and colour options; record submission options, rejection, failure and acceptance. | Only matching validated configuration submits with selected options; rejection precedes queuing and offers alternatives. Submission failure retains defaults; success with job ID commits them without rollback on later physical failure. | `tst_print::managedCupsEligibility` |
| `print_managed_cups_physical` | Document the opt-in, device, queue, filter chain, media, output colour space and profile, colour options and bypass evidence. Print a known target with nondefault tray, size, landscape and two copies; inspect device samples or raster diagnostics. | The bypass and physical options are confirmed for that configuration. | manual: requires a real CUPS queue and access to driver output or raster diagnostics |
| `print_preview_aids` | Use known in-gamut and out-of-gamut patches. Toggle each preview aid and extract samples from the PDFs written with the aids on and off. Compare a wide-gamut transparent source against the print conversion. | The preview shows the expected proof, warnings are confined to the out-of-gamut patch, the paper changes, and saved samples are equal. | `tst_print::previewAidsLeaveOutputSamplesAlone`, `pictura-app::wide_gamut_preview_uses_the_print_conversion_and_matte` |
| `print_hard_proof` | Set View proof with canvas Proof Colors off. Print, change the print-only proof and each supported simulation flag, print again, and remove a selected ICC profile. Compare preview, PDF data, View state and history. Check named profile collisions and gamut warning in hard-proof mode. | Preview and device samples match the selected simulation and respond to flags. View, image, and history are unchanged. A missing profile gives an explained unproofed preview and blocks submission. | `pictura-color::hard_proof_outputs_printer_device_samples`, `tst_print::hardProofUsesLocalSetup`, `tst_print::proofProfilePathTakesPrecedence` |
| `print_hard_proof_mode` | Reopen a document with a saved proof distinct from View; change colour mode and remove or invalidate the output ICC. Repeat without a saved print proof. | Saved proof wins and is retained; printer-managed mode explains the unavailable control, invalid output ICC blocks the job, and an absent saved setup initializes from View. | `tst_print::hardProofModeAndSavedSetup` |
| `print_marks_layout` | Print a named image with a File Info description, all decorations, and nonzero border and bleed on a page with room. Compare physical coordinates derived from preview and PDF and inspect the labels. | Crop marks move by the bleed inset, placements and widths agree, and filename, description, and marks appear in the expected regions. | `tst_print::outputMarksMatchPdfLayout` |
| `print_marks_no_room` | Use a deliberately constrained printable area and request oversized exterior decorations. Check preview and PDF. | Marks that do not fit are absent and the image stays inside the printable bounds. | `tst_print::outputMarksRespectPrintableBounds` |
| `print_persist_defaults` | Use isolated settings. Accept portable edits and local job choices, save PSD and PSB, reopen with a new app settings instance, and compare to a second document. Repeat with Cancel, close, and a failed job. Save snapshots around an image undo and a later print edit. Check inherited managed settings and saving a raster-path document with pending print metadata. | Local defaults persist and documents keep their own choices. Accepted edits reach Save without a history entry. Cancellation and failures make no changes, and an older completed save leaves a newer edit dirty. Raster documents route pending print metadata to native Save As. | `tst_print::acceptedDefaultsSurviveRestartAndReopen`, `tst_print::inheritedManagedSettingsPersist`, `tst_print::pendingPrintMetadataRequiresNativeSave`, `pictura-app::print_metadata_survives_undo_and_concurrent_save` |
| `print_codec_round_trip` | Read project-generated PSD and PSB containing version-16 print settings, unknown keys, legacy flags, platform data and unrelated resources. Change one field and write both formats. Repeat with an invalid descriptor and with no edit. | The supported field uses its standard resource and key. Untouched settings survive, unrelated and opaque bytes survive, and malformed data survives save and blocks destructive edits. | `pictura-codec::print_resources_round_trip_psd_and_psb`, `pictura-codec::opaque_print_resources_survive_save` |
| `print_adobe_round_trip` | In both CS6 and CC, open Pictura PSD and PSB files with distinctive settings and inspect File > Print. Edit one supported value, save a copy, reopen it in Pictura, then save and reopen in that Adobe version again. Record OS and exact version, and try CMYK destination and both simulation flags separately. | The minimum field set is restored in each direction. Edited and untouched values agree on reopening. A field matrix records results for all remaining controls. | manual: requires licensed Photoshop CS6 and Photoshop CC installations and their Print dialogs |
| A4 chosen in Print Settings reaches the preview and the job | Choose A4 and Cassette using the provider; inspect preview and emitted PDF MediaBox, record native submission options, and inspect the legacy Qt printer configuration. | A4 and Cassette persist, the MediaBox is A4, and native options and Qt configuration contain the choices. | `tst_print::pageSetupReachesOutput`, `tst_print::printSettingsPersistPageSetup` |
| `print_page_setup_physical` | Choose A4 and Cassette and submit a printer-managed job to a real CUPS queue. | The physical job uses the selected tray. | manual: requires a real CUPS queue and physical tray confirmation |

The implementation PR checklist includes all manual checks, including the legacy page-setup check. Record
actual results, including the queue and Adobe versions used.
