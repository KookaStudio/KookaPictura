# Test Plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| Layer via Copy extracts the selection | Select a non-group pixel layer, make a rectangular selection, assert the action is enabled and keeps `Ctrl+J`/`Layer via Copy`, then dispatch `layer.new.layerViaCopy` | A `"<name> copy"` layer appears directly above the source with only the selected pixels; the source is unchanged; one history state | `tst_layer_commands::ctrlJCopiesSelection`, `pictura-render::layer_via_copy_extracts_selection_and_keeps_source` |
| Layer via Cut clears the source | Select a raster layer carrying alpha, make a selection, and dispatch `layer.new.layerViaCut` | The copy sits above the source with the selected pixels; the source's pixels inside the selection are cleared; pixels outside are preserved; one history state; the engine math is covered by the existing test | `tst_layer_commands::ctrlJCutOutcomes`, `pictura-render::layer_via_cut_clears_full_and_scales_partial_coverage` |
| `lmb_via_copy_group` | Create a group with a named child, select the group row, leave no selection, refresh the registry, assert `Ctrl+J` resolves to `layer.new.layerViaCopy`, dispatch it (and attempt Ctrl+J via `QTest::keyClick` with the offscreen `trigger()` fallback); dispatch again with an active selection; then clear the selection, select the source group plus the plain bottom layer (anchor the group), and dispatch | The action is enabled; row count grows by two; a group copy with a copy of the child appears above the source; the group copy is selected; the source group, its child, and the child count are unchanged; one history state; the second dispatch also duplicates the group; the mixed selection adds three rows (a whole group copy with its child plus the plain layer's copy) and one history state | `tst_layer_commands::ctrlJDuplicatesGroup` |
| `lmb_via_copy_no_selection` | Select a plain pixel layer with no active selection, assert the action is enabled, and dispatch `layer.new.layerViaCopy`; then make an active selection that covers no pixels with an out-of-document `select_rect` and dispatch again | A `"<name> copy"` layer appears directly above the source, it is selected, and exactly one history state is recorded; the empty active selection duplicates the selected layer too (`"Duplicate Layer"` history label) rather than inserting a selection copy | `tst_layer_commands::ctrlJDuplicatesLayerWithoutSelection` |
| `lmb_via_cut_group` | Select a group with an active selection and dispatch `layer.new.layerViaCut` | The action is disabled; dispatch adds no layer and no history state; the document is unchanged | `tst_layer_commands::ctrlJCutOutcomes` |
| No selection is refused | With no active selection, inspect and dispatch `layer.new.layerViaCut` (Shift+Ctrl+J); repeat with an active selection that covers no pixels | The action is disabled in both cases; the no-selection dispatch leaves the row count and history unchanged | `tst_layer_commands::ctrlJCutOutcomes` |
