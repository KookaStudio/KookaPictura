# Test Plan

Covers every scenario in the `ui/layers-panel` and
`compositing/described-damage` deltas. The new preview, commit, cancellation,
and default behavior is exercised by Qt Test cases in
`crates/pictura-app/cpp/tests/tst_layers_preview_coalescing.cpp`. Unchanged behavior
that a modified requirement carries forward keeps its existing app self-test
coverage; `scripts/check-test-plan.py` cannot name a self-test token, so those
rows use `manual:` with the token that checks them. Rows marked "design-level"
cover a design choice that has no separate spec scenario.

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| `lpc_percent` | Mapping: set the Opacity field to 50 % via the panel | The layer stores 128 and one history state is added | manual: unchanged by this change; checked by the app self-test token `lpc_percent` (199) |
| `lpc_percent` | Display: set the layer opacity to 128 through the bridge, then refresh the panel | The Opacity field displays 50 % | manual: unchanged by this change; checked by the app self-test token `lpc_percent` (199) |
| `lpc_percent` | Drag the Opacity popup slider, then scrub the Opacity label | Both gestures change the value and emit previews | manual: unchanged by this change; `lpr_slider` (218) and `lpn_scrub` (303) cover the gestures; the panel's one-state commit is automated by `tst_layers_preview_coalescing::opacityDragCoalescesPreview` |
| `lpc_preview` | Drag the Opacity slider through several values, then release | No undo state during the drag; exactly one on release; the final stored value is the released value | `tst_layers_preview_coalescing::opacityDragCoalescesPreview` |
| `lpc_coalesced` | Emit several slider values within one preview interval, then keep emitting at a 40 ms cadence | At most one preview is applied per interval, using the latest value, no undo state is added, and continuous motion does not restart the interval | `tst_layers_preview_coalescing::opacityDragCoalescesPreview`, `tst_layers_preview_coalescing::fillDragCoalescesPreview`, `tst_layers_preview_coalescing::continuousTicksDoNotRestartTheTimer` |
| `lpc_pause` | Hold the slider still mid-drag for longer than the interval | The latest value is previewed while the button is held, with no undo state | `tst_layers_preview_coalescing::midDragPausePreviewsWhileHeld` |
| `lpc_round_trip` | Start at 100%, drag away and back to 100% within one interval, then release | No composite runs and no undo state is added | `tst_layers_preview_coalescing::fastOpacityRoundTripRecordsNothing`, `tst_layers_preview_coalescing::fillFastRoundTripRecordsNothing` |
| `lpc_commit_wins` | Release while a preview is still pending | The final value is applied exactly once; exactly one undo state is added | `tst_layers_preview_coalescing::opacityDragCoalescesPreview`, `tst_layers_preview_coalescing::fillDragCoalescesPreview` |
| `lpc_preserve` | Call `LayersPanel::refresh()` while a preview is pending | The field keeps the latest user value, no preview is applied early, and the preview fires on its interval | `tst_layers_preview_coalescing::pendingPreviewSurvivesPanelRefresh` |
| `lpc_target_change` | Let the preview fire, then switch documents, replace the document in the same view (Revert/open), or change the selected layer, and release | The gesture and the field's pending commit are canceled; the new target and history are unchanged; the old document stays modified and dirty | `tst_layers_preview_coalescing::documentSwitchCancelsPendingPreview`, `tst_layers_preview_coalescing::selectionChangeCancelsPendingPreview`, `tst_layers_preview_coalescing::sameViewReplacementCancelsPendingPreview` |
| `lpr_percent` | Show the Opacity and Fill fields | The `%` sign is drawn inside the value box | manual: unchanged by this change; checked by the app self-test token `lpr_percent` (215) |
| `lpc_percent` | Programmatic sync: refresh the panel without user input | No edit is sent and no history state is added | manual: unchanged by this change; checked by the app self-test token `lpc_percent` (199) |
| `lpc_no_selection` | Clear the Layers panel selection and inspect before any refresh | Opacity and Fill show `100%` and are disabled | `tst_layers_preview_coalescing::noSelectionShowsDefaultPercent` |
| `lpc_ineligible_default` | Select the Background, a fully locked layer, a synthetic Smart Filters row, and an all-ineligible multi-selection; select a group with Fill as the field | Each field without an eligible target shows `100%` and is disabled | `tst_layers_preview_coalescing::ineligibleTargetsShowDefaultPercent` |
| `lpc_multi_eligible` | Select an ineligible layer together with an eligible layer, for Opacity and for Fill | Each field stays enabled and shows the current row's value | `tst_layers_preview_coalescing::multiSelectionKeepsEligibleFieldEnabled` |
| A filter on a bounded layer updates only its rectangle | Apply a filter to a bounded pixel layer | Only that rectangle is composited; the result equals a full recomposite | manual: unchanged by this change; existing filter section-preview coverage is `pictura-app::section_previews_restore_only_what_they_wrote`; not re-verified here |
| An opacity change on a bounded layer updates only its rectangle | Commit an opacity or blend-mode change on a bounded layer | Only that rectangle is composited; no full frame rebuild runs; the result equals a full recomposite | `tst_layers_preview_coalescing::opacityCommitUsesTheRegionPath`, `pictura-app::layer_opacity_region_refresh_equals_a_full_recomposite` |
| `dd_preview_region` | Preview a bounded layer's opacity during a drag | The emitted region is the layer's rect and pixels outside are unchanged; the shared refresh path's full-recomposite equality is covered by `pictura-app::layer_opacity_region_refresh_equals_a_full_recomposite` | `tst_layers_preview_coalescing::opacityPreviewUsesTheRegionPath`, `pictura-app::changed_property_region_bounds_a_pixel_layer_and_rejects_a_group` |
| `dd_canvas_region` | Change a full-canvas pixel layer's opacity | The region path is used; no full frame rebuild runs; the full-document recomposite path is not run | `tst_layers_preview_coalescing::canvasSizedOpacityUsesTheRegionPath` |
| A paste updates only the pasted rectangle | Paste an image at a bounded destination | Only the pasted rectangle is composited; the result equals a full recomposite | manual: unchanged by this change; existing placement coverage is `tst_edit_clipboard::editClipboard`; the region path is not re-verified here |
| A paint commit updates only the stroke's rectangle | Commit a paint stroke | Only the stroke's changed rectangle is composited; the result equals a full recomposite | `pictura-app::paint_commit_region_patch_equals_a_full_recomposite` |
| A transform commit updates the union of source and destination | Commit a layer move or free transform | The union of the source and destination rectangles is composited | `pictura-app::layer_move_region_refresh_equals_a_full_recomposite` |
| Group preview falls back to the full document (design-level) | Preview a group's opacity | A full recomposite runs and no region blit is emitted | `tst_layers_preview_coalescing::groupOpacityPreviewFallsBackToFullRecomposite` |
| A non-fixed start byte round trip records one state (design-level ceiling) | Start a layer at stored opacity 127 (displayed 50%), drag away and back to 50%, then release | Exactly one state is recorded because the final byte is 128 | `tst_layers_preview_coalescing::fastRoundTripAtNonFixedByteRecordsOneState` |
| Preview cost is bounded (design-level profile) | Run N synthetic preview steps on a 4000² document with a bounded layer | Record the per-step full and region composite cost; the Qt coalescing tests, not the profile, count the coalesced canvas updates | `pictura-app::opacity_preview_profile_4000` |
