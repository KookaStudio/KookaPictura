# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `cal_sources_same_size` | Sources must match the active document's dimensions: open 20×20 twice and a 30×30 document, open the dialog | The active document is first; the 30×30 document is absent from both Source lists | `tst_calculations::sourcesMatchDimensions` |
| `cal_channel_list` | Composite is absent and Gray is offered: open an RGB document with one saved alpha channel and a pixel layer carrying a raster mask, plus a Grayscale document; read Source 1's, Source 2's, and the Mask channel lists for both source documents | Both Source lists offer Gray, the colour planes (Red, Green, Blue on the RGB document; the single Gray plane on the Grayscale document), Transparency, Layer Mask when the chosen layer has one, and the alpha channel names, with no composite entry; the Mask list adds Selection only when the chosen Mask image has a selection, and omits it when that image has none | `tst_calculations::channelListHasGrayAndNoComposite` |
| `cal_scale_offset_rows` | Scale and Offset follow the mode: switch Blending between Add, Subtract, and layer modes | Scale and Offset are visible only for Add and Subtract; Scale defaults to 1.000 with range 1.000–2.000; Offset defaults to 0 with range −255–255; both rows are hidden for every other mode | `tst_calculations::scaleOffsetFollowMode` |
| `cal_defaults` | Defaults: open the dialog and read the controls | Blending is Multiply, Opacity is 100 %, Result is New Document, Scale is 1.000 with range 1.000–2.000, Offset is 0 with range −255–255, and the Add/Subtract rows are hidden | `tst_calculations::defaults` |
| `cal_mode_list` | The mode list: read the Blending list | No Dissolve, Multiply selected, Subtract once | `tst_calculations::modeList` |
| `cal_disabled_modes` | Disabled modes and no document: open an Indexed document, then create a Bitmap document by converting a Grayscale document with the Bitmap mode command, refresh the registry, then close every document | The Calculations row is disabled in the Indexed, Bitmap, and no-document states | `tst_calculations::disabledModes` |
| `cal_menu_row` | Menu row is live: open a document and inspect Image ▸ Calculations… | The row is enabled and opens the dialog | `tst_calculations::menuRowIsLive` |
| `cal_add_scale_two` | Add with Scale 2 averages: run Add with Scale 2 and Offset 0 on known planes | The result is the average within 1/255 | `pictura-render::add_scale_two_averages` |
| `cal_subtract_scale_offset` | Subtract honours Scale and Offset: run Subtract at varied Scale and Offset | A higher Scale lowers the result; a positive Offset raises it | `pictura-render::subtract_honours_scale_and_offset` |
| `cal_layer_modes` | Layer modes use the shared blend: run each listed layer mode on the two sources | The result equals the shared blend function | `pictura-render::layer_modes_match_the_compositor` |
| `cal_invert` | Invert applies per source: run with Source 1 Invert, Source 2 Invert, and both | The blend reads the complemented source values | `pictura-render::invert_applies_per_source` |
| `cal_opacity` | Opacity mixes toward Source 1: run at 50 % opacity | The result is halfway between Source 1 and the full blend | `pictura-render::opacity_mixes_toward_source_one` |
| `cal_gray_luminance` | Gray matches the grayscale conversion: compare the Gray source plane with the chosen layer's or merged image's Rec.601 grayscale conversion | Values equal the Rec.601 grayscale conversion of the chosen layer or merged image (the same weights Image ▸ Mode ▸ Grayscale uses) | `pictura-render::gray_matches_grayscale_conversion` |
| `cal_alpha_source` | Alpha channel as a source: use a saved alpha channel as Source 1 | The blend reads the channel coverage | `pictura-render::alpha_channel_as_source` |
| `cal_16bit_precision` | 16-bit sources keep blend precision: blend two 16-bit values less than one 8-bit step apart | The difference changes the narrowed 8-bit result | `pictura-render::sixteen_bit_sources_keep_precision` |
| `cal_mask_hides` | Mask hides: mask with a black pixel | The result is black at that pixel | `pictura-render::mask_hides` |
| `cal_mask_invert` | Inverted mask: invert a dark mask channel | The blend shows where the channel is dark | `pictura-render::inverted_mask_reveals_dark` |
| `cal_selection_mask` | Selection as mask: use the Mask image's selection as the mask (when the Mask image is the active document this is the active selection; otherwise the chosen Mask image's selection; the Selection entry is absent when that image has no selection) | The result scales by the selection coverage and is black outside it | `pictura-render::selection_as_mask` |
| `cal_no_mask` | No mask applies everywhere: run with no mask | Every pixel holds the unmodified blend | `pictura-render::no_mask_applies_everywhere` |
| `cal_result_document` | New Document: OK with Result New Document | A same-size grayscale document opens with the blend; the source history is unchanged | `tst_calculations::resultNewDocument` |
| `cal_result_channel` | New Channel: OK with Result New Channel | An alpha channel with the blend is appended under the next default name, as one `Calculations` history state whose label is `Calculations` | `tst_calculations::resultNewChannel` |
| `cal_result_channel_undo` | New Channel undo: OK with New Channel, then undo | The channel disappears and the document is otherwise unchanged | `tst_calculations::resultNewChannelUndo` |
| `cal_result_channel_cap` | New Channel at the cap: run New Channel on a document at the 56-channel cap | The result is refused with the 56-channel limit reported; no channel is added and no history state is recorded | `tst_calculations::resultNewChannelAtCap` |
| `cal_result_selection` | Selection: OK with Result Selection | The selection coverage equals the blend, as one `Calculations` history state whose label is `Calculations` | `tst_calculations::resultSelection` |
| `cal_result_selection_replace` | Selection replaces: OK with Result Selection while a selection is live, then undo | The selection is replaced; undo restores the previous selection | `tst_calculations::resultSelectionReplaces` |
| `cal_results_agree` | Results agree: commit the same settings once per result target | The document pixels, channel coverage, and selection coverage are equal | `tst_calculations::resultsAgree` |
| `cal_preview_follows` | Preview follows controls: change a source, mode, opacity, mask, and invert | The preview image changes and the document is unmodified | `tst_calculations::previewFollowsControls` |
| `cal_preview_off` | Preview off: uncheck Preview | The preview image is hidden; the document is unmodified | `tst_calculations::previewOff` |
| `cal_preview_cancel` | Cancel changes nothing: preview, then Cancel | Pixels, channels, selection, and history are unchanged | `tst_calculations::cancelChangesNothing` |
| `cal_preview_matches_commit` | Preview matches commit: on an 8×8 document, compare the full-resolution preview plane returned by the bridge with the committed result for the same settings | The committed result equals the full-resolution preview plane, with no scaling applied to either | `tst_calculations::previewMatchesCommit` |
