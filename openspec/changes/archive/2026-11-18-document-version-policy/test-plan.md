# Test plan

| Scenario | Steps | Expected result | Coverage |
| --- | --- | --- | --- |
| dvp_stamp | Save a fresh supported document through the application as PSD and PSB and inspect both outputs. | Headers are 1 and 2 and both carriers report the same version pair and writer. | `pictura-app::native_save_stamps_document_versions` |
| dvp_header | Open generated PSD and PSB files with swapped suffixes, then open a generated file with a version-3 header. | Both supported files open, and the failed open identifies native version 3. | `tst_document_version_policy::reportsUnsupportedNativeVersion` |
| dvp_xmp_preserved | Save a generated editable file with an unrelated malformed XMP packet. | The packet remains byte-identical, the private record is present, and a save warning is shown. | `tst_document_version_policy::warnsWhenVersionMirrorCannotBeWritten` |
| dvp_legacy_current | Open unstamped and current-stamped synthetic native files. | Supported content remains editable without a warning. | `tst_document_version_policy::opensLegacyAndCurrentFilesForEditing` |
| dvp_future_writable | Open a future-but-compatible stamped file, edit a supported layer, and save. | One warning is reported and the newer stamp and opaque data survive. | `tst_document_version_policy::keepsCompatibleFutureStampOnSave` |
| dvp_private_read_only | Open generated files with a high reader floor, damaged or duplicate owned data, conflicting XMP, and XMP-only values. | Each restriction installs read-only access and reports its reason. | `tst_document_version_policy::restrictsUnsupportedPrivateVersions` |
| dvp_cc_metadata | Open and edit a synthetic CC-like file with informational writer metadata and safely preserved opaque data. | The write retains those fields and bytes without restricting access. | `tst_document_version_policy::editsFileWithAdvisoryWriterMetadata` |
| dvp_cc_feature | Open generated unsupported artboard, external link, adjustment, and unclassified layer/global critical records; exercise geometry changes, layer reorder, and deletion when dependencies cannot be proven safe. Include a known inert EXIF resource and a supported feature control. | Unsafe variants enter read-only mode and report why; controls remain editable and EXIF survives save. | `tst_document_version_policy::reportsUnsupportedPhotoshopFeatures`, `pictura-codec::unknown_group_blend_round_trips`, `pictura-app::vector_fill_compatibility` |
| dvp_adobe_reopen | Exercise PSD and PSB authored locally by CS6, CC 14.x, CC 2015, and the current and prior supported Adobe desktop releases. Vary compatibility-composite settings and check linked objects, artboards, and modern adjustments. Reopen layered output in Photoshop. | Record exact builds, feature retention, appearance, and editability. Confirm read-only outcomes and availability of flattened copies. Missing required releases or cases block shipment unless the requirement is deliberately revised. | manual: needs licensed Photoshop builds and interactive reopening to confirm Adobe rendering and layer editability |
| dvp_1057_fields | Decode generated PSD/PSB 1057 blocks with non-ASCII and supplementary Unicode names, then write them. | Typed fields match and the existing versions and names survive. | `pictura-codec::version_info_preserves_unicode_and_versions` |
| dvp_1057_recovery | Read and write files with absent, unsupported, and truncated 1057, including invalid string lengths. | Confirmed absent gets a new record; other records refuse version-aware writing and remain byte-identical. | `pictura-codec::version_info_handles_missing_or_unsupported_data` |
| dvp_1057_merged | Write version-aware PSD and PSB with merged output on and off, including a stale existing flag. | Read-back 1057 agrees with the presence of a real composite. | `pictura-codec::version_info_reports_written_merged_image` |
| dvp_1057_file_info | Open File Info for a generated native document with known 1057 values. | The Photoshop tab displays the typed resource fields. | `tst_document_version_policy::showsVersionInfoInFileInfo` |
| dvp_unrelated_bytes | Save with version metadata alongside unrelated XMP, a foreign same-ID resource, an unknown layer block, and valid framed unrelated blocks. | Only owned fields change and all other tested bytes survive. | `pictura-codec::versioned_write_preserves_unrelated_native_bytes` |
| dvp_read_only_guards | Invoke edit through a menu, a canvas tool, action playback, and ordinary save entry points including direct save. | Target content, history, path, modified state, and file bytes stay unchanged. | `tst_document_version_policy::readOnlyRejectsEditsAndSaves` |
| dvp_preview | Open generated read-only files with original merged pixels that differ from the known layer render, a false merged flag, and absent or unusable image data. | Only the real-source case shows the original merged pixels. The other cases report the missing faithful preview. | `tst_document_version_policy::usesOriginalCompositeForCompatibility`, `pictura-codec::versioned_write_marks_merged_transparency_without_marking_saved_channels`, `pictura-app::merged_transparency_ignores_saved_selection` |
| dvp_replace | Replace a read-only session through open and through revert from a newly compatible disk file. | The replacement accepts normal edits and saves. | `tst_document_version_policy::refreshesAccessOnReplacement`, `tst_document_version_policy::revertHistoryPreservesCompatibility` |
| dvp_flattened_copy | Confirm Save a Copy to a different PNG path and read it back. | The PNG matches the source composite and the open session and input bytes are unchanged. | `tst_document_version_policy::writesFlattenedCompatibilityCopy` |
| dvp_copy_refused | Cancel the warning, try the source or an alias, request a layered copy through the path API, and try a file without a usable merge. | No output is written and refused requests explain the restriction. | `tst_document_version_policy::refusesUnsafeCompatibilityCopies` |
| A resource section decodes to typed records | The document carries an image-resource section holding an EXIF resource and an XMP packet | `decode_image_resources` returns records carrying those ids, names, exact data bytes, and raw block bytes in stored order | `pictura-codec::decodes_resources_in_order_with_odd_padding` |
| The ICC profile is exposed by id | The decoded records include resource id `1039` | The record's `data` is the embedded ICC profile bytes and the well-known id constant equals `1039` | `pictura-codec::exposes_icc_resource_by_id` |
| A malformed block is skipped without panicking | The section ends with a truncated block or an unrecognized signature | `decode_image_resources` returns the records decoded before it and does not panic | `pictura-codec::truncation_returns_prior_records_and_never_panics` |
| Byte preservation is unchanged for unnormalized documents | A document read from a file with a non-empty image-resource section that was not ICC-normalized is written back using the default raw codec writer | The output's image-resource bytes are identical to the input's, except that a resource `1039` whose ICC data-space signature does not match the output header color mode is dropped | `pictura-codec::opaque_document_sections_round_trip` |
| Image resources and color-mode data round-trip | A document read from a file carries a non-empty image-resource or color-mode-data section, was not ICC-normalized, and is written back using the default raw codec writer | Reading the output yields the same resource and color-mode-data bytes | `pictura-codec::opaque_document_sections_round_trip` |
| An ICC-normalized document preserves every other resource | A document normalized from a non-sRGB ICC profile is written using the default raw codec writer and re-read | Every image resource except the profile resource is byte-identical and the profile resource is absent | `pictura-codec::non_srgb_profile_converts_and_drops_the_resource` |
| Unknown tagged blocks round-trip | A layer carries additional-layer-info blocks the engine does not model | Those blocks are present with identical keys and payloads after read→write→read | `pictura-codec::opaque_layer_blocks_round_trip` |
| An unmodeled channel round-trips | A layer carries a `-3` real-user-mask channel | The channel's bytes are present after read→write→read | `pictura-codec::depth16_unmodeled_layer_channel_round_trips_at_source_depth` |
| An unknown blend key round-trips | A layer's blend key is not one of the recognized modes | The original 4-byte key is written back after read→write→read | `pictura-codec::preserves_unknown_blend_key_on_write` |
| Blending ranges and mask parameters round-trip | A layer carries non-empty blending ranges or a mask block longer than the fixed fields | Those bytes are present after read→write→read | `pictura-codec::mask_extra_round_trips` |
| Save As writes a file | Save As a document to a new PSD path and reopen it | The file is a valid PSD at that path and the document becomes unmodified | `tst_import_save_coordinator::saveOpenAndRemember`, `tst_document_api::saveAndReopenRoundTrip` |
| Save uses the recorded path | Edit a document recorded at `photo.png` and run Save | The same path is rewritten in place | `tst_open_save::rasterOpenKeepsFilePath` |
| Save on an untitled document prompts for a path | Run Save on an untitled document through the save-path driver | A path is requested before any write | `tst_save_gif_copy::saveUntitledPromptsForPath` |
| Save after an edit writes the edited composite | Edit a raster document, save, reopen | The reopened composite is the edited render, not the pre-edit merge | `tst_open_save::rasterOpenKeepsFilePath` |
| Save As defaults to the import source format | Import a single-layer PNG and open Save As | PNG is preselected | `tst_save_format_options::formatKindForSuffix`, `tst_save_gif_copy::gifImportPreselectsGif` |
| A raster save clears modified and re-saves the same format | Save a document to `photo.png`, edit, save again | The second save writes a PNG and clears modified | `tst_open_save::rasterOpenKeepsFilePath` |
| A layered document saved to a flat format warns and flattens | Save a two-layer document to PNG and accept the warning | The flattened composite is written | `tst_save_gif_copy::layeredGifWarnsAndFlattens` |
| A layered document defaults Save As to PSD | Add a layer to a PNG import and open Save As | PSD is preselected | `tst_import_save_coordinator::saveOpenAndRemember` |
| Save on a layered raster path behaves as Save As | Save a layered document recorded at `.png` | The format-aware Save As opens instead of overwriting the PNG | `tst_import_save_coordinator::saveOpenAndRemember` |
| A PSB path writes a PSB container | Save a document to `.psb` and read the header | The file is a version-2 PSB | `pictura-codec::write_psb_small_document_widens_lengths` |
| dl_save_current | Save a modified document through the worker without editing it | The file holds the snapshot, the path is recorded, and the document is unmodified | `tst_offthread_jobs::aCompletedSaveWritesAndClearsModified` |
| dl_save_stale | Edit while the save worker runs | The file holds the snapshot and the document stays modified | `tst_offthread_jobs::anEditDuringSaveLeavesTheDocumentModified` |
| dl_save_failed | Save to an unwritable target | The save fails, path and dirty state are unchanged, and no temporary file remains | `tst_offthread_jobs::aFailedSaveLeavesTheDocumentUntouched` |
| dl_save_replaced | Replace the document while the save worker runs | The file holds the original snapshot and the replacement keeps its path and dirty state | `pictura-app::a_replaced_document_keeps_its_path_and_dirty_state` |
| copy-command-enabled | Open a document, then close all documents, and inspect Save a Copy | Enabled with a document, disabled without one | `tst_save_gif_copy::saveCopyEnabledWithDocument` |
| copy-dialog-matrix | Open Save a Copy for a single-layer PNG import | Filters and default format match Save As; PNG is preselected | `tst_save_gif_copy::saveCopyDialogMatchesSaveAs` |
| copy-cancel | Cancel the copy path dialog and a format options dialog | Nothing is written and the document is unchanged | `tst_save_gif_copy::saveCopyCancelWritesNothing` |
| copy-profile-dialog | Cancel the Embed Color Profile dialog during a copy | Nothing is written and the document is unchanged | `tst_save_gif_copy::saveCopyProfileDialog` |
| copy-nonmutating-raster | Save a modified `a.psd` document as a copy to `b.png` | `b.png` holds the flattened composite; `a.psd` stays recorded, modified, and with the same history | `tst_save_gif_copy::saveCopyRasterLeavesDocument`, `pictura-app::copy_intent_skips_path_and_dirty` |
| copy-psd | Save a copy to `backup.psd` and reopen it | The copy is a layered PSD; the open document keeps its path and format | `tst_save_gif_copy::saveCopyPsdLeavesDocument` |
| copy-pdf | Save a copy to `print.pdf` through the PDF dialog driver | The PDF is written; the document keeps its path, format, and dirty state | `tst_save_gif_copy::saveCopyPdfLeavesDocument` |
| copy-untitled | Run Save a Copy on an untitled document through the save-path driver | The copy is written at the chosen path; the document stays untitled | `tst_save_gif_copy::saveCopyUntitledStaysUntitled` |
| copy-gif | Save an RGB document as a copy to `web.gif` | The file is GIF89a; the document keeps RGB mode, path, dirty state, and history | `tst_save_gif_copy::saveCopyGifLeavesRgb` |
| copy-no-recorder | Record an action and save a copy | The action gains no step | `tst_save_gif_copy::saveCopyNoRecorder` |
| copy-failed | Save a copy over an existing file with a failing write | Failure is reported; the old bytes and the document are unchanged; no partial file remains | `tst_save_gif_copy::saveCopyFailurePreservesPreviousFile` |
| dvp_incomplete_resources | Open incomplete sections with truncated owned data, a hidden possible record, and a valid prefix stamp. | Each is read-only and version-aware rewrite is refused. | `pictura-codec::incomplete_resource_section_blocks_versioned_write`, `tst_document_version_policy::restrictsIncompleteResources` |
| dvp_1057_ambiguous | Open duplicate, malformed, or unsupported 1057 including stale true flags and disabled merge; attempt version-aware save and raw serialization. | Open remains inspectable read-only with a reason; version-aware save fails without changing destination or records; raw serialization preserves them. | `pictura-codec::ambiguous_version_info_refuses_versioned_write`, `tst_document_version_policy::restrictsAmbiguousVersionInfo` |
| dvp_raw_tail | Round-trip a resource tail using the raw writer and attempt a version-aware write. | Raw output preserves the tail; version-aware writing refuses it. | `pictura-codec::raw_write_preserves_resource_tail` |
| dvp_output_source_guard | Invoke every output path including control-server export_png and output from another active tab against source and path aliases, then export to an unrelated path. | Source attempts fail unchanged; unrelated export follows its ordinary behavior. | `tst_document_version_policy::protectsSourceAcrossOutputPaths`, `tst_document_version_policy::genericExportRejectsReadOnly` |
| dvp_source_decode_failure | Corrupt or replace the source after opening a source-backed preview and request a copy. | Viewing and copy report failure; no destination is created or changed. | `tst_document_version_policy::reportsSourceDecodeFailure` |
