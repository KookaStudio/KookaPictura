# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `et_one_owner` | Commit a layer visibility change through `PictureView::edit`; inspect the history count, dirty flag, and content revision before and after. | One state is added, the dirty flag is set, the revision advances once, and the declared compositing ran. | `pictura-app::one_commit_refreshes_captures_and_versions` |
| `et_reports_outcome` | Commit edits returning each `Edit` variant and compare the transaction's return value. | The returned outcome equals the outcome the mutation declared. | `pictura-app::the_declared_outcome_is_returned` |
| `et_noop` | Run a transaction whose mutation returns `Edit::None` on a document with existing history and damage. | History depth, revision, composite, dirty flag, damage, and signal counts are unchanged. | `pictura-app::an_unchanged_edit_records_nothing` |
| `et_bounded` | Declare one or more bounded rectangles for a small layer; commit, compare the region path with a full recomposite, and check the presentation. | Only the rectangles are composited, pixels outside keep their value, the result equals a full recomposite, and the blit effect is selected. | `pictura-app::a_bounded_outcome_requests_one_region`, `pictura-app::layer_opacity_region_refresh_equals_a_full_recomposite` |
| `et_paint_regions` | Commit a paint stroke whose dirty tiles form several disjoint rectangles. | The regions composite in one pass, exactly one region blit is emitted over the bounding box, and the result equals a full recomposite. | `pictura-app::a_multi_rect_outcome_requests_one_blit`, `pictura-app::a_multi_rect_stroke_commit_equals_a_full_recomposite` |
| `et_meta` | Commit a selection-only edit with `Edit::Meta` on a document with a known composite. | One history state is captured, the composite bytes and damage account are unchanged, and one notification fires. | `pictura-app::a_metadata_outcome_notifies_without_compositing` |
| `et_record` | Present a change through `preview`, then commit it with `Edit::Record`. | One history state is added, the compositor does not run again, and no additional `changed` is emitted. | `pictura-app::an_already_presented_edit_records_without_notifying` |
| `et_structural` | Link two layers, then commit a tree edit and a non-tree link-invalidating edit with `Edit::Structural`. | The link map is empty in both cases and the presentation requests a full rebuild. | `pictura-app::a_structural_outcome_clears_links_and_rebuilds` |
| `et_unbounded` | Commit a whole-document change with `Edit::Full`. | One rebuild is selected (no blit) and the history state is captured after the rebuild. | `pictura-app::a_full_outcome_rebuilds_once` |
| `et_capture_after_refresh` | Commit a full edit, undo it, and compare the display and document with the pre-edit state; undo must not run a full composite. | The restored document, composite, and display are byte-identical to the pre-edit state. | `pictura-app::a_commit_captures_the_refreshed_composite`, `tst_large_document::boundedUndoKeepsTheFrame` |
| `et_preview` | Run several preview edits, then commit the change; check history depth after the previews and after the commit. | Previews add no states; the commit adds exactly one. | `pictura-app::a_preview_records_nothing_and_its_commit_records_one`, `tst_layers_preview_coalescing::opacityDragCoalescesPreview` |
| `et_move_revision` | Commit a topmost-pixel-layer move and compare `content_revision` with one history state added. | Exactly one state is added and the content revision is unchanged. | `pictura-app::a_move_commit_keeps_the_content_revision` |
| `et_engine_no_composite` | Record `doc.composite` bytes, call resize, canvas-size change, crop, orientation, translation, arbitrary rotation, and perspective crop, and compare. | Each engine call leaves the composite byte-identical; the app's subsequent transaction compositing produces the displayed result. | `pictura-render::a_geometry_op_leaves_the_composite_untouched`, `tst_image_ops::imageSizeResamplesAndSetsResolution`, `tst_image_ops::canvasSizeGrowsAroundTheAnchor`, `tst_image_rotate::arbitraryRotatesAndRecords` |
| `et_mode_composite` | Convert an RGB document to grayscale and check the stored composite planes. | The composite is written in the converted representation and is not left for the app to rebuild. | `pictura-render::grayscale_is_rounded_rec601_luma_on_layers_and_composite` |
| `et_depth_composite` | Convert an 8-bit document to 16 bits and back; check the display composite and save. | The existing 8-bit display composite is preserved and the converted document saves at the new depth. | `pictura-render::eight_to_sixteen_widens_and_saves_sixteen_bit`, `tst_image_mode::depthConversionsSaveTheirDepth` |
| The cached composite equals a fresh composite after resize | Resize a layered document, commit through the transaction, and compare. | The transaction's materialized composite is bit-identical to `composite_rgba(&doc)` at the new size. | `pictura-render::resize_document_preserves_structure_and_composite` |
| `dr_engine_then_app` | Resize a layered document in the engine, check the composite before the app refresh, then commit through the transaction. | The engine leaves the cached composite byte-identical; the transaction materializes a composite equal to `composite_rgba` at the new size. | `pictura-render::resize_document_preserves_structure_and_composite` |
| `dr_merged_only` | Resize a layer-less document that has a merged composite; display and save it. | The composite is materialized as a Background with its alpha preserved, the pixels are transformed, and the result displays and saves. | `pictura-render::a_merged_only_document_keeps_its_pixels_through_geometry`, `pictura-render::a_merged_only_document_keeps_its_pixels_and_saves` |
| The resized document round-trips structurally | Resize a layered document, materialize the composite, write it, and re-read it. | The re-read document has the new dimensions and matching layer rects and channel lengths. | `pictura-render::resize_document_preserves_structure_and_composite` |
| psd-tools sees the resized document | Resize, materialize, write, and open the file with psd-tools. | psd-tools reports the new width, height, and layer count. | `pictura-render::psd_tools_sees_resized_document` |
| Missing psd-tools skips cleanly | Run any geometry oracle without psd-tools installed. | The oracle prints a skip message and the suite passes. | manual: the self-skip is only observable when psd-tools is absent |
| The cached composite equals a fresh composite after orientation | Rotate and flip a layered document, commit through the transaction, and compare. | The transaction's materialized composite is bit-identical to `composite_rgba(&doc)` at the resulting dimensions. | `pictura-render::rotate_document_preserves_structure_and_composite`, `pictura-render::flip_document_preserves_structure_and_composite` |
| `do_engine_then_app` | Rotate and flip a layered document in the engine, check the composite before the app refresh, then commit through the transaction. | The engine leaves the cached composite byte-identical; the transaction materializes a composite equal to `composite_rgba` at the resulting dimensions. | `pictura-render::rotate_document_preserves_structure_and_composite`, `pictura-render::flip_document_preserves_structure_and_composite` |
| `do_merged_only` | Rotate and flip a layer-less document that has a merged composite; display and save it. | The composite is materialized as a Background with its alpha preserved, the pixels are transformed, and the result displays and saves. | `pictura-render::a_merged_only_document_keeps_its_pixels_through_geometry`, `pictura-render::a_merged_only_document_keeps_its_pixels_and_saves` |
| The rotated document round-trips structurally | Rotate a layered document, materialize the composite, write it, and re-read it. | The re-read document has the swapped dimensions and matching remapped layer rects. | `pictura-render::rotate_document_preserves_structure_and_composite` |
| psd-tools sees the rotated and flipped document | Rotate/flip, materialize, write, and open the file with psd-tools. | psd-tools reports the remapped dimensions and layer count. | `pictura-render::psd_tools_sees_rotated_document` |
| The cached composite equals a fresh composite after canvas resize | Canvas-resize a layered document, commit through the transaction, and compare. | The transaction's materialized composite is bit-identical to `composite_rgba(&doc)` at the new dimensions. | `pictura-render::resize_canvas_document_preserves_structure_and_composite` |
| `dc_engine_then_app` | Canvas-resize a layered document in the engine, check the composite before the app refresh, then commit through the transaction. | The engine leaves the cached composite byte-identical; the transaction materializes a composite equal to `composite_rgba` at the new dimensions. | `pictura-render::resize_canvas_document_preserves_structure_and_composite` |
| `dc_merged_only` | Canvas-resize a layer-less document that has a merged composite; display and save it. | The composite is materialized as a Background with its alpha preserved, the pixels are translated, and the result displays and saves. | `pictura-render::a_merged_only_document_keeps_its_pixels_through_geometry`, `pictura-render::a_merged_only_document_keeps_its_pixels_and_saves` |
| The canvas-resized document round-trips structurally | Canvas-resize a layered document, materialize the composite, write it, and re-read it. | The re-read document has the new dimensions and matching translated layer rects. | `pictura-render::resize_canvas_document_preserves_structure_and_composite` |
| psd-tools sees the canvas-resized document | Canvas-resize, materialize, write, and open the file with psd-tools. | psd-tools reports the new dimensions and layer count. | `pictura-render::resize_canvas_document_preserves_structure_and_composite` |
| A Move commit on a large document composites on the GPU | Commit a layer move on a 4000x4000 document with GPU compute and a usable adapter. | The app's transaction composites the dirty rectangle on the GPU within ±1 LSB of the CPU oracle, and `translate_layer_active` remains the oracle. | manual: requires a usable Vulkan adapter; GPU parity is covered by the ignored translate_layer_active GPU test |
