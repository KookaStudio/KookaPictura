# Test Plan

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| `panel_surface_change` | Open two documents; switch the active document; replace the active view's document (generation change); switch between two windows of one document; open another document and check the new surface is bound once; open a document with pattern resources and switch back; repeat while a filter commit runs on the new view. | The dock rebinds immediately when no filter commit is running and refreshes each panel once (one Layers refresh); with a running commit the bind is deferred until it lands; the Adjustments pattern button and Layers pattern action follow the pattern resources across the switch. | `tst_edit_refresh::aDocumentSwitchRebindsTheDock`, `tst_edit_refresh::aNewDocumentRefreshesLayersOnce` |
| `panel_edit_in_place` | Commit a layer edit on the active document; separately trigger a region-preview tick; let the 120 ms pass run. | Panel contents refresh and no panel is re-bound (retarget count flat) for either the edit or the preview. | `tst_edit_refresh::anEditRefreshesTheDockInPlace` |
| `panel_layers_once` | Take the Layers refresh count, commit one notifying edit, wait past the debounce. | The Layers count increases by exactly one. | `tst_edit_refresh::aCommittedEditRefreshesLayersOnce` |
| `panel_background_change` | Change a background document, then commit a notifying edit on the active document; wait past the debounce. | The active Layers panel still refreshes for the background change and exactly once more for the active edit. | `tst_edit_refresh::aCommittedEditRefreshesLayersOnce` |
| `panel_no_rebind` | Take the dock retarget count, commit one notifying edit, wait past the debounce. | The retarget count is unchanged. | `tst_edit_refresh::anEditDoesNotRebindTheDock` |
| `panel_inactive_close` | Open two documents, make one active, close the other. | The dock rebind count is unchanged and no panel is re-bound. | `tst_edit_refresh::anInactiveCloseDoesNotRebindTheDock` |
| `panel_bound_close` | Start a delayed filter commit, switch away and back so the bind is deferred, then close the still-bound inactive document before the commit lands. | The dock rebinds before the bound view is freed; closing does not leave a dangling panel view. | `tst_edit_refresh::aDeferredBindSurvivesClosingTheBoundDocument` |
| `panel_stroke_refresh` | Paint a stroke on the Background layer, wait mid-stroke, commit it, wait past the debounce. | Layers does not rebuild mid-stroke; after the commit Layers and History refresh; Histogram bins, Navigator thumbnail, and Channels thumbnail reflect the stroke. | `tst_edit_refresh::aStrokeCommitRefreshesPanels` |
| `contour_cache_hit` | Select a rectangle, warm the contour, commit a filter that does not write the selection. | The contour compute count and the canvas contour-set count are unchanged. | `tst_selection_preview::anEditKeepsTheCachedContour`, `pictura-app::selection_contour_cache_reuses_a_revision` |
| `contour_stroke_commit` | Select a rectangle, warm the contour, paint and commit a stroke without writing the selection. | The contour compute count is unchanged. | `tst_edit_refresh::aStrokeCommitDoesNotRetraceTheContour` |
| `contour_invalidate` | Select one rectangle, open a second window of the same document (`window.arrange.new.window.for.file`), then commit a different selection (and separately deselect); inspect both canvases (`windowCanvasForTest`). | The contour is retraced for the new mask and both canvases show it; deselecting clears the cache and both canvas outlines. | `tst_selection_preview::aSelectionChangeRetracesTheContour`, `pictura-app::selection_contour_cache_recomputes_after_a_selection_change`, `pictura-app::selection_contour_cache_clears_without_a_selection` |
| `ants_partial_region` | Show a small selection on a large canvas and a Move-tool outline; show the window/canvas, wait for exposure, then wait for one ants tick. | The last paint rect covers the selected outline and Move-outline bounds plus the stroke and, for a selection that does not span the canvas, is smaller than the canvas. | `tst_selection_preview::antsTickRepaintsOnlyTheOutline` |
| `cr_preview_coalesced` | Call `preview_layers_opacity` several times faster than 120 ms, then let the timer fire. | The command registry refresh count increases by at most one. | `tst_edit_refresh::previewTicksCoalesceTheRegistry` |
| `cr_preview_commit_unaffected` | Trigger region presentations, then commit a notifying edit before the debounce fires. | The command registry refreshes synchronously once for the edit. | `tst_edit_refresh::aCommitRefreshIsNotDelayedByPreviews` |
