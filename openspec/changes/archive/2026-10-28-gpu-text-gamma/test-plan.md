# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `tg_rasterize` | Rasterize a type layer at 100 % and 50 % opacity with the default gamma and compare the raster composite against the live type composite | Stored alpha is the curve of the coverage within one level; the composite alpha is within two levels at both opacities | `pictura-render::rasterized_type_composites_as_live_type`, `pictura-render::materialize_bakes_the_curve`, `pictura-render::materialize_bakes_the_curve_when_opacity_is_zero` |
| `tg_gpu_proxied` | Composite a document with a proxied type layer at the default γ 1.45 through `composite_active(doc, true)` | `Backend::Gpu`, every channel within ±1 LSB of `composite_rgba`, and the `type_source` decline count does not increase | `pictura-render::proxied_type_layer_at_default_gamma_matches_cpu` |
| `tg_gpu_gammas` | Loop γ 1.00, 1.45, 2.20, and off over the proxied type and gated scenes | Every instance matches the CPU oracle within ±1 LSB | `pictura-render::proxied_type_gamma_values_and_gates_match_cpu` |
| `tg_gpu_gates` | Composite a proxied type layer with opacity 180, Fill 96, and an enabled raster mask on the GPU | Every channel matches the CPU oracle within ±1 LSB | `pictura-render::proxied_type_gamma_values_and_gates_match_cpu` |
| `tg_gpu` | Ask `composite_gpu` for a document whose only text is a type layer with no raster proxy | `Err(GpuError::UnsupportedText)`; the CPU path composites it | `pictura-render::proxy_less_type_layer_declines_as_type_source`, `pictura-render::proxy_less_type_layer_composites_live_coverage`, `pictura-render::gpu_declines_a_proxy_less_type_layer` |
| Every declining content route has a reason | Run `check_supported` on one document per declining content route | Each returns its own `GpuError` with no device | `pictura-render::every_declining_route_names_its_reason` |
| A proxied type layer stays eligible with the gamma on | Run `check_supported` on a type layer with a raster proxy at the default gamma | Accepted | `pictura-render::proxied_type_layer_with_gamma_is_eligible` |
| A channel-less type layer declines as a type source | Run `composite_gpu` on a proxy-less type layer and read the decline counters | `UnsupportedText`; the `type_source` count increases, `type_source` is present in `DECLINE_REASONS`, and `unsupported_text` is absent | `pictura-render::type_source_decline_is_counted` |
| Effects win over the content route | Run `composite_gpu` on a fill layer carrying an enabled drop shadow | `Err(GpuError::UnsupportedLayerEffect)` | `pictura-render::gpu_reports_the_effect_for_a_fill_layer` |
| The CPU oracle is unchanged | Review the change's diff for any edit to the CPU compositing path (`composite_rgba`, `blend_into_row`, `text_gamma_alpha`) | No CPU compositing code changes; existing CPU text-gamma tests still pass | manual: the guarantee is a no-diff property of the CPU oracle, not an output this change’s tests can distinguish from the pre-change code |
| A proxied type layer inside a group matches the CPU | Composite isolated and pass-through groups with a proxied type child at each gamma | Every instance matches the CPU oracle within ±1 LSB and stays on the GPU | `pictura-render::proxied_type_in_groups_matches_cpu` |
| A region composite with a proxied type layer matches the full slice | Composite a proxied type layer region on the CPU and GPU and compare it with the full composite slice | Each region equals the corresponding full-composite slice; the GPU region reports `Backend::Gpu` and the CPU region reports `Backend::Cpu` | `pictura-render::region_matches_full_slice`, `pictura-render::cpu_region_matches_full_slice` |
| A proxied type layer in every GPU blend mode matches the CPU | Composite proxied type layers in `Multiply` and `Hue` at the default gamma | Every instance matches the CPU oracle within ±1 LSB and stays on the GPU | `pictura-render::proxied_type_blend_modes_match_cpu` |
