# Test Plan — filter-parameter-descriptor

One row per scenario in `specs/imaging/filter-app-ui/spec.md`. Rows name an existing test or a test `tasks.md` creates; `(existing)` marks the former.

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| Each known kind maps to its default filter | For every kind the descriptor records, map it with an empty slot list | A filter is produced, carrying that kind's documented defaults | `pictura-app::every_kind_defaults_from_empty_and_rejects_wrong_arity` (existing), `pictura-app::mapping_defaults_come_from_the_descriptor` |
| A parameter list overrides the defaults | Map `gaussian-blur` with a one-value slot list | The radius is the supplied value, not the default `5.0` | `pictura-app::parameter_values_override_defaults` (existing) |
| A wrong-arity parameter list is refused | Map a known kind with a slot list of the wrong length | No filter is produced and the document is unchanged | `pictura-app::wrong_arity_is_refused_without_mutation` (existing) |
| Unknown kind is refused | Map a kind the descriptor does not record | No filter is produced and the document is unchanged | `pictura-app::every_kind_defaults_from_empty_and_rejects_wrong_arity` (existing) |
| `fpd_arity` | For every recorded kind, map its descriptor's default vector, then the same with one more zero, and — when the slot count is greater than one — one fewer | The default vector maps to a filter; the longer list and (when the slot count exceeds one) the shorter list are refused and the document is unchanged | `pictura-app::arity_is_the_descriptor_slot_count`, `pictura-app::every_kind_defaults_from_empty_and_rejects_wrong_arity` (existing), `tst_filter_menu::everyRowsKindIsSupportedAndArityMatches` (existing, extended) |
| `fpd_variable_lists` | Map `lighting-effects` with rigs of 1 and 16 lights, and each Blur Gallery kind with its variable pin, path and spin lists | Each documented list maps to a filter; a partial light, 17 lights, or a record list that does not match its count is refused | `pictura-app::lighting_maps_a_rig_of_any_size_up_to_the_cap`, `pictura-app::field_blur_defaults_and_accepts_a_variable_pin_list`, `pictura-app::iris_blur_defaults_and_accepts_a_variable_pin_list`, `pictura-app::tilt_shift_defaults_and_accepts_a_variable_pin_list`, `pictura-app::path_blur_defaults_and_accepts_variable_paths`, `pictura-app::spin_blur_defaults_and_accepts_spins`, `pictura-app::blur_gallery_combines_each_effects_records` (all existing) |
| `fpd_dialog_defaults` | Open every kind edited by the shared parameter controls and read its controls, their order, their ranges, their choices and their opening values | The dialog's controls and values are the ones the descriptor records | `tst_filter_menu::everyRowOpensOnItsDefaults` |
| `fpd_mapping_defaults` | Map every recorded kind with an empty slot list, and map it again with the descriptor's default vector; read both filters | The two filters are equal, and for a kind whose engine supplies a default the descriptor-built filter equals that default | `pictura-app::mapping_defaults_come_from_the_descriptor`, `pictura-app::engine_defaults_agree_with_the_descriptor` |
| `fpd_commit_defaults` | Map Lens Blur with an empty slot list, then commit the dialog's opening values | The mapped filter opens on Faster, while the committed and stored slots carry More Accurate | `tst_lens_blur_dialog::fasterStillCommitsMoreAccurate`, `pictura-app::lens_blur_defaults_and_refuses_a_missing_depth_map` (both existing) |
| `fpd_cpp_rows` | Build the filter menu and compare every menu row against the descriptor the bridge returns; also resolve the descriptor with no menu row by kind | Each menu row's kind, label, menu path, controls, slot counts, ranges, choices, default values, dialog kind, map-after-OK flag and preview flags equal the descriptor's for the same kind; the no-menu-row descriptor is absent from `filterCommands()` but resolves through `filterCommandForKind` | `tst_filter_menu::rowsComeFromTheRustDescriptor`, `tst_filter_menu::everyRowsKindIsSupportedAndArityMatches` (existing, extended) |
| `fpd_whole_layer` | Ask every recorded kind whether it resolves against the whole layer, and ask for a kind the descriptor does not record | Each answer is the descriptor's flag, and the unrecorded kind is not a filter kind | `pictura-app::whole_layer_comes_from_the_descriptor`, `pictura-app::descriptor_covers_every_mapping_arm`, `pictura-app::positional_kinds_preview_the_whole_layer` (existing) |
| `fpd_dialog_kind` | Choose each kind that owns a dialog from the filter menu and read the window that opens; then choose a parameterized kind with no dedicated dialog | The dedicated dialog opens for the first, the shared parameter dialog for the second | `tst_filter_menu::eachKindOpensTheDialogItsDescriptorNames`, `tst_lens_flare_dialog::menuOpensItAndCommitsTheFlare` (existing), `tst_lighting_effects_dialog::menuCommitsTheRig` (existing), `tst_picture_frame_dialog::menuOpensItAndCommitsTheFrame` (existing), `tst_reduce_noise_dialog::menuOpensItAndCommits` (existing), `tst_blur_gallery_dialog::menuCommitsAndCancelRestores` (existing), `tst_liquify_dialog::okCommitsOneFilterState` (existing) |
| A parameterised filter opens its dialog | Choose `Filter > Blur > Gaussian Blur…` | A dialog opens with a Radius control and a preview thumbnail | `tst_filter_menu::dialogCollectsParameterSlots`, `tst_filter_menu::parameterizedCommandOpensDialogAndCommits` (both existing) |
| The preview zoom is independent of the document | Click the dialog's zoom-in or zoom-out control | The percentage readout steps and only the thumbnail scales; the document pixels and zoom are unchanged | `tst_filter_menu::zoomChangesOnlyThumbnailAndLabel` (existing) |
| The preview shows the current canvas section | Open a dialog while the canvas views a particular section at a zoom | The thumbnail shows that section at the seeded zoom, not the whole image shrunk to fit | `tst_filter_menu::zoomedOutPreviewDrawsAReducedCopy` (existing) |
| Radial Blur shows the Blur Center instead of a thumbnail | Open `Filter > Blur > Radial Blur…` and read the dialog values | Amount, Blur Method, Quality and a draggable Blur Center, no thumbnail; the centre's x and y are slots 3 and 4 | `tst_filter_menu::radialBlurCarriesBlurCenter` (existing), `pictura-filters::radial_center_moves_the_origin` (existing) |
| A parameterless filter applies directly | Choose `Filter > Sharpen > Sharpen` | The filter applies immediately with no dialog | `tst_filter_menu::parameterlessAppliesDirectly` (existing) |
| An implemented entry is enabled and dispatches | Open the Filter menu on an unlocked normal pixel layer and choose an implemented entry | The entry is enabled and runs its filter or dialog | `tst_filter_menu::implementedEntriesAreEnabled` (existing) |
| Dialog entries carry an ellipsis | Show the Filter menu | Every dialog-opening entry ends with `…`; every parameterless entry does not | `tst_filter_menu::dialogEntriesEndWithEllipsis` (existing) |
| An unimplemented entry stays disabled | Open the Filter menu | Entries with no engine kernel, such as `Filter > Video > De-Interlace`, are disabled | `tst_filter_menu::stubEntriesStayDisabled` (existing) |
| No pixel layer disables the filters | Make the active layer missing or not an unlocked normal pixel layer | The filter commands are disabled | `tst_filter_menu::nonPixelActiveLayerDisablesFilters` (existing) |
