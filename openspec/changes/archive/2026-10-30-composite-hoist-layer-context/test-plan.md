# Test plan

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| `ck_native` | Build a 16-bit and a 32-bit document with a retained native plane, including a layer whose store omits one channel; composite through the resolved per-layer state and through the test-only legacy source path. | Both composites are byte-identical, including the per-channel 8-bit fallback. | `pictura-render::ctx_high_depth_matches_legacy` |
| `ck_mask` | Composite a feathered raster mask, a feathered vector mask, a plain vector mask, and a native raster combined with a vector mask, each through the context and the legacy switch. | Every output byte matches, including the 8-bit `(r*v+127)/255` combine and the native `f32` product. | `pictura-render::ctx_masks_match_legacy` |
| `ck_const` | Composite a layer with opacity 128, fill 64, a non-default Blend If range, and a type-tool curve through the context and the legacy switch. | Every output byte matches. | `pictura-render::ctx_constants_match_legacy` |
| `ck_skip` | Composite a layer whose rect covers the canvas but whose alpha is zero over most pixels; read the test-only mask-sample counter. | Output is byte-identical to the legacy composite and the counter records zero samples on zero-alpha pixels. | `pictura-render::zero_alpha_skips_mask` |
| `ck_skip_cover` | Composite a knockout layer with zero alpha at a pixel; inspect the coverage mask. | The coverage flag stays false and the backdrop is unchanged. | `pictura-render::zero_alpha_does_not_mark_cover` |
| `ck_legacy` | For every layer blend mode, evaluate random source/backdrop samples, including a `fill != 255` layer, through the context kernel and the legacy per-pixel switch. | Every channel is bit-for-bit equal in `Px` `f32` `to_bits()` and in the final `u8`. | `pictura-render::ctx_kernel_matches_legacy` |
| `ck_callers` | Composite a corpus covering pixel, isolated group, adjustment, solid/gradient/pattern fill, smart source, smart filter, and type source, each with the legacy switch on and off. | Each route's bytes match. | `pictura-render::ctx_route_callers_match_legacy` |
| `ck_oracles` | Run the document, clipping, knockout, adjustment, merge, native-depth, and reference-fixture oracle suites. | Every output buffer and encoded file is unchanged. | `pictura-render::merge_down_matches_imagemagick_for_every_supported_mode`, `pictura-render::knockout_composite_matches_psd_tools`, `pictura-render::native_depth_edit_survives_a_psd_round_trip`, `pictura-render::resize_document_preserves_structure_and_composite`, `pictura-render::psd_tools_composites_a_clipping_group_alike`, `pictura-render::psd_tools_reads_encoded_color_balance`, `pictura-render::merge_down_matches_committed_imagemagick_fixture` |
| `ck_region` | Composite the same document in bands, over a sub-region, and whole; compare samples. | Corresponding samples are byte-identical. | `pictura-render::a_region_no_effect_reaches_composites_alone_and_exactly`, `pictura-render::short_region_composite_matches_serial`, `pictura-render::banded_compositing_equals_one_canvas`, `pictura-render::banding_with_a_short_type_layer_equals_one_canvas`, `pictura-render::parallel_row_equals_sequential_row` |
| Profile protocol (not a spec scenario) | Run the ignored 4000² profile for Normal without a mask, Multiply, feathered raster mask, vector mask, and a full-canvas type layer. | Prints one timing per scenario. | `pictura-render::cpu_composite_profile_4000` |
| Before/after timing (not a spec scenario) | Run the profile on master and on the branch, same machine and build profile. | Recorded table in the PR body; no automated threshold because wall time is machine-dependent. | manual: wall time is machine-dependent and the change sets no fixed threshold |
