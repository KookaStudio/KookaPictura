# Test plan

The test names below are the contract for this change. Rust tests run under nextest; the GPU parity checks are `#[ignore]`d device tests and run in the `gpu-parity` CI job.

## imaging/filter-catalogue

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `fc_catalogue_complete` | Enumerate the catalogue and compare it with `FilterKind::ALL`. | One row per kind, no duplicate, each row's kind matches its position. | `pictura-filters::catalogue_covers_every_kind`, `pictura-filters::catalogue_rows_match_kind_order` |
| `fc_catalogue_missing_row` | Remove a row from the macro table in a scratch copy and compile. | The filter crate does not compile. | manual: negative compile check; the macro table is the only source of `FilterKind` and each row names a required spec const |
| `fc_facts_round_trip` | Compare the representative facts for Gaussian Blur, Solarize, Smart Blur, and the moved-kernel fixture; the all-row loop is a consistency check that each row's accessors agree. | The representative facts equal today's values; the all-row accessors agree with their row. | `pictura-filters::catalogue_rows_round_trip_their_facts`, `pictura-filters::filter_reports_its_own_facts`, `pictura-filters::generated_variant_list_names_every_variant_once`, `pictura-render::moving_kernel_fixture_matches_the_moving_set` |
| `fc_defaults_build` | Build every row from its canonical defaults and from an empty slot list. | Both produce the same filter, and a wrong-length fixed list is refused. | `pictura-filters::every_catalogue_row_builds_from_its_defaults`, `pictura-app::every_kind_defaults_from_empty_and_rejects_wrong_arity` |
| `fc_defaults_in_range` | Check every row's defaults against its parameter schema under each control's own semantics. | Every scalar, colour, placement, matrix, and curve default is in range. | `pictura-filters::catalogue_defaults_are_in_range` |
| `fc_add_noise_range` | Read the Add Noise row's amount range; apply amount 0.1 and 0.0. | The row says `0.1..400`; 0.1 succeeds; 0.0 is refused. | `pictura-filters::add_noise_amount_has_one_range` |
| `fc_surface_range` | Read the Surface Blur threshold range; apply threshold 1 and 0. | The row says `1..255`; 1 succeeds; 0 is refused. | `pictura-filters::surface_blur_threshold_has_one_range` |
| `fc_range_refused` | Build and apply Add Noise and Smart Blur, and build Adaptive Wide Angle, with values outside their row ranges. | The build refuses the value or the engine returns `InvalidParams`; the buffer is unchanged. | `pictura-filters::out_of_range_slot_is_refused` |
| `fc_fixed_build` | Build each fixed-shape kind from its defaults and from an explicit slot list. | The row's constructor produces the documented filter; wrong lengths are refused. | `pictura-app::parameter_values_override_defaults`, `pictura-app::every_kind_defaults_from_empty_and_rejects_wrong_arity` |
| `fc_variable_build` | Build Lighting Effects with several light counts and each Blur Gallery kind with its documented list shapes. | Each documented shape maps; malformed shapes and counts above the cap are refused. | `pictura-app::lighting_maps_a_rig_of_any_size_up_to_the_cap`, `pictura-app::field_blur_defaults_and_accepts_a_variable_pin_list`, `pictura-app::iris_blur_defaults_and_accepts_a_variable_pin_list`, `pictura-app::tilt_shift_defaults_and_accepts_a_variable_pin_list`, `pictura-app::blur_gallery_combines_each_effects_records`, `pictura-app::path_blur_defaults_and_accepts_variable_paths`, `pictura-app::spin_blur_defaults_and_accepts_spins` |
| `fc_resource_build` | Build Lens Blur, Displace, Liquify, Adaptive Wide Angle, and Vanishing Point with kept ids and with stale ids. | Kept ids resolve; stale ids are refused. | `pictura-app::lens_blur_defaults_and_refuses_a_missing_depth_map`, `pictura-app::displace_reads_its_slots_and_refuses_a_map_it_no_longer_has`, `pictura-app::liquify_names_a_kept_mesh_and_refuses_one_it_no_longer_has`, `pictura-app::adaptive_wide_angle_reads_its_slots_and_refuses_an_unkept_set`, `pictura-app::vanishing_point_names_a_kept_edit_and_refuses_one_it_no_longer_has` |
| `fc_gpu_parity_list` | Compare the GPU parity fixture's kind set with the catalogue's accelerated and CPU-preferred kinds. | The two sets are equal; every accelerated row has a case and no other kind has one. | `pictura-render::accelerated_parity_fixture_matches_the_catalogue` |
| `fc_gpu_plan` | Plan a representative filter for each accelerated row and for an unsupported row; for Radial Blur use Zoom and check Spin falls back. | Accelerated rows' representatives yield a plan; Radial Blur Spin yields none; unsupported rows yield none. | `pictura-render::gpu_plan_matches_the_row_policy` |
| `fc_menu_rows` | Build the shell filter menu and compare it with the menu-visible catalogue rows. | Each row appears once with its path and label; non-menu rows do not appear. | `tst_filter_menu::rowsComeFromTheRustDescriptor`, `tst_filter_menu::everyRowsKindIsSupportedAndArityMatches` |
| `fc_gallery_order` | Build the gallery categories and inspect names, counts, and the first rows. | Artistic 15, Brush Strokes 8, Distort 3, Sketch 14, Stylize 1, Texture 6; inner order follows the ranks. | `tst_filter_gallery::categoriesFollowCs6` |
| `fc_hdr_toning_engine_only` | Enumerate the catalogue and the filter command surfaces for HDR Toning. | One catalogue row; no menu entry, gallery entry, or supported scriptable filter command. | `pictura-filters::hdr_toning_is_engine_only`, `pictura-app::hdr_toning_is_not_a_filter_command`, `pictura-app::engine_only_kinds_are_not_filter_commands` |
| `fc_script_commands` | Run the script catalogue membership test against the filter catalogue. | Every menu row resolves to a command definition; the three unwired leaves stay unwired. | `pictura-script::every_wired_filter_has_a_definition` |
| `fc_ffi_mirror` | Ask the app bridge for its descriptor rows and compare them with the catalogue. | One row per catalogue row, same order, path, label, params, dialog policy, and gallery rank. | `pictura-app::filter_descriptors_mirror_the_catalogue`, `tst_filter_menu::rowsComeFromTheRustDescriptor` |
