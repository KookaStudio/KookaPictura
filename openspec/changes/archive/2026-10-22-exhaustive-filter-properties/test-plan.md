# Test Plan — exhaustive-filter-properties

One row per scenario in the change's four spec deltas. Coverage names the test that proves the scenario's THEN: `pictura-filters::…` and `pictura-render::…` are Rust `#[test]` functions under those crates; the three compile-fail rows are checked by the compiler, which no std test can observe. The per-variant tests need one default instance per `Filter` variant, which the change assembles in `crates/pictura-filters/tests/`.

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| `fef_new_variant_needs_every_fact` | Add a variant to `Filter` and to the generated list, and leave one fact undecided | The crate does not compile; the compiler reports the variant whose match arm is missing | manual: a compile-fail check needs a scratch edit to the enum and a compiler invocation, which no std test observes |
| `fef_filter_reports_its_facts` | Ask a Gaussian Blur of radius 16 and a Solarize for their facts | Gaussian Blur: moves alpha, apron 16, native engine. Solarize: fixed alpha, the default apron of 128 pixels | `pictura-filters::filter_reports_its_own_facts` (new) |
| `fef_variant_list_covers_type` | Read the generated variant list | One entry per variant, no name repeated, each entry naming its engine | `pictura-filters::generated_variant_list_names_every_variant_once` (new) |
| `fef_variant_list_drift_fails` | Add a variant to `Filter` without adding it to the generated list | The crate does not compile, naming the uncovered variant | manual: a compile-fail check needs a scratch edit to the enum and a compiler invocation, which no std test observes |
| `fef_engine_matches_implementation` | Apply every variant in the generated list to a buffer | Each is applied by the engine its entry names and none is refused as unsupported; no variant is applied by both or neither | `pictura-filters::each_variant_is_applied_by_the_engine_its_property_names` (new) |
| `fef_missing_implementation_fails` | Add a variant to `Filter` and to the generated list, and leave it out of both engines' implementations | The crate does not compile; the compiler reports the match that omits the variant | manual: a compile-fail check needs a scratch edit to the enum and a compiler invocation, which no std test observes |
| `fef_mapping_covers_every_variant` | Run the oracle mapping test | Exactly one row per variant in the generated list; a missing or duplicate row fails | `pictura-filters::mapping_table_holds_one_row_per_variant` (new) |
| `fef_mapping_row_states_oracle` | Run the oracle mapping test | Every row names an ImageMagick operator with a tolerance, or names none and carries a non-empty note stating why it has none | `pictura-filters::every_mapping_row_states_an_oracle_or_states_none` (new) |
| `fef_ported_cases_cover_every_variant` | Run the ported-engine contract test | A case for every variant the generated list assigns to the ported engine; a missing case fails | `pictura-filters::ported_cases_cover_every_ported_variant` (new) |
| `fef_digest_decides_every_variant` | Run the kernel-digest test | Every variant in the generated list either carries a recorded digest or is recorded as having none | `pictura-filters::every_variant_has_a_digest_decision` (new) |
| `fef_moving_fixture_matches_set` | Compare the render crate's moving-kernel fixture against the moving-alpha set | The fixture holds one instance of every variant in the set and none of the others | `pictura-render::moving_kernel_fixture_matches_the_moving_set` (new) |
| Transparency is bit-identical | Filter an unlocked, partly transparent layer with a value kernel | The channel with id `-1` equals the input bit for bit | `pictura-render::value_kernels_leave_alpha_bit_identical` (existing) |
| A moving kernel keeps an opaque layer opaque | Filter an unlocked layer whose alpha is 255 everywhere with a moving kernel | Every alpha sample is still 255 | `pictura-render::moving_kernels_keep_an_opaque_layer_opaque` (existing) |
| Offset moves the layer edge | Offset a half-clear layer to the right with wrap off | The transparent half moves right with the colour and the exposed left columns are opaque | `pictura-render::offset_moves_the_layer_edge_and_fills_what_it_exposes_opaque` (existing) |
| Offset can expose transparency | Offset a layer with wrap off in "Set to Transparent" mode | The exposed area's transparency is 0 while the colour planes take the dialog's Background colour | `pictura-render::offset_in_transparent_mode_exposes_clear_pixels` (new) |
| Every moving kernel moves a soft layer edge | Run each moving filter over a soft-edged disc with a stray speck | The channel with id `-1` differs from the input | `pictura-render::moving_kernels_move_a_soft_layer_edge` (existing) |
| Picture Frame may add opacity | Run Picture Frame on an unlocked layer that is partly transparent | The transparency channel gains the composited border's opacity where the frame covers a clear pixel | `pictura-render::picture_frame_adds_opacity_over_a_clear_pixel` (new) |
| Layer metadata is unchanged | Filter a layer | `rect`, `mask`, `opacity` and `blend` equal their pre-call values | `pictura-render::gaussian_blur_changes_interior_leaves_alpha_and_meta` (existing) |
| Only the region changes | Apply a filter over a region smaller than the layer | Pixels outside the region are bit-identical to their input | `pictura-render::region_apply_matches_full_inside_and_leaves_the_rest` (existing) |
| The region interior matches a full apply | Apply the same filter over the whole layer and over a region expanded by the filter's apron | Pixels at least one apron inside the region match the full apply | `pictura-render::hdr_toning_apron_covers_its_blur_support` (existing) |
| Default routes to the GPU | Apply an accelerated filter with the default `gpuCompute` value on a machine with a usable adapter | The GPU backend runs the filter | `pictura-render::accelerated_filters_match_cpu_within_one_lsb` (existing) |
| Disabling forces the CPU | Apply a filter with `gpuCompute` false | `pictura_filters::apply` runs on the CPU and the reported backend is `Backend::Cpu` | `pictura-render::disabled_gpu_is_byte_identical` (existing) |
| A CPU-faster kernel skips the GPU on a layer | Apply a Gaussian Blur, Unsharp Mask, Median or Maximum to a layer with GPU compute enabled | The layer equals the same filter applied with GPU compute disabled | `pictura-render::cpu_preferred_kernels_skip_the_gpu` (existing) |
| Every moving kernel maps opaque to opaque | Run each filter whose alpha fact is that its kernel moves over a flat 255 grey plane | The plane comes back flat 255 | `pictura-render::moving_kernels_map_opaque_to_opaque` (existing) |
