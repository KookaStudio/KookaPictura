# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `merge_work` | Create overlapping Work Path rectangles, an interior hole and a separate curved contour. Trigger the Path Selection menu item and Undo. | Filled samples and hole agree, the separate curve keeps its handles, and one Undo restores the original. | `tst_merge_shape_components::mergeWorkPath`, `pictura-select::merges_nonzero_overlap_and_keeps_hole_and_curve` |
| `merge_nested` | Overlay two overlapping reverse-winding contours inside a positive enclosing contour; also exercise nested even-odd contours. Compare input and output filled regions and boundaries. | Ambient winding or parity is retained, including the overlap; topology and the 1/256-pixel boundary bound hold. | `pictura-select::preserves_nested_ambient_winding_and_parity`, `pictura-select::compares_effective_boundaries_and_topology`, `pictura-select::accepts_cancelled_work_path_fill` |
| `merge_target` | Select a saved Paths row with a shape layer selected, merge, then target the layer outline and merge with other paths present. | The saved row takes priority; each merge changes only its target, and layer fill rule, styling and flags are retained. | `tst_merge_shape_components::mergeSavedPathAndLayer`, `pictura-select::preserves_even_odd_exclusion` |
| `merge_curved_mask` | Merge overlapping curved layer-mask contours plus an open contour; compare the renderer's pre- and post-merge polylines and filled samples. | Fill topology and boundary displacement meet the stated bound, and the open contour is unchanged. | `pictura-app::merge_curved_mask_preserves_rendered_geometry` |
| `merge_focus` | Focus one contour in an active path containing a separate overlapping group, then merge from the menu with another path present. | Both overlapping groups in the active path merge; the other path stays unchanged. | `tst_merge_shape_components::mergeWholePathWithFocusedContour` |
| `merge_noop` | Create a redo branch, then invoke with no active path, disjoint contours and input beyond the geometry budget. | Geometry and history do not change, and redo remains available. | `tst_merge_shape_components::noMergeWithoutOverlap`, `pictura-select::leaves_disconnected_and_over_budget_inputs_alone` |
| `merge_mask_declined` | In private app Rust fixtures, construct an imported mask with unsupported stored operations and a mask whose normalization would remove its last filled contour; create redo before each attempt. | Both attempts preserve original mask bytes, effective fill, history and redo. A separate fixture compares pre- and post-encode polygon geometry when a gap closes; it does not exercise history or redo. | `pictura-app::declines_unsafe_imported_mask_merge`, `pictura-app::declines_permissive_empty_mask_merge`, `pictura-app::declines_mask_round_trip_that_closes_a_gap` |
