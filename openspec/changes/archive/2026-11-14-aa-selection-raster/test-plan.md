# Test plan — aa-selection-raster

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| `mag_aa` | Close a Magnetic Lasso outline with Anti-alias on, then with it off | On: boundary values strictly between 0 and 255. Off: only 0 and 255. | `tst_selection_aa::magneticAntiAliasCommitsPartialCoverage` |
| `chan_cap_new` | RGB document with 53 extra channels; request New Channel | Refused; channel count and history unchanged. | `pictura-app::new_alpha_refuses_at_cap`, `tst_channels_panel::newChannelDisabledAtCap` |
| `chan_cap_save` | Document at 56 channels; request Save Selection | Refused; no channel added, no history state. | `pictura-app::save_selection_refuses_at_cap` |
| `chan_cap_budget` | Document at 55 channels; add one, then add another | First add succeeds; the second is refused at 56. | `pictura-core::channel_budget_refuses_at_56` |
| `chan_cap_write` | In the new `crates/pictura-codec/tests/psd/channel_budget.rs` integration test, write an RGB document with 53 extras, then one with 54 | 56 total writes; 57 total is rejected. | `pictura-codec::extra_channels_write_at_the_56_channel_limit` |
| `chan_cap_source_mode` | Converted CMYK document (source mode CMYK, three stored composite planes) with 52 extras; request another channel | At 56 total the predicate refuses; counting only three working RGB channels would wrongly allow 53 extras and a 57-channel save. | `pictura-core::channel_budget_uses_the_source_mode` |
| RGBA display alpha is trimmed before the budget | An RGBA (`Document::from_rgba`) document with 52 extras permits one more, then refuses 53 | The post-add save trims the display alpha to three colour channels, so 56 is reached at 53 extras | `pictura-core::channel_budget_counts_the_trimmed_rgba_alpha` |
| A constructed zero-channel Multichannel cannot add | `Document::new(ColorMode::Multichannel)` has no composite colour channel | The predicate refuses rather than reporting 56 free slots | `pictura-core::channel_budget_rejects_a_constructed_multichannel` |
| `sm_aa_fractional` | Rasterise an AA ellipse and an AA polygon | Boundary pixels hold values strictly between 0 and 255; interior 255; exterior 0. | `pictura-select::ellipse_aa_has_fractional_edge`, `pictura-select::polygon_aa_has_fractional_edge` |
| `sm_aa_off_binary` | Rasterise the same primitives with Anti-alias off | Every value is 0 or 255. | `pictura-select::ellipse_aa_off_is_binary`, `pictura-select::polygon_aa_off_is_binary` |
| `sm_aa_contour` | Extract the 50 %-coverage contour of an AA primitive | Contour lies within 1 px of the analytic ellipse / drawn polygon. | `pictura-select::aa_contour_follows_the_primitive`, `pictura-select::ellipse_aa_contour_follows_the_primitive`, `tst_selection_aa::polygonalAntiAliasFollowsThePolygon` |
| `sm_aa_order` | Commit an AA primitive with Feather > 0 and an Add, Subtract, or Intersect mode | The result equals feathering the AA primitive before the combine operation, not feathering a binary primitive. | `tst_selection_aa::antiAliasCombineAndFeather`, `pictura-select::aa_applied_before_feather` |
| `sm_aa_existing` | Build an AA primitive for a New, Add, Subtract, or Intersect commit over an existing selection | The existing stored coverage is unchanged while the primitive is built; only the chosen combine operation changes it. | `tst_selection_aa::antiAliasCombineAndFeather`, `pictura-select::aa_leaves_existing_selection_unchanged` |
| `sm_aa_clip` | Rasterise an AA ellipse and an AA polygon that extend past the canvas | Coverage outside the canvas is absent; the clipped row or column keeps its clipped value; only the in-canvas shape boundary is softened. | `pictura-select::aa_clips_at_the_canvas_edge` |
| `sm_aa_rect` | Use the Rectangular Marquee and inspect its options | Mask is binary; no Anti-alias control. | `pictura-select::rect_selects_half_open_and_clips`, `tst_selection_aa::optionsEnableAntiAlias` |
| Contiguous flood stops at a colour boundary | Seed the wand in a red region touching blue with a tolerance that excludes blue | Only connected red pixels are selected. | `pictura-select::magic_wand_contiguous_and_global` |
| Global mode selects disconnected matches | Run the wand non-contiguous on two identical patches | Both patches are selected. | `pictura-select::magic_wand_contiguous_and_global` |
| Tolerance rejects distant colours | Anti-alias off; neighbour differs by more than tolerance | Neighbour is not selected. | `pictura-select::magic_wand_rejects_tolerance_and_bounds`, `pictura-select::wand_aa_off_is_binary` |
| Out-of-bounds seed errors | Seed outside the image | Error returned, no panic. | `pictura-select::magic_wand_rejects_tolerance_and_bounds` |
| The tool combines with the current selection | Existing selection, Add mode, wand click | Union committed in one undo state; the extended `wandAntiAliasFringe` asserts the Add union and exactly one history state. | `tst_selection_aa::wandAntiAliasFringe` |
| `wand_aa_fringe` | AA on; boundary pixel at distance between tolerance and tolerance + width, where width = max(0.5 × tolerance, 1.5) | Pixel coverage is strictly between 0 and 255; inside stays 255; at or beyond tolerance + width stays 0. | `pictura-select::wand_aa_grades_boundary`, `tst_selection_aa::wandAntiAliasFringe` |
| `wand_aa_low_tolerance` | AA on with Tolerance 1; neighbour at Chebyshev distance 2 | Coverage is strictly between 0 and 255; distance 0 stays 255; distance 3 or more stays 0. | `pictura-select::wand_aa_low_tolerance_fringes` |
| `wand_aa_off` | AA off, or Tolerance 0 with AA on | Every coverage value is 0 or 255. | `pictura-select::wand_aa_off_is_binary`, `pictura-select::wand_aa_zero_tolerance_is_binary` |
| `wand_aa_global` | Non-contiguous wand with AA on | Each matched region gets its own fringe; gaps stay 0. | `pictura-select::wand_aa_global_fringes_each_region`, `tst_selection_aa::wandAntiAliasGlobalFringe` |
| `wand_aa_options` | Show the Magic Wand options bar | Anti-alias enabled; Sample All Layers disabled with a reason. | `tst_selection_aa::optionsEnableAntiAlias` |
