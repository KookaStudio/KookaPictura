# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `zero_opacity_canvas` | Select two layers with distinct opacity values and tap 0 twice on the Move canvas. Undo. | Both values reach zero without changing Fill. One Undo restores both originals. | `tst_layer_zero_shortcuts::canvasOpacity` |
| `zero_fill_tree` | Select a layer and send two synthetic Shift+`Qt::Key_0` presses to the Layers tree. Undo. | Fill reaches zero in one step. Opacity retains its value. | `tst_layer_zero_shortcuts::treeFill` |
| `zero_eligibility` | Try both sequences on Background and fully locked layers. Try Fill, then Opacity twice on a group. | Only the first group opacity gesture adds a history state. | `tst_layer_zero_shortcuts::eligibilityAndNoOp` |
| `numeric_single` | Press each standalone digit with and without Shift and wait for it to resolve. | Its mapped value commits once. Value and history stay unchanged before timeout. | `tst_layer_zero_shortcuts::singleDigits` |
| `numeric_pair` | Enter 05, 54 and 99 on both paths, including a keypad pair, then Undo. | Each exact value commits once without a standalone prefix edit. Undo restores the prior value. | `tst_layer_zero_shortcuts::exactPairs` |
| `zero_ignore` | Hold a digit, wait between two digits, switch Shift state between presses before timeout, deliver a different-mode digit after the deadline while the event loop is stalled, and interrupt with a non-digit. Wait for each pending gesture to resolve. | A held digit resolves only once; slow digits resolve separately. A Shift change before the deadline discards the first digit and only the second resolves; after the deadline both resolve independently. An interrupted prefix never commits; values and history reflect only the resolved gestures. | `tst_layer_zero_shortcuts::interruptedSequence` |
| `zero_context` | Arm a digit, change focus, document, selection, tool or pointer context, restore it, then let the timeout expire. | No stale edit or history entry appears, including after switching away and back. | `tst_layer_zero_shortcuts::contextChanges` |
| `numeric_registered` | Press a layer digit, a digit assigned to a Qt shortcut, then another layer digit. Repeat with the registered action entering a nested event loop that spans the first digit's deadline. | The Qt action runs, including across the deadline, without resolving the intercepted prefix; only the last digit's standalone value is applied. | `tst_layer_zero_shortcuts::registeredNumericShortcut` |
| `numeric_paint` | With the Brush tool and canvas active, send plain and shifted digit sequences. | Layer values and history stay unchanged. | `tst_layer_zero_shortcuts::paintingCanvas` |
| `zero_modifiers` | Send Ctrl, Alt and Meta zero combinations, including Ctrl+0 and Ctrl+Alt+0, alone and between plain zeros. Start the final plain zero → Ctrl+Alt+0 → plain zero sequence from a non-100% opacity and wait for the trailing zero to resolve. | Modified keys never form a layer pair; registered Ctrl+0 and Ctrl+Alt+0 commands still act. The final standalone zero sets opacity to 100% once and adds one history entry; the discarded prefix adds none. | `tst_layer_zero_shortcuts::modifiedKeys` |
| `zero_transform` | Begin a pending transform and send both gestures on the Move canvas and Layers tree; use a transform key afterwards. | Layer properties and history stay unchanged by the gestures, and the transform key works. | `tst_layer_zero_shortcuts::pendingTransform` |
| `zero_editor` | Enter 00 into the Layers opacity field without committing. | The editor receives the digits without a shortcut history entry. | `tst_layer_zero_shortcuts::editorInput` |
| Native numeric keys and keypad | On US and Finnish layouts, focus the Move canvas or Layers tree and try Shift+05, Shift+99 and Shift+00. Try standalone 5 and 0 and a keypad 54. | Fill reads 5%, 99%, and 0%. Opacity reads 50%, 100%, and 54%. Undo each gesture once. | manual: Synthetic Qt events cannot reproduce native shifted keyboard translation. |
