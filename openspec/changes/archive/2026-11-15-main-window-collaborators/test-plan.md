# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `mwc_forwarders_delegate` | Construct the shell, obtain `DocumentRegistry` through the frame's `documentRegistry()` hook, add a document through the registry, then read the frame's document hooks. | The frame's `documentCount`/`viewAt`/`activeView` return the registry's state; no second document list exists on the frame. | `tst_document_registry::frameForwardsDocuments` |
| `mwc_no_facade` | Inspect the production translation units of the four collaborators. | None names `PicturaMainWindow` and none includes `frame.h`; behavior is not delegated back to the frame. | `check-shell-seams::check_collaborator_tus` |
| `mwc_registry_standalone` | Construct `DocumentRegistry` with a parent widget and no frame; add, activate, float, dock, tile, reorder, and remove documents. | Each operation succeeds and emits the documented change signal. | `tst_document_registry::addActivateFloatDockTileRemove` |
| `mwc_removal_notifies` | Construct `DocumentRegistry` with a stub owner connected to `aboutToRemoveDocument`; remove a document whose view that owner still holds (the smart-object/recovered cleanup path in miniature). | The owner's cleanup runs before the document is destroyed. | `tst_document_registry::removingADocumentNotifiesOwners` |
| `mwc_panel_host_standalone` | Construct `PanelHost` with a stub document area and no frame; build the panels, create/move a column, toggle a panel, apply a workspace layout. | The panel set exists, the column operations succeed, and the workspace layout is applied and observable. | `tst_panel_host::buildColumnsToggleAndWorkspace` |
| `mwc_files_standalone` | Construct `ImportSaveCoordinator` with a `DocumentRegistry` and no frame; save a small document to a temporary PSD/PSB, reopen it, and read the recent list. | The file round-trips, the reopened document is in the registry, and the path is first in the recent list. | `tst_import_save_coordinator::saveOpenAndRemember` |
| `mwc_menu_standalone` | Construct `MenuRegistrar` with the collaborators, a stub chrome registrar, and a stub `MenuRuntime`, then build a menu bar. | The menu bar carries the expected top-level menus and a document-dependent command reports its enabled/checked state. | `tst_menu_registrar::buildsMenuWithoutFrame` |
| `mwc_panels_no_frame` | Search production files under `crates/pictura-app/cpp/panels/` for `frame.h` and `PicturaMainWindow`. | No match. | `check-shell-seams::check_panel_tus` |
| `mwc_menus_no_frame` | Search the registrar/menu translation units for `frame.h` and `PicturaMainWindow`. | No match. | `check-shell-seams::check_menu_tus` |
| `mwc_collab_headers_clean` | Search the four collaborator headers for `#include "frame.h"`. | No match. | `check-shell-seams::check_collaborator_headers` |
| `mwc_guard_panels` | Run the shell-seam guard with a synthetic panel TU that includes `frame.h` or names `PicturaMainWindow`. | The guard fails and names the file. | `check-shell-seams::check_panel_tus` |
| `mwc_guard_menus` | Run the shell-seam guard with a synthetic menu TU that includes `frame.h`, names `PicturaMainWindow`, or leaves a `frame_menus*.cpp`. | The guard fails and names the offending file. | `check-shell-seams::check_menu_tus` |
| `mwc_guard_budgets` | Run the shell-seam guard with a `frame.h` over 760 lines or a `frame_includes.h` over 60 include lines. | The guard fails with the offending file and measured size. | `check-shell-seams::check_budgets` |
| `mwc_existing_suites` | Run the full test report on the branch and diff the files under `crates/pictura-app/cpp/tests/` against the pre-change tree. | Every registered Qt suite passes and no file under `crates/pictura-app/cpp/tests/` was edited. | manual: `scripts/test-report.sh` runs the whole unchanged suite set; no single case asserts that test files were not edited. |
| `mwc_selftest_baseline` | Run both headless self-test invocations and compare stderr tokens and exit codes with the pre-change baseline. | Token sequence and exit codes match. | manual: the baseline comparison is a whole-run diff, not a test case. |
| `mwc_session_roundtrip` | Change UI scale and a panel/workspace setting, save, reconstruct the shell, and reload; separately round-trip the session store file. | The schema, keys, and values match the pre-change store for the same settings. | `tst_ui_scale::sessionPersistsScale`, `tst_session_store::ownWritesRoundTrip`, `tst_floating_workspaces_restart::restartRestoresFloatAtRightOfRestoredFrame` |
| Full session schema comparison | Save the session after the refactor and compare the `state.json` key set and values with a pre-change fixture. | The key set, schema version, and values are unchanged. | manual: compare the saved `state.json` key set and values against a pre-change fixture; the field round-trips are covered by the named tests. |
