# Test plan

One row per scenario in the delta spec. The three Python checks and the shared
helper are named by `<script>::<fn>`; `check-file-size.sh` is a shell gate with no
`<script>::<fn>` owner, so its self-test is a runnable `manual:` arm that the
gate runs through `file_size_check` in `scripts/verify-fast.sh`.

## verification/verification-harness

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `vh_changed_set_shared` | Run `changed_files.py --self-test`; inspect `verify-fast.sh` for the helper invocation and the single `changed_file` it hands to each scoped check. | The helper's self-test passes (merge base, working diff, untracked files, filtered set, empty set, unreadable list, affecting path), and `verify-fast.sh` obtains the list only through `changed_files.py` and passes the same file to each scoped check. | `changed_files::_self_test` |
| `vh_changed_set_scoped` | Give each check a changed list naming one clean file in a sandbox that also holds an unchanged violating file; then run the same tree with `--full`. | The scoped run passes and the `--full` run fails naming the unchanged file. | `changed_files::_self_test`, `check-milestone-names::_self_test`, `check-msvc-string-limits::_self_test`, `check-colour-literals::_self_test`, manual: `scripts/check-file-size.sh --self-test` (shell gate; no crate/`tst_` test owner) |
| `vh_changed_set_violation` | Give each check a changed list that includes the violating file. | The scoped run fails and names the file. | `changed_files::_self_test`, `check-milestone-names::_self_test`, `check-msvc-string-limits::_self_test`, `check-colour-literals::_self_test`, manual: `scripts/check-file-size.sh --self-test` (shell gate) |
| `vh_changed_set_empty` | Give each check an empty list; give one an unreadable path; give `check-file-size.sh` a non-empty newline-only list. | The empty list scans the whole tree and fails on the violation; the unreadable path and the newline-only list exit non-zero as usage errors rather than falling back or passing silently. | `changed_files::_self_test`, `check-milestone-names::_self_test`, `check-msvc-string-limits::_self_test`, `check-colour-literals::_self_test`, manual: `scripts/check-file-size.sh --self-test` (shell gate) |
| `vh_changed_set_allowlist` | Give `check-colour-literals.py` a changed list holding `scripts/colour-literal-allowlist.txt`, and `check-file-size.sh` a list holding `scripts/file-size-allowlist.txt`. | Both scan the whole tree and report the violation in an unnamed file. | `changed_files::_self_test`, `check-colour-literals::_self_test`, manual: `scripts/check-file-size.sh --self-test` (shell gate) |
| `vh_file_size_batched` | Run `scripts/check-file-size.sh --self-test` over a sandbox with a code-budget violation, an allowlisted over-cap file, a grown allowlist entry, and a 1250-line file under `crates/tests/`. | One `wc -l` batch feeds both the cap and the allowlist decision, and the sandbox splits exactly as the old per-file loop did. | manual: `scripts/check-file-size.sh --self-test` (shell gate; the batched count is asserted by the sandbox's pass/fail split) |
| `vh_guard_unchanged` | Run `bash scripts/guard.sh` with no arguments before and after the change on the same tree, diff the output, and grep the guards workflow for a bare invocation. | The whole-tree output and exit status are unchanged, and `.github/workflows/guards.yml` still calls the guard with no arguments. | manual: `scripts/guard.sh` has no self-test owner; its unchanged whole-tree behaviour is proven by diffing its output and exit status before and after on the same tree |
| `vh_file_size_caps` | Run `scripts/check-file-size.sh --self-test`: the sandbox holds a small clean file, a 1250-line `crates/big.rs` allowlisted at 1200, and a 1250-line `crates/tests/growing.rs` allowlisted at 1300. | The grown `big.rs` is reported, the 1250-line test file passes under the 1400-line test budget, and the clean file passes. | manual: `scripts/check-file-size.sh --self-test` (shell gate; no crate/`tst_` test owner) |
| `vh_file_size_caps_unchanged` | Inspect `scripts/check-file-size.sh` for `CODE_BUDGET=1200` and `TEST_BUDGET=1400`, and diff `scripts/file-size-allowlist.txt` against `origin/master`. | Both budgets read 1200 and 1400, and the allowlist has no added entry. | manual: `scripts/check-file-size.sh --self-test` asserts the split, and the allowlist diff is a reviewer check on the same commit |
| `vh_changed_set_self_test` | Run `--self-test` on the helper and all four checks. | Each asserts the scoped pass, the scoped failure, the empty-set failure and the full-scan failure. | `changed_files::_self_test`, `check-milestone-names::_self_test`, `check-msvc-string-limits::_self_test`, `check-colour-literals::_self_test`, manual: `scripts/check-file-size.sh --self-test` (shell gate) |
