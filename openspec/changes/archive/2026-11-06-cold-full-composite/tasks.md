# Tasks

This is the complete diagnostic prerequisite. All diagnostic code/tests are
written before any build/compile/test-build command. Tests named in a task are
run at the final build stage, not between edits. No task selects or implements
a render optimization; that requires the follow-on proposal after measurement.
