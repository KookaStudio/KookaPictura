# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| Every persisted field round-trips per key | For each `toolOptions` row, apply its non-default object to a fresh `ToolController`, serialize, apply the serialization to a second controller, serialize again | Both serializations equal the row's object exactly | `tst_tool_options_persistence::everyToolOptionsKeyRoundTrips` |
| The sweep table covers every persisted field and key | Compare each row's declared fields with the serialized object from a fresh controller, the row-key set with the top-level keys `toolOptionsToJson(ToolController{})` emits, each value with the same field's default, and every colour leaf (`fillColor`, `strokeColor`, `shieldColor`) with canonical 8-digit ARGB hex | The field sets and top-level key sets match, every value is non-default, and colours are canonical 8-digit ARGB | `tst_tool_options_persistence::roundTripTableIsComplete` |
| Every key survives a restart | Merge all rows plus the four top-level `crop*` values (Classic on, delete-pixels off, non-zero ratio and grid overlay), apply to window A, `saveSession()`, open window B, serialize its tools and read its `CropOptions` | The whole restored `toolOptions` object equals the merged row object, the four `CropOptions` getters equal the set values, and the store is restored through a scope guard even on failure | `tst_tool_options_persistence::everyToolOptionsKeySurvivesARestart` |
| Wrong-type, null, and malformed-colour entries restore defaults | Assert applying the default payload serializes back identically; replace one field at a time with a non-null value of a different JSON type, then `null`; apply malformed colour strings (`"nope"`, `"#12345"`) to `strokeColor` and `shieldColor`, seeded with a valid non-default colour | Non-colour fields read their defaults; colour leaves read the empty string; `null` keeps the default; the `shape.fillColor` wrong-type row is skipped because its default is already empty | `tst_tool_options_persistence::wrongTypeEntriesRestoreDefaults` |
| Group-level bad entries restore defaults | Apply a missing key, a non-object value, and `null` per group to a controller that already holds non-default values | Each group resets to its defaults | `tst_tool_options_persistence::groupEntriesRestoreDefaults` |
| Out-of-range entries clamp | Restore one out-of-range value per clamped family | The chosen field reads its clamp; unclamped and other fields keep wrong-type coverage | `tst_tool_options_persistence::outOfRangeEntriesClamp` |
| The four crop* session keys persist and restore | Set Classic true, delete-pixels false, a non-zero ratio, and a non-zero grid overlay; read the store back, then open a new window | The four top-level `SessionState` fields carry the set values (value read-back owned by `tst_crop_options`), and the new window's `CropOptions` getters equal them (startup restore owned by the restart case) | `tst_crop_options::cropOptionsPersist`, `tst_tool_options_persistence::everyToolOptionsKeySurvivesARestart` |
