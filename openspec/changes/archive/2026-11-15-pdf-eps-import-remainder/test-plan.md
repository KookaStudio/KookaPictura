# Test plan

Covers every scenario in the `interop/pdf-eps-import` delta. Ghostscript-backed
tests self-skip when `gs` is absent; CI installs it. New tests are added by this
change before the implementation tasks that make them pass.

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| `pdf_native_rgb16_precision` | Render a smooth tonal page with `psdrgb16` and read it as RGB Color at 16 bit | RGB 16-bit document whose retained samples include values that are not multiples of 257 | `pictura-codec::native_rgb16_render_keeps_more_than_eight_bits`, `tst_import_pdf::nativeRgb16ImportKeepsDepth` |
| `pdf_native_cmyk16` | Render a page painting a DeviceCMYK rectangle and a known red patch with `psdcmyk16`/`psdcmyk` and read it as CMYK Color at 16 and 8 bit; compare the stored plates with the profile-free GCR conversion and check the red patch and a partially covered edge | CMYK 16-bit and 8-bit documents whose native plates are not paper-only, differ from the GCR conversion, display the red patch red, and whose display equals the CMYK-to-RGB conversion of the stored plates at a partially covered edge | `pictura-codec::native_cmyk16_keeps_rendered_inks`, `pictura-codec::native_cmyk8_keeps_rendered_inks`, `pictura-codec::native_cmyk16_is_not_the_gcr_conversion`, `pictura-codec::native_antialias_toggles_edge_coverage`, `tst_import_pdf::modeAndDepthApply` |
| `pdf_native_gray16_precision` | Render a tonal page with `psdrgb16` and read it as Grayscale at 16 bit | Grayscale 16-bit document whose samples include values that are not multiples of 257 | `pictura-codec::native_gray16_keeps_more_than_eight_bits`, `tst_import_pdf::nativeGray16ImportKeepsDepth` |
| `pdf_native_transparency` | Render a page that paints part of its canvas at CMYK 16 bit with an alpha pass | Painted pixels opaque, unpainted pixels alpha 0 | `pictura-codec::native_render_keeps_unpainted_areas_transparent`, `tst_import_pdf::nativeCmyk16ImportKeepsTransparency` |
| `pdf_native_antialias` | Render a diagonal-edge page at CMYK 16 bit with Anti-aliased on, then off | Partial edge coverage only in the first render | `pictura-codec::native_antialias_toggles_edge_coverage` |
| `pdf_native_crop` | Render the 144 × 72 pt rectangle page at RGB 16 bit with Crop To Bounding Box, then a rotated page with Crop To Crop Box at 144 ppi and a Name; compare each with the 8-bit import | Same cropped size and placement as the 8-bit import for both boxes, and the second document keeps the chosen Name and 144 ppi Resolution | `pictura-codec::native_crop_matches_the_rgb8_import`, `tst_import_pdf::nativeCropKeepsNameAndResolution` |
| `pdf_image_native` | Open a 16-bit image XObject from Images mode as RGB Color at 16 bit | 16-bit document whose samples include values that are not multiples of 257 | `pictura-codec::native_image_render_keeps_more_than_eight_bits` |
| `eps_native_cmyk` | Open an EPS painting a process-colour rectangle as CMYK Color at 16 bit | CMYK 16-bit document with the rendered inks, transparent outside the rectangle | `pictura-codec::native_eps_render_keeps_cmyk_inks`, `tst_import_pdf::epsNativeCmyk16` |
| `pdf_images_mode_lists` | Open the two-XObject fixture and choose Images | Two images listed, label reads `1 of 2 image(s) selected` | `pictura-codec::images_listed_once_through_forms`, `tst_import_pdf::imagesModeListsImages` |
| `pdf_images_mode_opens` | Open the 40 × 30 px Flate RGB image from Images mode | 40 × 30 px document with the image's samples | `pictura-codec::image_renders_at_native_size`, `tst_import_pdf::imagesModeOpensImage` |
| `pdf_objects_broken_xref` | Point `startxref` past the end of the file and list images | Objects found by scanning, images still listed | `pictura-codec::objects_survive_broken_xref` |
| `pdf_images_encrypted` | Encrypt a PDF with one image using Ghostscript (`kooka`); open it in the window, enter `kooka`, and choose Images | Images is enabled and lists and opens the image; the reader also returns `None` for a wrong or unsupported password | `pictura-codec::encrypted_images_open_with_the_password`, `tst_import_pdf::encryptedImagesNeedThePassword` |
| `pdf_inline_images_listed` | Open a page drawing one XObject and one inline image, choose Images | XObject listed first, then the inline image, count two | `pictura-codec::inline_images_are_listed_after_xobjects`, `tst_import_pdf::inlineImagesAreListed` |
| `pdf_inline_image_opens` | Open the listed inline image | Document at the inline width and height with its samples | `pictura-codec::inline_image_renders_at_its_native_size`, `pictura-codec::inline_indexed_image_renders`, `tst_import_pdf::inlineImageOpens` |
| `pdf_inline_images_skip_unknown_filters` | Open a page whose content stream uses an unsupported filter and draws one XObject and one inline image, and choose Images | The XObject is listed and the inline image is not | `pictura-codec::inline_images_skip_unsupported_content_filters` |
| `eps_dialog_defaults` | Open an EPS with `%%BoundingBox: 0 0 144 72` | Width 2 and Height 1 inches at 300 Pixels/Inch, RGB Color, Bit Depth 8 bit, Constrain Proportions and Anti-aliased on | `tst_import_pdf::epsDialogDefaults` |
| `eps_render` | Open that EPS, painting a blue rectangle over its whole bounding box, at 72 ppi | 144 × 72 px document whose pixels are opaque blue | `tst_import_pdf::epsOpensAtSize`, `pictura-codec::eps_renders_bounding_box` |
| `eps_dos_binary_header` | Open an EPS wrapped in a DOS binary header with a TIFF preview | The PostScript section's bounding box sizes the dialog and the render | `pictura-codec::dos_eps_header_is_unwrapped` |
| `eps_cancel` | Cancel the Rasterize Generic EPS Format dialog | No document is added | `tst_import_pdf::epsCancelOpensNothing` |
