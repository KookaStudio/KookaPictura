# Test plan

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| `cp_once` | Build a document taller than two bands with a pixel layer, a Curves layer, a proxy-less type layer, a smart-filtered layer, and a styled layer; composite it banded while reading the test-only per-layer resolution counters. | Every layer's route, effects, passes, source, mask gates, and native planes are resolved once for the composite; every band reuses them. | `pictura-render::banded_composite_resolves_each_layer_once` |
| `cp_identity` | Composite the same tall stack in bands, over a sub-region, and on one canvas; compare every sample. | Corresponding samples are byte-identical. | `pictura-render::banded_compositing_equals_one_canvas`, `pictura-render::banded_equals_whole_with_object_layers` |
| `cp_adjust_once` | Build a tall document with a Curves layer and a Color Lookup layer carrying an embedded `.CUBE`; composite banded and read the adjustment-decode counter keyed by the block's plane ident. | Each adjustment decodes exactly once for the composite, `.CUBE` parse included. | `pictura-render::adjustment_decodes_once_per_composite` |
| `cp_source_once` | Build a tall document with a proxy-less type layer, a smart-filtered layer, and a styled layer; composite banded and read the per-key source-lookup counter and the pass-build counter. | Each cached source raster is fetched once and each effect pass is built once for the composite. | `pictura-render::sources_resolve_once_per_composite`, `pictura-render::banded_sub_region_reuses_one_pass` |
| `cp_hidden` | Add an invisible adjustment and an invisible type layer to a tall document, plus a visible layer as a positive control; composite banded and read the resolution counters. | The invisible layers resolve no route, source, effect, or mask, the visible layer resolves once, and the composite equals the document without the invisible layers. | `pictura-render::hidden_layer_resolves_nothing` |
| `cp_no_materialize` | Diverge a styled layer's channel plane by writing one band (`write_band`); build the plan, record `pictura_core::plane::materializations()`, then run the band loop. | The counter is flat across the band loop after the plan build. | `pictura-render::banded_composite_does_not_materialize_a_fractured_plane` |
| `cp_invalidate` | Edit a layer's channel, mask, adjustment, effect, payload, and text model in turn; composite after each edit and against a purge-then-composite; for the channel, mask, and adjustment edits assert both the new key and byte equality. | Each edit yields a new resolved key and the same bytes as purge-then-composite. | `pictura-render::content_key_invalidates_on_edit`, `pictura-render::editing_text_invalidates_the_composite`, `pictura-render::replacing_smart_object_contents_invalidates_the_composite`, `pictura-render::effect_passes_invalidate_on_style_or_rect` |
| `cp_clip_reuse` | Build a tall document whose clipping base is an adjustment or type layer, plus a pass-through group base with a non-default Blend If, a drop-shadow base, and a clipping case under the legacy switch; composite banded and read the decode counter. | The group's coverage and opaque composites reuse the base's resolved content, decode it once, re-decide the group arm only when the override changes blend/opacity/mask, skip effects on the coverage canvas, and equal the pre-change bytes, including under the legacy switch. | `pictura-render::clipping_group_reuses_base_content`, `pictura-render::pass_through_group_base_clips_as_isolated` |
| `cp_oracles` | Run the document, clipping, knockout, adjustment, merge, native-depth, and reference-fixture oracle suites. | Every output buffer and encoded file is byte-identical to its recorded result. | `pictura-render::a_region_composite_matches_the_full_one`, `pictura-render::deep_knockout_punches_through_to_the_background`, `pictura-render::merge_down_matches_committed_imagemagick_fixture`, `pictura-render::depth16_native_composite_keeps_sub_8bit_adjustment_samples`, `pictura-render::psd_tools_composites_a_clipping_group_alike` |
| `ck_native` | Composite a 16-bit and a 32-bit document with a retained native plane, including a layer whose store omits one channel, through the plan and through the test-only legacy source path. | Both composites are byte-identical, including the per-channel 8-bit fallback. | `pictura-render::ctx_high_depth_matches_legacy` |
| `ck_mask` | Composite a feathered raster mask, a feathered vector mask, a plain vector mask, and a native raster combined with a vector mask, each through the plan and the legacy switch. | Every output byte matches, including the 8-bit `(r*v+127)/255` combine and the native `f32` product. | `pictura-render::ctx_masks_match_legacy`, `pictura-render::depth16_native_mask_gates_differently_from_the_widened_8bit_mask` |
| `ck_const` | Composite a layer with opacity 128, fill 64, a non-default Blend If range, and a type-tool curve through the plan and the legacy switch. | Every output byte matches. | `pictura-render::ctx_constants_match_legacy` |
| `ck_banded_reuse` | Build a tall document with a feathered mask and a retained native plane; composite banded and read the mask-sample and native-plane resolution counters. | Mask gates and native planes resolve once; every band samples them without a cache lookup; output equals the whole composite. | `pictura-render::banded_reuses_resolved_mask_and_native_state` |
| `lsc_steal` | A pool worker building a cached artifact runs a queued job that looks up the same key before the build finishes. | Both lookups complete and return the same published artifact. | `pictura-render::same_key_lookup_stolen_mid_build_does_not_deadlock` |
| `lsc_steal_cross` | A build joins on parallel work; another pool worker runs the joined half and looks up the key being built while the build waits. | Both lookups complete and return the same published artifact. | `pictura-render::same_key_lookup_in_a_stolen_half_of_the_build_does_not_deadlock` |
| `lsc_dedupe` | Eight threads outside the worker pool look up one missing key at the same time. | The artifact is built exactly once. | `pictura-render::parallel_build_of_one_key_runs_once` |
| `lsc_panic` | A lookup's build panics. | The panic reaches that caller, and the next lookup of the key builds and returns the artifact. | `pictura-render::panicking_build_releases_its_claim` |
| `lsc_huge_glow` | Composite a 512×512 document with an inner glow of size and choke `1e30` in bands on the shared pool. | The composite finishes within 15 seconds and leaves every pixel outside the layer equal to the plain composite. | `pictura-render::huge_glow_is_bounded` |
| `lsc_band_once` | Composite a tall sub-region of a styled document in bands with a purged cache. | The layer's whole-layer pass is built exactly once and the output equals the whole composite. | `pictura-render::banded_sub_region_reuses_one_pass` |
| Profile protocol (not a spec scenario) | Run the ignored 4000² profile over a stack with Curves, Color Lookup, a proxy-less type layer, and a styled layer. | Prints one timing per scenario. | `pictura-render::cpu_composite_profile_4000` |
| Before/after timing (not a spec scenario) | Run the profile on `origin/master` and on the branch, same machine and build profile. | Recorded table in the PR body; no automated threshold because wall time is machine-dependent. | manual: wall time is machine-dependent and the change sets no fixed threshold |
