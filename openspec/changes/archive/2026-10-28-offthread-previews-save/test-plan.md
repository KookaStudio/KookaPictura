# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `pec_hit_bytes` | Encode a multi-layer RGB document through a fresh cache, encode it again unchanged, and encode a clone with no cache | The cached second write and the uncached write are byte-identical; the second write reports channel hits | `pictura-codec::a_cache_hit_equals_a_fresh_encode` |
| `pec_changed_plane` | Edit one pixel layer after a cached encode and encode again through the same cache | That layer's channel bytes differ from the cached stream and a fresh read returns the edit | `pictura-codec::an_edited_plane_is_re_encoded` |
| `pec_parallel_identical` | Encode a multi-layer document with parallel channel encoding and with a single-threaded encode | Both outputs are byte-identical | `pictura-codec::parallel_encoding_matches_serial` |
| `pec_parallel_error` | Call `encode_scanlines` directly with `psb=false` and a synthetic row larger than the `u16` byte-count limit, or encode a layer with a channel-length error | The encode returns an error and produces no output | `pictura-codec::a_channel_error_fails_the_encode` |
| `pec_pruned` | Encode, delete a layer, and encode again through the same cache | The deleted layer's keys are no longer resident and an identical plane with a fresh identity misses | `pictura-codec::unused_entries_are_pruned` |
| `pec_counters` | Encode a 20-layer document, edit one layer, and encode again | The second encode reports one layer with encoded channels and channel hits for the unchanged layers | `pictura-codec::only_the_edited_layer_is_encoded` |
| `pec_cmyk_reuse` | Read the CMYK fixture, then write it unchanged through a cache | Every unchanged layer's CMYK stream equals the retained stream and the test-only conversion counter stays zero | `pictura-codec::unchanged_cmyk_layer_reuses_retained_planes` |
| `pec_cmyk_edited` | Read the CMYK fixture, edit one working color channel, and write it | The edited layer is converted through the document profile; the other layers reuse their retained streams | `pictura-codec::edited_cmyk_layer_is_converted` |
| Save As writes a file | Run Save As to a chosen path and read the file back | A valid file of that format exists at the path and the document is unmodified | `tst_open_save::chosenFormatWinsOverTypedSuffix`, `tst_document_api::saveAndReopenRoundTrip` |
| Save uses the recorded path | Edit a document with a recorded raster path and run Save | The file at that path is overwritten in place without Save As | `tst_open_save::rasterOpenKeepsFilePath` |
| Save on an untitled document prompts for a path | Run Save on an untitled document | A Save As path is requested before any write | manual: the modal Save As file dialog is only exercised by the C++ self-test's save flow; no Qt Test slot drives it |
| Save after an edit writes the edited composite | Edit a raster document, save it, and reload it | The saved file carries the edited pixels, not the pre-edit merged image | `tst_open_save::rasterOpenKeepsFilePath` |
| Save As defaults to the import source format | Open a single-layer PNG and invoke Save As | The Save As dialog preselects PNG | manual: the modal Save As default is asserted by the C++ self-test's raster_export check, not a Qt Test slot |
| A raster save clears modified and re-saves the same format | Save a document to `photo.png`, edit it, and save again | The second save rewrites the PNG and the document is unmodified | `tst_open_save::rasterOpenKeepsFilePath`, `tst_document_api::saveAndReopenRoundTrip` |
| A layered document saved to a flat format warns and flattens | Save a layered document to a PNG and confirm the warning | The flattened composite is written as a PNG | manual: the flatten warning is exercised by the C++ self-test's raster_export check; no Qt Test slot drives the modal warning |
| A layered document defaults Save As to PSD | Add a layer to an imported PNG and invoke Save As | The Save As dialog preselects PSD, not PNG | manual: the Save As default is asserted by the C++ self-test's raster_export check, not a Qt Test slot |
| Save on a layered raster path behaves as Save As | Save a layered document recorded at a `.png` path | The format-aware Save As dialog opens instead of overwriting the PNG | manual: the layered-raster diversion is exercised by the C++ self-test's raster_export check; no Qt Test slot drives the modal dialog |
| A PSB path writes a PSB container | Save a document to a `.psb` path and inspect the header | The written file is a version-2 PSB | `tst_save_options::psbOn` |
| `dl_save_current` | Save a modified document through the worker and reopen the file | The path is recorded, the document is unmodified, and the reopened layers and composite match the snapshot | `tst_offthread_jobs::aCompletedSaveWritesAndClearsModified` |
| `dl_save_stale` | Hold a save in flight, edit the document from a timer, then finish the save | The file holds the snapshot bytes, the path is recorded, and the document remains modified | `tst_offthread_jobs::anEditDuringSaveLeavesTheDocumentModified` |
| `dl_save_failed` | Save to a path whose directory cannot be written | The save returns false, the path and modified state are unchanged, and no temp file remains | `tst_offthread_jobs::aFailedSaveLeavesTheDocumentUntouched` |
| `dl_save_replaced` | Hold a save in flight and replace the document before finishing the save | The file holds the original snapshot and the replacement keeps its own path and dirty state | `pictura-app::a_replaced_document_keeps_its_path_and_dirty_state` |
| A mutating command marks modified | Apply a filter or adjustment to a clean document | The document reports modified | `tst_document_windows::closeDirtyCancelKeepsTab` |
| Save clears modified | Save a modified document without a concurrent edit | The document reports unmodified | `tst_document_api::saveAndReopenRoundTrip` |
| Open clears modified | Open a document | It reports unmodified | `tst_document_api::saveAndReopenRoundTrip` |
| `ml_history_navigation` | Edit a saved document and navigate undo, redo, history jump, and snapshot restore | The document reports modified off the saved state | `tst_document_session::historyNavigationMarksDirty` |
| `ml_return_to_saved` | Edit a saved document and undo back to the saved state | The document reports unmodified | `pictura-app::returning_to_the_saved_state_clears_dirty` |
| `ml_saved_state_dropped` | Push enough edits to drop the saved state from the bounded history | The document reports modified and cannot return to unmodified | `pictura-app::a_dropped_saved_state_stays_dirty` |
| `dl_save_worker` | Start a native save with the delay seam, then run a 10 ms timer probe while pumping events | The timer keeps firing, no gap exceeds 50 ms, and the save is still in flight | `tst_offthread_jobs::saveKeepsTheEventLoopLive` |
| `dl_save_sync_bytes` | Save one document through the synchronous API and an identical one through a held worker save | The two files are byte-identical | `pictura-app::a_synchronous_save_writes_the_worker_bytes` |
| `cr_snapshot_cache` | Save through the session cache, edit one layer, and write a recovery snapshot | The snapshot reports one layer with encoded channels, hits the unchanged layers, and reopens with the edited pixels | `pictura-app::a_snapshot_reuses_the_encode_cache` |
| `fdp_full_zoom_worker` | Open a large document, start a whole-layer filter preview at 100% with the delay seam, and run the timer probe | The timer keeps firing with no gap over 50 ms, the busy bar shows, the live document is unchanged, and once released the canvas shows the exact picture | `tst_offthread_jobs::largeWholeLayerPreviewKeepsTheEventLoopLive` |
| `fdp_full_zoom_cancel` | Start the large whole-layer preview and cancel before and after its worker finishes | The layer, composite, and history equal their pre-preview state and the canvas preview is gone | `tst_offthread_jobs::largeWholeLayerPreviewCancelLeavesTheDocument` |
| `fdp_full_zoom_commit` | Let the exact picture for a large whole-layer preview finish, then accept the dialog | The committed layer and composite equal the worker's result and history gains one state | `tst_offthread_jobs::largeWholeLayerPreviewCommitReusesTheResult` |
| `fdp_full_zoom_mask` | Start a whole-layer filter preview over more than 4 MP at 100% with a layer-mask target, then cancel | The mask is previewed synchronously on its own plane and Cancel restores the mask exactly | `tst_offthread_jobs::maskFullZoomPreviewStaysSynchronous` |
| `ia_dialog_worker` | Start an adjustment dialog preview with the delay seam and run the timer probe | The timer keeps firing with no gap over 50 ms and the live layer is unchanged until a result lands | `tst_offthread_jobs::adjustmentPreviewKeepsTheEventLoopLive` |
| `ia_dialog_latest` | Start one preview, change the parameters while it is held, then let both finish | The canvas and layer reflect the second change and the first result is not applied | `tst_offthread_jobs::latestAdjustmentPreviewWins` |
| `ia_dialog_cancel` | Preview an adjustment, then cancel the dialog | The layer and composite are bit-identical to the pre-dialog state and history is unchanged | `tst_image_adjustments::dialogPreviewsCancelsAndApplies` |
| `ia_dialog_apply` | Preview an adjustment, press OK with the apply held by the delay seam, and run the timer probe | One history state named for the adjustment is recorded and the timer keeps firing while the worker runs | `tst_offthread_jobs::adjustmentApplyKeepsTheEventLoopLive` |
| `ia_dialog_mask` | Preview a destructive adjustment with a layer-mask target, then cancel | The mask-sized synchronous preview runs and Cancel restores the mask exactly with no history state | `tst_offthread_jobs::maskAdjustmentPreviewStaysSynchronous` |
| Busy indicator appears after 250 ms | Run each long job on a real window and watch the wait cursor and busy dialog | A job under 250 ms shows only the wait cursor; a longer job shows the busy dialog | manual: needs a real window and compositor to judge the flash threshold |
| 24 MP, 20-layer profile | Run `cargo test -p pictura-codec -- profile_24mp_cold_and_warm_encode --ignored --nocapture`; the benchmark builds the document, encodes cold and warm, and edits one layer between them | The warm encode reports one layer with encoded channels and a lower time than cold; the numbers are recorded in the PR body | manual: ignored benchmark; requires a 24 MP document and wall-clock measurement, recorded in the PR body |
