# Design

The HDR preview maps light in the canvas display path. Use a region-sized native composite for layered content and read pixel spans from authoritative merged stores when available. Preserve values above white through native reads and compositing before tone mapping, leave alpha unchanged, and keep the general-purpose 8-bit composite separate. The existing native compositor clamps float RGB; exposing it unchanged cannot meet this requirement. Reuse the CPU renderer and draw through the existing canvas provider. Mask solo and editing overlays retain precedence. Info uses the same native source through a one-pixel read, bypassing the display transform.

Preview Options owns a live draft with accept and cancel. Save the accepted method, exposure and gamma in an identifiable versioned Pictura image resource, preserved by PSD and PSB and carried by the TIFF Photoshop metadata tag. Keep the status-bar offset on the view; a double click resets it. Use an exposure gain of 2^EV and power of 1/gamma. Use a luminance-preserving shoulder for Highlight Compression, an approximation of the closed Adobe operator.

The TIFF resource path can preserve the record, but that alone does not provide an HDR TIFF round trip: raster import converts the decoded image to RGBA8888 and constructs an 8-bit document. The current TIFF output also needs its sample depth and float behavior established before claiming HDR pixel preservation. This change tests resource transport separately; native 32-bit TIFF pixel read/write and a full HDR TIFF reopen are an explicit remaining boundary. Do not claim TIFF HDR persistence from a metadata-only test.

Maintain one authoritative float foreground/background color state with a derived QColor proxy for legacy consumers. All mutations must update or invalidate the float value: picker accept/cancel, foreground/background swap and reset, eyedropper, Color panel, swatches, presets, and other QColor setters. Swap moves the full float values; reset and 8-bit mutations replace them with the corresponding converted color. Reuse standard controls for base hue, render stepped swatches with the same preview transform, and allow document exposure to affect the preview. Add to Swatches must ask before converting a color that the existing swatch representation cannot retain; cancel leaves the library unchanged.

The standard Brush stroke uses an 8-bit Rgba color and 8-bit layer channels; it has no existing native float stroke path. A float state and bridge alone cannot paint an above-white value or safely preserve native destination channels. Native 32-bit Brush painting and other float editing consumers remain outside this change until a native stroke path exists; the picker retains values for reopening, not as a claim of HDR painting support.

Adobe's [HDR guide](https://helpx.adobe.com/lu_en/photoshop/using/high-dynamic-range-images.html) specifies stop increments and the inverse relationship between light intensity and exposure compensation. The encoding of Adobe's persisted preview setting is unverified. Keep its opaque resource separate from Pictura's record; Pictura's record is not a claim that Photoshop will apply the setting. Interoperability remains open pending lawful observation of the encoding and a manual cross-application check.
