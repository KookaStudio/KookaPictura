# Proposal

## Why

Review of the Crop menus (#104): the Settings menu's checkbox panel sat tight
against the menu edge and looked unlike the guide-overlay menu beside it.

## What Changes

- The Settings menu uses checkable menu actions with the same check marks,
  padding and separator spacing as the guide-overlay menu. Color and Opacity
  stay as widget rows indented under Enable Crop Shield; Auto Adjust Opacity is
  a checkable item.
- **BREAKING**: none.

## Capabilities

### Modified Capabilities
- `tools/crop-settings`: the Settings menu requirement.
