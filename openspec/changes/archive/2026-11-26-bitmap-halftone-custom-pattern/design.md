## Context

The current path converts the flattened grayscale plane to white/black samples, packs a depth-1 source plane, and commits a single Convert Mode state. The new methods share that path. The existing Output resolution omission is outside the two new methods. Pattern Dither remains the existing ordered 8×8 Bayer approximation under #556: the current capability requires an ordered 8×8 matrix and no reproducible CS6 geometry oracle is available. Its geometry is explicitly deferred, not claimed as CS6 parity.

## Decisions

- Halftone Screen uses the document's stored horizontal PPI or the existing 72 PPI fallback. Frequency in lines/cm is multiplied by 2.54 before dividing by PPI. Sample at pixel centers in axes rotated by the inverse of the requested screen angle. The cell center receives ink first. Rank a centered 128×128 cell sampled at subcell centers. Let x and y be the absolute centered coordinates, each normalized to [0, 1]. Scores are Round x²+y², Diamond x+y, Ellipse x²+3y², Line y, Square max(x,y), and Cross 3min(x,y)+max(x,y). Sort the 16,384 scores ascending; equal scores share their zero-based midrank. The integer threshold is 255 − floor(256 × (midrank + 0.5) / 16,384). A pixel is black when its grayscale value is at or below the threshold. Map the rotated cell position to the corresponding grid sample, with periodic wrapping. This ranks spot area and keeps equal scores at equal thresholds. Explicit black and white endpoints avoid stray pixels. Exact Photoshop spot placement is unpublished. The shape list comes from [Adobe's CS6 JavaScript reference](https://usermanual.wiki/adobe/PhotoshopCS6JavaScriptRefen.2024600616.pdf).
- Custom Pattern repeats the selected tile from document origin. Convert RGBA samples to luminance after compositing over white. A grayscale sample above the local threshold becomes white. Solid black and white are preserved. Resolve the tile before flattening so invalid inputs do not modify the document.
- Add method-specific visibility to the existing dialog. Use 45 LPI, 45°, and Round as project-chosen initial screen settings. Keep integer IDs 0–2 and add 3 for Halftone Screen and 4 for Custom Pattern. Record the screen settings or pattern identity and, for imported presets, its native data. Silent replay uses the recorded options and refuses an unresolved pattern. Modal replay uses a context handler to prefill the recorded method and options, applies accepted edits and returns them to the command, and cancels without conversion or changed parameters. Reuse the installed preset and document pattern sources without adding a pattern manager.
- Follow [Adobe's conversion help](https://helpx.adobe.com/ie/photoshop/desktop/adjust-color/color-modes/convert-an-image-to-bitmap-mode.html) for physical units and tile behavior. Compare against CS6 visually when an oracle is available.

## Risks

Screens near or above the raster sampling frequency can alias. Imported and embedded pattern lookup can fail, so reject an unresolved tile before committing. The existing history and packing paths are shared by all methods.
