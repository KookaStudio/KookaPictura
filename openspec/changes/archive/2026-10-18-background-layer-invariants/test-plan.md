# Test plan

One row per spec scenario in the delta. Coverage names the automated test, or
`manual: <reason>` when it cannot be automated. Checked by
`scripts/check-test-plan.py`.

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| Bring to Front moves the active layer to the top | Arrange a layer in a three-layer stack with Bring to Front; count history | Layer is topmost, the others keep their order, one undo state | `pictura-render::arrange_moves_within_container_and_refuses_edges`, `tst_command_tree::layerArrangeStamp` |
| Send to Back moves the active layer to the bottom | Send to Back on the top layer of a stack without a Background; count history | Layer is bottom-most, one undo state | `pictura-render::arrange_moves_within_container_and_refuses_edges`, `tst_command_tree::layerArrangeStamp` |
| Bring Forward and Send Backward move one position | Run Forward then Backward on the same middle layer | The pair swaps and swaps back | `pictura-render::arrange_moves_within_container_and_refuses_edges` |
| A boundary move is refused and disabled | Forward and Front on the top layer | No change, `can_arrange_path` false, no history | `pictura-render::arrange_moves_within_container_and_refuses_edges`, `tst_command_tree::layerArrangeStamp` |
| The Background does not reorder | Run all four Arrange ops on the Background | Every call refuses, document unchanged | `pictura-render::arrange_refuses_background_and_locked` |
| Send to Back stops above the Background | Background + middle + top; Send to Back on the top layer, then Send Backward on the layer directly above the Background | Top lands at index 1 with one undo state; the second call is a disabled no-op | `pictura-render::arrange_stops_above_background`, `tst_command_tree::arrangeStopsAtBackground` |
| A move below the Background is refused | Move the top layer below the Background with `move_path_to` and `can_move_path_to` | Both refuse and the document is unchanged | `pictura-render::move_path_to_refuses_below_background` |
| A delta move clamps at the Background | Move a layer at the floor by -1 and the top layer by -5 | The floor layer returns false; the top layer stops directly above the Background | `pictura-render::move_path_clamps_at_background_floor` |
| A delta move from below the Background is refused | Build `[A, Background(flag), B]` and move A by +1 | The move is refused and the document is unchanged | `pictura-render::move_path_refuses_a_source_below_the_background` |
| A second Background is refused | Convert a normal layer with `background_from_layer` when a Background already exists | The conversion is refused and the document is unchanged | `pictura-render::background_from_layer_refuses_a_second_background` |
| A nested group applies the same floor | Build a group whose bottom child is a Background; move and arrange its upper children | Drop below the nested Background is refused and Arrange stops above it | `pictura-render::a_group_with_a_background_keeps_it_bottom` |
| Menu and Alt-click | Create a clipping mask from the menu on a fill above a shape, release from the base, Alt-click the dividing line twice; count history | Each gesture changes the clip; create, release, and both Alt-clicks each add one state | `tst_layers_panel::clippingMasks` |
| The Background cannot be a clipping base | Create a clipping mask on the layer above the Background via the predicate, Alt-click toggle, and Properties toggle | Every path refuses and records no history | `pictura-render::a_background_is_never_a_clipping_base`, `tst_layers_panel_fixes::cannotClipToBackground` |
| A new clipped layer above the Background lands unclipped | Request a clipped New Layer with the Background selected | The layer is inserted above the Background with `clipping == false` | `pictura-render::a_background_is_never_a_clipping_base`, `tst_layers_panel_fixes::cannotClipToBackground` |
| Deleting the base releases its run | Delete a base with clipped layers above it | The former run is released | `pictura-render::deleting_the_base_releases_its_run` |
| Moving the base out releases its run | Move a base away from directly below its run | The former run is released | `pictura-render::moving_the_base_out_releases_its_run` |
| Converting the base to Background releases its run | Convert a base (root and grouped) to the Background | The run is released and the new Background is not clipped | `pictura-render::converting_the_base_to_background_releases_its_run`, `pictura-render::converting_a_grouped_base_to_background_releases_its_run` |
| Deleting a clipped layer keeps the run | Delete a middle clipped layer | The remaining run keeps its clip | `pictura-render::deleting_a_clipped_layer_keeps_the_run` |
| Ungrouping a base group releases its run | Ungroup a group that is a clipping base | The run is released | `pictura-render::ungrouping_a_base_group_releases_its_run` |
| Grouping a clipped layer clears the new bottom | Group a clipped layer so it becomes the new group's bottom child | Its clip is cleared and the parent is normalized | `pictura-render::grouping_a_clipped_layer_clears_the_new_bottom` |
| Reverse never leaves a clipped bottom layer | Reverse a base and clipped layer at a container bottom | The new bottom layer is released | `pictura-render::reverse_clears_a_clipped_bottom` |
| Reverse never leaves a clip on the Background | Reverse a base with a clipped layer so the clipped layer lands directly above the Background | The clip is released | `pictura-render::reverse_releases_a_clip_on_the_background` |
| Ungrouping never leaves a clipped bottom layer | Ungroup a group whose spliced children start with a clipped layer | The bottom layer is released | `pictura-render::ungroup_clears_a_clipped_bottom` |
| A new clipped layer at a container bottom is released | Insert a clipping-requested layer at a container bottom | The inserted layer has `clipping == false` | `pictura-render::new_clipped_layer_at_container_bottom_is_released` |
| `lpr_drag` | Drag a row and release it above a sibling; check the selection | Reorder in one undo step, selection unchanged | `tst_layers_panel::dragReorder`, `tst_layers_panel::dropAnywhereOnLayerRowReorders` |
| `lpr_drag_top_level` | Drag a top-level row over the gap above/below a sibling | The model is drop-enabled for the invalid parent and the reorder is accepted | `tst_layers_panel::dropAnywhereOnLayerRowReorders` |
| `lpr_drag_cursor` | Start a row drag and end it | Closed-hand cursor during the drag, previous cursor restored after | manual: unchanged by this change; checked by the C++ self-test token `lpr_drag_cursor` (`pictura --headless --self-test`); the self-test is not a test-plan reference type |
| `lpr_drag_reorder_mode` | Drop a row on the upper/lower half of a plain layer row | The drop resolves to above/below, never into the row | `tst_layers_panel::dropAnywhereOnLayerRowReorders` |
| `lpr_drag_state` | Enter a drag over the tree, then hover an invalid target | Dragging state set, indicator painted for valid targets, cleared for invalid | manual: unchanged by this change; checked by the C++ self-test tokens `lpr_drag_sibling` and `lpr_drag_invalid` (`pictura --headless --self-test`); the self-test is not a test-plan reference type |
| `lpr_drag` | Drag a row onto the centre of a group row | The row becomes a child of the group in one undo step | `tst_layers_panel_fixes::dropIntoOpenGroupKeepsExpanded` |
| `lpr_drop_out` | Drag a child out of a group and drop it on the empty viewport | The row is reparented to the document root | manual: unchanged by this change; checked by the C++ self-test token `lpr_drop_out` (`pictura --headless --self-test`); the self-test is not a test-plan reference type |
| `lpr_drop_rules` | Hover the row's descendant, itself, and a refusal target | No indicator, the drop is ignored, history unchanged | manual: unchanged by this change; checked by the C++ self-test token `lpr_drop_rules` (`pictura --headless --self-test`); the self-test is not a test-plan reference type |
| `lpr_drop_bg_below` | Drag a layer over the lower edge of the Background row | No indicator, no drop, no history state, Background stays at index 0 | `tst_layers_panel_fixes::dropBelowBackgroundRefused` |
| `lpr_drag` | Drag the Background or a fully-locked row onto another row | The pending move is rejected by the engine predicate | `pictura-render::move_path_to_keeps_reorder_and_refusals` |
| `lpr_drag_enabled` | Press a row and move the pointer | The drag pipeline starts and the selection is not extended | manual: unchanged by this change; checked by the C++ self-test token `lpr_drag_sibling` (`pictura --headless --self-test`); the self-test is not a test-plan reference type |
| `lpr_drop_button` | Drag a row onto the Delete strip button | The row is deleted in one undo step | `tst_layers_panel::dropOnDelete` |
| `lpr_drop_button` | Drag a non-Background row onto the New Layer strip button | The row is duplicated in one undo step | manual: unchanged by this change; no direct Qt or Rust check exists for the New Layer strip-button drop |
| `lpr_drop_background_convert` | Drag the Background onto the New Layer strip button | The Background converts in place, no `Background copy` | manual: unchanged by this change; checked by the C++ self-test token `lpr_background_drop` (`pictura --headless --self-test`); the self-test is not a test-plan reference type |
| `lpr_drop_button` | Drag a row onto the New Group strip button | The row is wrapped in a new group in one undo step | manual: unchanged by this change; no direct Qt or Rust check exists for the New Group strip-button drop |
| Add a layer | Click New Layer with a layer selected | An empty transparent layer is inserted above it and selected | manual: unchanged by this change; checked by the C++ self-test token `lpr_new_layer_dialog` (`pictura --headless --self-test`); the self-test is not a test-plan reference type |
| `m39_tree` | Click New Layer with a group selected | An empty transparent layer becomes the group's topmost child | `tst_layers_panel_fixes::addingLayerKeepsGroupExpanded` |
| Add a group | Click New Group with no selection | An empty group is inserted at the top and selected | manual: unchanged by this change; checked by the C++ self-test token `lpr_new_group_dialog` (`pictura --headless --self-test`); the self-test is not a test-plan reference type |
| Duplicate a layer | Duplicate the selected layer | A deep copy named `"<name> copy"` sits above it and is selected | `pictura-render::duplicate_paths_returns_new_paths` |
| Delete a layer | Delete the selected layer | The layer is removed and the panel updates | `pictura-render::delete_skips_background_and_locked` |
| Move a layer | Move the selected layer up or down within its container | The order changes, the rows reorder, and the composite updates | `pictura-render::move_path_clamps_and_rename_resolves` |
| Move Down at the Background floor is refused | Move the layer directly above the Background down | The order is unchanged, no history state is added, and the Background stays bottom-most | `tst_layers_panel_fixes::moveDownStopsAtBackground` |
| Duplicating the Background makes an ordinary layer | Duplicate the Background | `Background copy` sits above it as an unlocked pixel layer with no lock badge, and the original stays the Background | `pictura-render::duplicating_a_background_makes_an_unlocked_layer_with_alpha` |
