# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `preview_clip_engine` | Inspect the production call chain from `ImageView::setSelectionShapePreview` through `pictura::clipSelectionShapeToCanvas`. | The shell forwards through `selection_api` and the existing `selection_bridge.h` membrane to Rust; no production Qt boolean remains. | manual: source review confirms delegation and the single shell entry point |
| `preview_clip_inner` | Clip the pinned inner rectangle through the engine and the bridged Qt path. | Exact ordered equality, with no border edge. | `pictura-select::inner_loop_is_unchanged`, `tst_selection_preview::clipToCanvasLeavesInnerShapesAlone` |
| `preview_clip_outside` | Clip the pinned outside rectangle through the engine and the bridged Qt path. | No loop is returned. | `pictura-select::outside_loop_is_dropped`, `tst_selection_preview::clipToCanvasDropsOuterShapes` |
| `preview_clip_short` | Clip empty, one-point, and two-point traces through the engine and the bridged Qt path. | Every trace is returned with exact ordered equality. | `pictura-select::short_traces_are_unchanged`, `tst_selection_preview::clipToCanvasKeepsDegenerateLoops` |
| `preview_clip_zero_area` | Clip the pinned closed doubled-back horizontal trace through the engine and the bridged Qt path. | The original closed trace is returned with exact ordered equality. | `pictura-select::zero_area_trace_is_unchanged`, `tst_selection_preview::clipToCanvasKeepsATraceThatEnclosesNothing` |
| `preview_clip_open_band` | Clip an open zero-area diagonal band through the engine and the Qt oracle, including the magnetic-lasso preview. | The path is clipped to the canvas with no outside vertex; an empty path result preserves the original trace. | `pictura-select::open_zero_area_band_is_clipped`, `tst_selection_preview::clipDifferentialCorpusMatchesQt`, `tst_selection_preview::magneticLassoPastTheEdgeClosesAlongTheBorder` |
| `preview_clip_border` | Clip the pinned border-crossing rectangle through the engine and the bridged Qt path. | One loop has exact right/bottom corners, snapped border coordinates, and no outside vertex. | `pictura-select::border_crossing_closes_along_the_border`, `tst_selection_preview::clipToCanvasClosesAlongTheBorder` |
| `preview_clip_self_overlap` | Clip the pinned self-overlapping trace through the engine and the bridged Qt path. | One connected loop bounds the even-odd region; only exact shared endpoints are spliced. | `pictura-select::self_overlap_uses_the_even_odd_region`, `tst_selection_preview::clipToCanvasClosesASelfOverlappingShape` |
| `preview_clip_near_touch` | Clip distinct contours whose endpoints are within `1e-6` but not identical, including near a canvas edge. | The contours remain separate; border snapping does not create a splice. | `pictura-select::near_touching_contours_stay_separate`, `tst_selection_preview::clipToCanvasKeepsNearTouchesSeparate` |
| `preview_clip_empty_canvas` | Call the engine with zero, negative, NaN, and infinite widths and heights. | Every input is returned unchanged. | `pictura-select::invalid_canvas_returns_the_input` |
| `preview_clip_degenerate` | Clip tangent point and tangent line intersections; call the contour arity filter with zero-, one-, two-, and three-point contours. | An empty contour list falls back to the original loop; contours with fewer than two points are discarded and two- or three-point contours remain unchanged. | `pictura-select::degenerate_intersections_follow_arity_rules`, `pictura-select::contour_arity_filter_keeps_two_or_more_points`, `tst_selection_preview::clipToCanvasHandlesTangentDegeneracies` |
| `preview_clip_parity` | Run the six pinned cases and differential corpus through the engine and a local copy of the complete old function; perturb a canonical loop by `0.5e-6` and `2e-6`. | Fast paths match exactly; simplified, intersection-split boundary segments match within `1e-6`; the smaller perturbation passes and the larger one fails. | `tst_selection_preview::clipToCanvasClosesAlongTheBorder`, `tst_selection_preview::clipToCanvasLeavesInnerShapesAlone`, `tst_selection_preview::clipToCanvasDropsOuterShapes`, `tst_selection_preview::clipToCanvasKeepsDegenerateLoops`, `tst_selection_preview::clipToCanvasKeepsATraceThatEnclosesNothing`, `tst_selection_preview::clipToCanvasClosesASelfOverlappingShape`, `tst_selection_preview::outlineComparisonToleranceHasTeeth` |
| Differential corpus matches the complete Qt reference | Run multiple-loop, hole-order, duplicate-closing-vertex, border-collinear, near-touch, tangent, and open zero-area inputs through both paths. | Exact fast-path equality and tolerant boundary-segment topology for filled intersections. | `tst_selection_preview::clipDifferentialCorpusMatchesQt` |
| Non-finite input does not panic | Clip a loop containing NaN and infinity. | The loop is returned unchanged without entering the boolean library. | `pictura-select::non_finite_loop_is_unchanged` |
| Holes and loop order survive clipping | Clip outer and hole loops in both input orders. | Both contours remain separate, and sorted canonical topology is identical. | `pictura-select::clipping_preserves_holes`, `tst_selection_preview::clipParityIgnoresLoopOrder` |
| Malformed bridge payloads fail closed | Pass odd coordinate counts, overflowing length sums, truncated lengths, and trailing points. | `valid = false`, empty vectors, and no C++ loop output. | `pictura-app::selection_clip_shape_to_canvas_rejects_malformed_payloads` |
| Owned bridge result is copied safely | Inspect the Qt adapter's result decoding and destruction order. | Qt loops own their points before the Rust result vectors are destroyed; no references escape. | manual: source review confirms copy-before-destruction without a test-only bridge seam |
| Large coordinates keep exact borders and sub-micro precision | Clip a border crossing on a 300000-pixel canvas. | Border coordinates are exact after snapping; canonical non-border intersections stay within `1e-6`. | `pictura-select::large_coordinates_keep_sub_micro_precision` |
