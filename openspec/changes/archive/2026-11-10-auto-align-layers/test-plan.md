# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `auto_align_reposition` | Build two synthetic layers from one textured source, offset the moving layer by a known integer translation, plan Reposition Only, and inspect/apply the plan. | The plan is a pure translation, no rotation or scale, and the aligned content is within one pixel. | `pictura-render::reposition_only_recovers_a_translation` |
| `auto_align_perspective` | Warp a synthetic layer by a known homography, plan Perspective, and compare the estimated map's corner images with the known targets. | Corner error is small and the overlap score improves over no alignment. | `pictura-render::perspective_recovers_a_homography` |
| `auto_align_scene_collage` | Rotate and scale a synthetic layer, plan Scene Collage, and inspect the transform and a circular mark. | The transform is a similarity (equal scales, no projective terms) and the circle stays round within tolerance. | `pictura-render::scene_collage_preserves_shape` |
| `auto_align_cylindrical_spherical` | Build two wide synthetic panoramas with overlapping content, plan Cylindrical and Spherical, and apply each. | Both estimate finite projected maps, the overlap score improves, and the source rect maps without infinities. | `pictura-render::cylindrical_and_spherical_improve_overlap` |
| `auto_align_auto` | Plan Auto for a synthetic pair and compare its score with the Perspective and Cylindrical candidates. | Auto returns one of the two and is not worse than either. | `pictura-render::auto_keeps_the_better_projection` |
| `auto_align_reference` | Select a position-locked layer and two ordinary layers, plan and apply, and compare the locked layer before/after. | The locked layer's rect and pixels are unchanged; the others align to it. | `pictura-render::a_locked_layer_is_the_reference` |
| `auto_align_centre_reference` | Plan an alignment of three ordinary layers and read the plan's reference. | The reference is the layer whose content centre is nearest the union centre. | `pictura-render::the_centre_most_layer_is_the_reference` |
| `auto_align_skips` | Include a group, adjustment layer, Smart Object, shape layer, and two raster layers; plan and apply. | Only the two raster layers change; a selection with fewer than two eligible layers reports that Auto-Align does not apply. | `pictura-render::ineligible_layers_are_skipped` |
| `auto_align_one_state` | Trigger Edit ▸ Auto-Align Layers on two layers, then undo. | Exactly one "Auto-Align Layers" state is added and one undo restores every rect and pixel. | `tst_auto_align::oneHistoryStateAndUndo` |
| `auto_align_cancel` | Start a delayed run, cancel it, and finish. | No history state is added and the document is unchanged. | `tst_auto_align::cancelMidRun` |
| `auto_align_lens_correction` | Pass a synthetic lens profile and request geometric distortion and vignette removal; plan and apply. | The plan carries the correction, the corner pixels change as the profile predicts, and matching runs on corrected content. | `pictura-render::lens_correction_uses_the_profile` |
| `auto_align_lens_skipped` | Run Lens Correction on a document with no matching profile. | Pixels change only by the alignment and the run reports that lens correction was skipped. | `tst_auto_align::missingProfileIsReported` |
| `auto_align_menu` | Select one, two, and three eligible layers and open the Edit menu; repeat with a modal transform active. | The command is disabled with one layer, enabled with two or more, and disabled during a modal transform. | `tst_auto_align::menuEnablement` |
| `auto_align_dialog` | Construct the dialog, change the projection and sub-options, construct another with the saved choice. | Auto is the default, the Lens Correction sub-options follow the Lens Correction radio, and the saved choice is restored. | `tst_auto_align::dialogDefaults`, `tst_auto_align::dialogRestoresAChoice`, `tst_auto_align::lensSubOptionsFollowProjection` |
| `auto_align_progress` | Start a delayed run, observe progress and running state, and cancel. | Progress is reported, the run stops after cancellation, and nothing is committed. | `tst_auto_align::cancelMidRun` |
| `auto_align_stale` | Start a delayed run and edit the document before it finishes. | The plan is discarded, no history state is added, and the run reports that the document changed. | `tst_auto_align::staleRunIsDropped` |
| Reposition Only moves the selected layers | Create two overlapping textured layers with a known offset, trigger Edit ▸ Auto-Align Layers with Reposition Only, and inspect the layer rects. | The moving layer's rect changes by the expected translation and the reference stays put. | `tst_auto_align::repositionOnlyMovesLayers` |
| The committed layers stay selected | Trigger Auto-Align and read the Layers panel selection. | The moved layers remain selected after the commit. | `tst_auto_align::selectionAfterCommit` |
| Determinism | Plan the same synthetic pair twice and compare the plans. | The two plans are identical. | `pictura-render::the_plan_is_deterministic` |
| Apply changes only the targets | Apply a plan and compare every non-target layer with its pre-plan clone. | Non-target layers are bit-identical; target layers move. | `pictura-render::applying_one_plan_changes_only_the_targets` |
