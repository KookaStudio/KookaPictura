# Design

Use a dedicated CPU merge in pictura-core and an application bridge alongside the stack import. Use bounded raster import, its metadata readers, and an HDR variant of the source picker. Inputs over 8 bits per channel are refused before decode; native-depth import is a remaining gap. Only clean saved open documents are eligible; never save, edit, or otherwise modify any input file or document.

Require three distinct, readable, equal-sized sources. JPEG and TIFF EXIF shutter time, aperture, and ISO yield photographic EV100 = log2(N² / t × 100 / ISO); exposure is 2^(-EV100). Editable EV100 fields use metadata where complete and start empty for missing rows, which require explicit finite values. Divide linear samples by relative exposure and normalize to the median bracket exposure; reject non-finite or unrepresentable exposure ratios.

Fit a monotonic parametric inverse response per channel: the sRGB inverse transfer followed by a fitted positive per-channel exponent, using unclipped aligned pixel pairs. With insufficient evidence use exponent 1 (sRGB inverse). Reject malformed, non-finite, non-positive or unsupported-version response curves. Use exposure-normalized, midrange-weighted fusion inspired by Debevec and Malik. An analytical synthetic scene checks numerical radiance; a Debevec oracle comparison is explicitly deferred because no reference oracle and agreed tolerance are supplied. [Debevec and Malik’s radiance reconstruction paper](https://www.pauldebevec.com/Research/HDR/debevec-siggraph97.pdf).

Search bounded translations with exposure-invariant correlation. Refuse low-confidence, boundary, or ambiguous results; unsupported displacements can be indistinguishable in repeating content. Exclude out-of-frame and fully transparent samples. Fuse RGB independently with per-channel exposure weights. For each channel with no weighted sample, choose the least-exposed valid source if all are highlight-clipped, the most-exposed if all are shadow-clipped, and otherwise the valid source nearest the base; ties follow source order. For weighted pixels, alpha is the mean weighted by each sample's largest channel weight; otherwise use the nearest-base alpha. With no nonzero alpha output transparent black. Ghost suppression uses the selected base per usable channel when observations disagree, with normal fusion and fallback for clipped base channels.

Estimate decoded source, alignment, merge, preview, conversion, and staged-output memory with checked arithmetic before allocation; reserve against the existing photo/working memory budget and reject over-budget or overflowed jobs with a visible error. Release reservations and temporary buffers on every exit. Stage the output privately and register exactly one document only after acceptance and successful conversion; failure or cancellation at any stage leaves all inputs and existing documents unchanged.

Expose response values in a versioned Pictura format separate from presets. Reuse existing HDR conversion methods for integer output. Preview brightness changes only the reduced display preview, using the existing native document display narrowing; it never changes merged samples. Persisting that white point through PSD/PSB/TIFF reopen is a #558 remaining parity gap: the existing document display has no persistent white-point field. Externally tested CS6 defaults, proprietary interchange, and exact CS6 output remain open questions.
