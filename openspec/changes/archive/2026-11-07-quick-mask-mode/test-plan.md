# Test plan

Every automated reference below names a test to add during apply. None is claimed to exist or pass at proposal time. Write the named tests before the corresponding implementation tasks; run compilation and tests only after all source changes are finished. Use independent offscreen Qt fixtures and deterministic generated images. The command-table goldens gain the canonical Quick Mask row and frozen ID; all existing rows remain intact.
