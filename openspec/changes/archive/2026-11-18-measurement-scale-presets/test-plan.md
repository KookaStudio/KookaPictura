# Test Plan

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| `scale_conversion` | Convert a 100 px length and a 2500 px² area at 50 px = 1 micron. Also exercise Default. | Length is 2 microns, area is 1 square micron, and Default is the identity. | `pictura-core::measurement_scale_converts_length_and_area` |
| `scale_invalid` | Try zero, negative, fractional, or out-of-range pixel lengths, nonpositive or nonfinite logical lengths, an underflowed factor, and whitespace-only units. Submit invalid input through Custom. | The model rejects invalid values and Custom keeps the active scale and history. | `pictura-core::measurement_scale_rejects_invalid_values`, `tst_measurement_scale::rejectsInvalidCalibration` |
| `scale_dialog` | Open Custom, verify the Ruler is active, fill the pixel field with a noninteger ruler drag, and verify its rounding. Repeat with typed input and measure a 100 px line. Enable the Info and status modes. | Both entry paths apply a valid scale. At 50 px = 1 micron the ruler reports 2 microns plus the existing readout. Info and status show the active scale. | `tst_measurement_scale::calibratesFromRulerAndTypedInput` |
| `scale_history` | Open two documents. Apply a scale to one, select Default, undo and redo, and switch tabs. | Each change creates one history state. Undo and Redo restore the scale and readouts. The second tab retains its own value. | `tst_measurement_scale::restoresScaleThroughHistoryAndTabSwitch` |
| `scale_noop` | Cancel a changed draft. Reopen and apply the already active custom values. | Neither operation changes the scale, dirty state, or history length. | `tst_measurement_scale::cancelAndUnchangedScaleAreNoops` |
| `scale_standard` | Run the app in Standard and inspect menus, status choices, and the Ruler. | Calibration controls and calibrated readouts are absent and the regular Ruler works. | `tst_measurement_scale::standardKeepsUncalibratedRuler` |
| `scale_presets` | Use isolated application data. Save a preset, restart against the same store, apply it to two documents, delete it, and reopen the menu. | The preset persists, can be applied in both documents, and disappears on deletion. Both documents keep their calibration. | `tst_measurement_scale::persistsAndDeletesPresetsIndependently` |
| `scale_psd_roundtrip` | Save a fresh document and a document calibrated with a fractional logical length and Unicode units as PSD and PSB. Reopen via both eager and lazy paths. Select Default, save, and reopen. | The fresh file has no 1074, edited values round-trip exactly, and the explicit reset removes 1074 and restores Default. | `pictura-codec::measurement_scale_roundtrips_eager_and_lazy_psd_psb` |
| `scale_psd_oracle` | Open the local `measurement-scale-75px.psd` in Kooka, change 75 px = 2.5 µm to 50 px = 1 mm, save a copy, and reopen that copy in CS6 Extended. | Kooka sees the original values and CS6 sees the edited scale. Record the Photoshop version and both scale values. | manual: requires a licensed Photoshop CS6 Extended installation and the local reference file |
| `scale_psd_preserve` | Generate one supported 1074 and cases with an unsupported version, malformed descriptor, and invalid values. Add surrounding blocks and an unparsed tail. Open, perform an unrelated edit and save in both editions. | Supported values are interpreted. Other cases display Default where calibration is available. Each 1074 and neighboring block is preserved byte-for-byte, along with the tail. | `pictura-codec::measurement_scale_preserves_untouched_resource_bytes`, `tst_measurement_scale::preservesCalibrationThroughEditionSave` |
| `scale_psd_replace` | Open a generated opaque 1074 with neighbors. Save after applying a custom value. Repeat from the original and select Default. Undo the reset and save again. | The custom edit emits one readable replacement 1074. Default removes it. Undo restores the original bytes, and neighbors remain intact. | `pictura-codec::measurement_scale_replaces_or_resets_opaque_resource`, `tst_measurement_scale::opaqueResourceResetIsUndoable` |
| `measurement_tsv` | Export reordered columns and a subset of frozen rows with different scales and labels containing Unicode, tab, line breaks, and quotes. | Header and selected rows retain order and recorded values. Quoting and locale-independent numbers match expected UTF-8 bytes. | `pictura-codec::measurement_export_writes_ordered_utf8_tsv` |
| `measurement_export_empty` | Export zero rows to an absent destination and to a path with existing content. | Neither call creates output or changes existing content. | `pictura-codec::measurement_export_empty_selection_has_no_output` |
| `measurement_histograms` | Export a summary histogram, an intervening row without a histogram, and two feature histograms. Include distinct bin counts in ordered channels. | `0.csv` through `2.csv` contain bins 0–255 in channel order. Table cells point to the associated file or stay empty. | `pictura-codec::measurement_export_writes_numbered_histograms` |
| `measurement_without_histograms` | Export rows containing histogram data while omitting the Histogram column. | The table writes successfully and no sibling histogram directory appears. | `pictura-codec::measurement_export_omits_unselected_histograms` |
| `measurement_export_failure` | Test an existing table, an existing required histogram directory, and an injected write error after output creation. | Each reports an error, existing bytes are intact, and incomplete newly created artifacts are removed or reported. | `pictura-codec::measurement_export_preserves_destinations_on_failure` |
| `scale_dialog_inactive` | Open Custom with a changed draft, focus the canvas and switch between views of the same document, then switch documents. Repeat and close its document. | Same-document views and canvas focus keep the draft open. Switching documents or closing the document cancels it without changing any document or history. | `tst_measurement_scale::cancelsDraftOnDocumentChange` |
| `scale_menu_check` | Apply Default, a custom identity ratio with distinct units, equivalent ratios with different entered values, unmatched custom values, and duplicate matching presets. Undo, redo, delete presets, and switch tabs. | The active state checks Default, Custom, or the lexicographically smallest preset matching all three values throughout. Equivalent ratios alone do not match. | `tst_measurement_scale::checksCurrentScale` |
| `scale_resample` | Resample calibrated documents uniformly and nonuniformly through Image Size and transform dispatch, save and reopen, then separately undo and save and reopen. | Each resample resets the scale and indicates recalibration. The resampled save omits 1074. Undo restores the original scale and resource intent, and each saved state reopens accordingly. | `tst_measurement_scale::resampleResetsCalibration` |
| `scale_resize_preserve` | Change resolution without resampling, perform a same-dimension resize, and force a resize failure on a calibrated document. | Calibration and its history state remain unchanged by the no-op and failure, and calibration survives the resolution edit. | `tst_measurement_scale::resizePreservesCalibration` |
| `scale_resample_opaque` | Resample files with opaque 1074 in Standard and Extended, save and reopen. | Original 1074 bytes remain intact and recalibration is indicated. | `tst_measurement_scale::resamplePreservesOpaqueScale` |
| `scale_psd_guides` | Edit guides on a document with untouched 1074, save and reopen. | The guide edit survives and the original 1074 bytes remain intact. | `pictura-codec::measurement_scale_preserves_bytes_with_guide_edit` |
| `scale_perspective` | Warp with unchanged dimensions and test rigid and refused transforms, including opaque calibration. | Distance-changing warps invalidate and indicate recalibration. Rigid and refused warps preserve calibration and opaque state remains available for resource replay. | `tst_measurement_scale::perspectiveWarpNotice`, `pictura-render::perspective_crop_invalidates_only_non_isometric_calibration` |
| `scale_background` | Resize an inactive calibrated document and undo before activation. Repeat and activate before undo. | Undo before activation discards the notice. Otherwise the indication appears on activation and is cleared by Undo. | `tst_measurement_scale::backgroundResampleNotice` |
