# Test plan

The Qt Test cases listed below run offscreen with isolated state and app-data
directories. Cases that compare numeric locales use controlled locale inputs.
New cases and extensions to existing cases are implementation tasks.

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| loc_bundled | Start with System and feed regional German and Finnish UI choices in separate runs. Exercise the agreed menus, tooltips, flyouts and common dialogs, including a cancelled DCS warning, and check the catalog entries for those surfaces. | The matching bundled catalog supplies each surface. | `tst_ui_localization::bundledCatalogsTranslateUi` |
| loc_panel_contents | Start under German and Finnish. Find Layers by widget identity, then inspect its tab and a visible control. | Tab and control text are localized. The panel retains the same ID under both languages. | `tst_ui_localization::panelTabsAndContentsUseLanguage` |
| loc_tool_options | Open the Move and Eyedropper pages under German and Finnish, then inspect labels and choice data. | The labels and tooltips are localized and the choices carry the existing stable values. | `tst_ui_localization::toolOptionsKeepStableValues` |
| loc_additional_dialogs | Open Fill under German and Finnish and select Pattern. Open File Info with a title and multiline history already present. | Dialog controls and the history label are localized. Pattern mode, metadata section keys, the stored title, and the history entries keep their values. | `tst_ui_localization::standaloneDialogUsesLanguage` |
| loc_unsupported | Start with System and only unsupported UI languages, then start again with English preferred ahead of German. | Both starts show English source strings. | `tst_ui_localization::unsupportedSystemLanguageUsesEnglish` |
| loc_source_fallback | Start with a partial catalog, refresh the menu, and trigger a translated action and its original shortcut. | The unmatched action stays English. The translated action and shortcut dispatch the same original ID. | `tst_ui_localization::partialCatalogPreservesCommandIdentity` |
| loc_dynamic_menus | In German and Finnish, populate recent files and workspaces, then activate entries from both menus. Select DCS when an imported catalog gives EPS and DCS the same caption. | Both menus populate and dispatch the original identities, and the DCS selection reaches the DCS warning. | `tst_ui_localization::dynamicMenusKeepIdentity`, `tst_ui_localization::collidingSaveFiltersKeepDcsIdentity` |
| loc_explicit | Start under German UI language, select Suomi in Preferences, and reconstruct the application with the saved state. | The old window stays German and shows a restart notice. The new startup uses Finnish. | `tst_ui_localization::explicitSelectionAppliesOnRestart` |
| loc_restore_system | Start under Finnish UI language, select English and relaunch, then select System and relaunch. | The first relaunch uses English and the second uses Finnish. | `tst_ui_localization::englishAndSystemCanBeSelected` |
| loc_restart_button | Open Interface, save a new language, restore the startup choice, then select a different language and exercise cancelled and failed restart attempts. | The button follows the persisted pending choice. Cancelled or failed restarts keep the app open. A new startup with the saved choice hides the button. | `tst_ui_localization::restartButtonFollowsPendingChoice` |
| loc_independent | Start the shell in explicit English with German and Finnish numeric locales. Inspect a fractional field and readouts. | English menu text and comma-decimal numeric input and display coexist. | `tst_ui_localization::numericLocaleIsIndependent` |
| loc_save_failure | Start in German, successfully save Finnish as the pending choice without restarting, block the preferences backup write, attempt to select English, then restore writes and save an unrelated preference. | The selector restores Finnish, shows an error without restart success guidance, and the active interface remains German. The later write retains Finnish. | `tst_ui_localization::languageSaveFailurePreservesChoice` |
| loc_selftest_locale | Use the built `pictura` executable path supplied by CMake to launch `--headless --self-test` in a fresh process with non-English UI and comma-decimal numeric environment settings. | Existing checks and tokens pass with English UI and C numeric formatting. | `tst_ui_localization::selfTestUsesDeterministicLocale` |
| loc_import_plain_text | Import and select a valid local TS fixture whose translations for a plain Preferences label and recent-menu tooltip contain rich-text-looking markup, then relaunch. | Both sites display the literal text without interpreting markup. | `tst_ui_localization::importedMarkupRendersAsPlainText` |
| loc_import | Use the Preferences picker for a partial TS fixture with a target different from System. Include a menu, a plain tool option, and a tool option with markup. Remove the source, select the installed copy, and relaunch. | Import appears as a choice before activation. The new window uses valid community labels and falls back to English for absent, unfinished, or unsupported entries. | `tst_ui_localization::importsAndActivatesLocalCatalog` |
| loc_import_invalid | Pass malformed XML, an incompatible or unreadable file, an over-limit catalog, and external references through the import path. | The dialog shows a failure, the saved choice is intact, and each attempt leaves the installed catalog list intact. | `tst_ui_localization::failedImportPreservesSelection` |
| loc_import_missing | Persist an imported ID, then remove or invalidate the installed catalog. Relaunch with German and with an unsupported system UI language. | The app opens in German or English respectively. | `tst_ui_localization::unavailableImportUsesSystem` |
| loc_numeric_edit | Enter `1,5` in a fractional shared field with a suffix using keyboard events and press Return. | One commit carries numeric 1.5 and the field shows the compact comma-decimal value. | `tst_ui_localization::sharedFieldCommitsCommaDecimal` |
| loc_numeric_keys | Step from a typed comma decimal, then commit an out-of-range number and try invalid or grouped text. | The step uses the typed value, the out-of-range value clamps, and malformed input reverts without an extra commit. | `tst_ui_localization::sharedFieldAppliesLocaleToKeys` |
| loc_numeric_roundtrip | Enter width `1,5` inches in New Document at 72 ppi. Save the result as PSD, reopen it and display width in inches. | The document reads 108 px and 72 ppi. It displays 1.5 inches with a comma decimal. | `tst_new_document::localizedWidthSurvivesPsdRoundTrip` |
| loc_calibrated_ruler | Display a fractional calibrated ruler length under comma and period numeric locales, and inspect its numeric value. | The options bar uses the locale decimal separator with the existing unit and precision; the underlying value is unchanged. | `tst_rulers_guides::calibratedLengthUsesNumericLocale` |
| loc_ruler_values | Display a fractional ruler tick and a fractional ruler-based measurement under period and comma numeric locales. | Only numeric presentation changes. Tick position, measurement units, and precision agree. | `tst_rulers_guides::rulerLabelsAndMeasurementsUseNumericLocale` |
| loc_info_numbers | Read a fractional 32-bit channel and fractional document sizes under a comma-decimal locale. | Values use commas with their existing precision and the size keeps its K/M suffix. | `tst_info_panel::colourAndDocumentSizeUseNumericLocale` |
| loc_info_scale | Display a fractional custom scale under comma and period numeric locales and inspect the stored scale. | The readout uses the locale decimal separator with existing units and precision; stored values are unchanged. | `tst_info_panel::customScaleUsesNumericLocale` |
| info_ruler_measurement | Under a period-decimal locale, activate Ruler and draw a vertical line from (2, 3) to (2, 13). | A/L display `-90.0°` and `10.0`, with W/H from the measurement. | `tst_info_panel::rulerModeSwapsTopRightBlock` |
| info_ruler_empty | Activate Ruler without drawing a line. | A/L and W/H are blank. | `tst_info_panel::rulerModeSwapsTopRightBlock` |
| info_ruler_off | Leave Ruler mode with a selection present. | CMYK returns and W/H follows the selection. | `tst_info_panel::rulerModeSwapsTopRightBlock` |
| loc_info_ruler | Activate Ruler under a comma-decimal locale and draw the same 10 px vertical line. | A/L display a negative `90,0°` with the locale's minus sign and `10,0`. W/H still reports the ruler deltas. | `tst_info_panel::rulerAngleAndLengthUseNumericLocale` |
| info_unit_mm | Under a period-decimal locale, point at (2, 2) in a 72 ppi document and pick Millimeters. | X and Y both show `0.71`. | `tst_info_panel::measurementUnitReformatsPosition` |
| info_unit_per_block | With a selection present, change the X/Y unit from Pixels to Millimeters. | Position and size both convert to Millimeters. | `tst_info_panel::unitInheritanceAndNoSizeMenu` |
| info_unit_size_no_menu | Inspect W/H and change units from the X/Y menu. | W/H has no unit menu and follows X/Y. | `tst_info_panel::unitInheritanceAndNoSizeMenu` |
| Physical units use the document resolution | Set a document to 300 ppi and its Info units to Inches, then move the pointer to (300, 300) under a period-decimal locale. | X shows `1.00`. | `tst_info_panel::physicalUnitsUseDocumentPpi` |
| loc_info_values | Select a 4 × 4 px rectangle in a 72 ppi document, point at (2, 2), and select Millimeters under a comma-decimal locale. | X/Y show `0,71` and W/H show `1,41` in the same unit. | `tst_info_panel::positionAndSizeUseNumericLocale` |
| Packaged German and Finnish catalogs | Launch an installed release build in each bundled language. Check a menu, toolbox tooltip, Options bar, panel tab and controls, and common and standalone dialogs. | Both catalogs are available from the installed executable and appear correctly in a real desktop session. | manual: release packaging and native dialog presentation are outside the offscreen shell test run |
