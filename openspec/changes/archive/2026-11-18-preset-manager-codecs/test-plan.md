# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `preset_codec_import` | Decode project-generated fixtures for ACO, ASE, ABR, GRD, ASL, PAT, SHC, CSH, and TPL using the advertised variants. | Check order, names and each format's typed payload, including source color models, linked brush samples, gradient midpoints, effect values, tile pixels, corner flags, Bézier controls, and tool options. | `pictura-codec::preset_libraries_decode_supported_payloads` |
| `preset_codec_partial` | Decode usable entries adjacent to an unsupported entry or setting at a known boundary, including unsupported gradient stops. Include a descriptor case without a safe recovery boundary. | Usable values survive, diagnostics identify failures, and the decoder never guesses its way into a subsequent record. | `pictura-codec::preset_libraries_report_partial_import` |
| `preset_codec_invalid` | Probe wrong types and versions. Decode truncated data, excessive nesting or sizes, and invalid record counts or lengths. | A bounded error identifies the failure. No panic, overread or oversized allocation occurs. | `pictura-codec::preset_libraries_reject_invalid_input` |
| `preset_codec_native` | Round-trip reordered sets of all eight types with Unicode and duplicate names, bounded opaque data, and a valid empty set. | Type, order, names, typed payloads, opaque data, and explicit emptiness survive. | `pictura-codec::preset_native_sets_round_trip` |
| `preset_codec_swatch_export` | Export and decode named swatches of every supported color model through both formats. | Names and source models survive, and components agree within each format's precision. | `pictura-codec::preset_swatches_round_trip_exchange` |
| `preset_codec_csf` | Decode a generated CSF fixture with a missing profile reference and round-trip its representable values. Exercise unsupported fields or variants and the maximum tag count. | The values and references are returned independently of app state and profile discovery. Unsupported data or writes produce a diagnostic. | `pictura-codec::csf_round_trips_supported_settings`, `pictura-codec::csf_tag_limit_is_enforced_on_export` |
| `preset_codec_cs6_oracle` | In CS6, author minimal libraries and Color Settings files for the advertised variants. Import them through Pictura or the codec harness. Open advertised Pictura Adobe exports in CS6 and compare the supported values. | The supported variants interoperate in the advertised directions and the documented limits agree with the observed results. | manual: The independent oracle needs a licensed CS6 installation and locally authored files outside the repository. A generated fixture cannot establish that CS6 accepts Pictura output. |
| `preset_ui_pages` | Open the Manager from Edit without a document. Inspect the type selector and view menu while switching between pages. | Exactly eight pages appear, and all five common views plus the brush-only Stroke Thumbnail are available where expected. | `tst_preset_manager::opensWithEightTypesAndViewModes` |
| `preset_ui_edit` | Load duplicate-named swatches, reorder via the model's drag path, rename with Unicode after a pending import, and delete a selected row with duplicate displayed swatches. Inspect another window's Swatches panel. | The right entries are changed and both windows show the same order and names. | `tst_preset_manager::editsDuplicateNamesByIdentity` |
| `preset_ui_library_commands` | Drive Load, Replace, Reset with Append, and Reset with Replace using distinct starting sets. | Each command gives the correct resulting list and order. | `tst_preset_manager::loadsReplacesAndResets` |
| `preset_ui_import_errors` | Reject and accept a partial result, cancel a file chooser, and try Replace with zero usable entries or an invalid file. | Only accepting the partial result changes the set, which matches the reported usable entries. | `tst_preset_manager::commitsOnlyAcceptedImports` |
| `preset_ui_async` | Hold an import on a controlled worker during encoding and staging, switch pages or start a newer import, then release the stale worker and process its reply. | The interaction completes while the worker is pending, and neither page receives the stale result. | `tst_preset_manager::ignoresCancelledOrSupersededImport` |
| `preset_ui_save` | Save a non-contiguous selection, then a page with no selection. Force a failure before a further export commits over the first file. | The files reload in library order with the right subsets. A failed commit preserves the original bytes. | `tst_preset_manager::savesSelectedSetsAtomically` |
| `preset_ui_persist` | Seed a named legacy palette and separately an empty legacy palette. Migrate, make same-count rename and reorder edits, empty another list, and reopen under the same isolated state home. | Legacy content and emptiness migrate correctly. Edits, order and intentional emptiness survive subsequent restarts. | `tst_preset_manager::migratesAndPersistsCurrentSets` |
| `preset_ui_discovery_reset` | Drop a file into an isolated per-type data directory. Restart, inspect the matching page, and confirm preference reset after its warning. | The file is discoverable before and after reset, while current-list edits are cleared only after confirmation. | `tst_preset_manager::discoversLibrariesAcrossPreferenceReset` |
| `preset_ui_apply` | Import and apply known payloads through the Swatches panel, brush picker, gradient controls, Layer Style and contour controls, Pattern Stamp and layer pattern pickers, Custom Shape, and the tool-preset picker. | Check actual colors, paint coverage, gradient stops or output, effect and contour values, tile pixels, vector geometry, and restored tool options. | `tst_preset_manager::appliesImportedSwatchBrushAndToolOptions`, `tst_preset_manager::appliesImportedGradientStyleAndContour`, `tst_preset_manager::appliesImportedPatternsAndCustomShape` |
| `preset_ui_snapshot` | Change the current library while a sampled brush stroke is open and attempt to record it as an Action. Apply an imported pattern to a document, change the library, and save and reopen the document. | The stroke uses its captured sample, the reopened document renders the embedded tile, and library mutations create no document History state. | `tst_preset_manager::libraryEditsPreserveStrokeAndDocumentContent`, `pictura-app::sampled_brush_is_not_recorded_as_a_replayable_paint_stroke` |
| `preset_ui_empty_set` | Save an empty native set, Load and Replace a populated set, and attempt failed and partial zero-usable imports. | Load is a no-op, Replace clears, and failures preserve the list. | `tst_preset_manager::emptyNativeSetLoadAndReplace` |
| `preset_ui_migration_reset` | Migrate legacy custom swatches, reset and restart; separately inject candidate-write or manifest-switch failure and check that obsolete generations are reclaimed safely. | Defaults survive restart; failure preserves the entire previous generation and legacy data. | `tst_preset_manager::migrationResetSurvivesRestart` |
| `sw_persist_restart` | Add a swatch and create a window. | The window shows the swatch. | `tst_swatches_panel::addedSwatchesSurviveARestart` |
| `sw_persist_empty` | Empty swatches and create a window. | The panel stays empty. | `tst_swatches_panel::emptyPanelSurvivesARestart` |
| `sw_persist_default` | Start without native or legacy swatches. | The default palette appears. | `tst_swatches_panel::freshStoreUsesDefaultPalette` |
| `sw_persist_unrelated_save` | Save an unrelated setting. | Stored swatches remain unchanged. | `tst_preset_manager::swatchPersistenceRegressions` |
| `sb_export_sections` | Export after populating session, workspaces, adjustment, action and PDF presets. | All sections and preset files are included. | `tst_settings_backup::exportCarriesEveryStore` |
| `sb_export_unknown_keys` | Export a session with an unknown key. | The key is unchanged. | `tst_settings_backup::unknownSessionKeysSurvive` |
| `sb_export_excludes_caches` | Export with GPU caches and recovery present. | They are excluded. | `tst_settings_backup::exportExcludesCaches` |
| `sb_import_rejects_malformed` | Import malformed or wrongly formatted JSON. | No import is staged or store changed. | `tst_settings_backup::malformedFileIsRefused` |
| `sb_import_rejects_newer` | Import a newer format version. | It is rejected without staging. | `tst_settings_backup::newerFormatIsRefused` |
| `sb_import_rejects_unsafe_names` | Import an unsafe workspace or preset path. | Import is refused without outside writes. | `tst_settings_backup::unsafeNamesAreRefused` |
| `sb_import_backs_up` | Stage a valid import. | Timestamped backup exists. | `tst_settings_backup::importBacksUpCurrentSettings` |
| `sb_import_sanitizes` | Import missing recent file and off-screen geometry. | Both are removed from pending session. | `tst_settings_backup::importSanitizesMachineSpecificValues` |
| `sb_import_stages` | Import valid settings while running. | Pending file exists, live session is unchanged, and restart is offered. | `tst_settings_backup::validImportIsStaged` |
| `sb_apply_all` | Apply a pending import with all original sections. | Stores update and pending file is removed. | `tst_settings_backup::pendingImportAppliesEverySection` |
| `sb_apply_absent` | Apply a session-only pending import. | Workspace and preset stores stay unchanged. | `tst_settings_backup::absentSectionsAreLeftAlone` |
| `sb_apply_corrupt` | Start with an invalid pending file. | It is quarantined and existing settings load. | `tst_settings_backup::corruptPendingIsQuarantined` |
| `sb_round_trip` | Export, change, import and apply the stores. | The stores match the export. | `tst_settings_backup::roundTripRestoresEveryStore` |
| `sb_current_lists_round_trip` | Export populated, default and empty current lists, edit all types at the destination, stage and apply import. | All eight exported lists return exactly, including the formerly default type; pre-import backup captures prior lists. | `tst_settings_backup::currentPresetListsRoundTrip` |
| `sb_current_lists_absent` | Apply an older backup without the section and a section missing a type. | Corresponding lists remain unchanged. | `tst_settings_backup::currentPresetListsAbsent` |
| `sb_current_lists_invalid` | Import malformed or oversized list data or force staging failure with an existing pending import. | Failure leaves live stores and the previous pending import intact. | `tst_settings_backup::currentPresetListsInvalid` |
| `sb_current_lists_export_failure` | Export over an existing destination with an unreadable list and an oversized full backup. | Both fail visibly and preserve destination bytes. | `tst_settings_backup::currentPresetListsExportFailure` |
| `sb_current_lists_retry` | Inject a startup write or manifest-switch failure after staging part of the candidate, then retry. | The error is reported, startup loads the previous complete lists, and pending survives; retry publishes all present lists together. | `tst_settings_backup::currentPresetListsRetry` |
