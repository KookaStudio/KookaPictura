# Test Plan

Pure-refactor acceptance plan for `document-composite-cache`. There is no spec
delta (`skip_specs: true`); one row per check. All coverage is automated Rust
except the static "no second store/patch path" check, which is manual.

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| Full refresh stores the composite | Build an RGB document with layers; call the render cache's full refresh; read `doc.composite`. | The composite has document dimensions and equals a full composite of the stack. | `pictura-render::a_full_refresh_stores_the_composite` |
| Region refresh patches the composite | Build an RGB document; seed the cache with a marker buffer; refresh a region smaller than the canvas; compare pixels inside and outside. | The region is written at its origin (equal to the full composite) and every pixel outside keeps the marker. | `pictura-render::a_region_refresh_patches_the_composite` |
| Region equals the full slice and outside is unchanged | Build a multi-layer RGB fixture; seed the cache with a marker; hide a layer; compute the new full composite; refresh a sub-region; compare the patched region against the full slice and the outside pixels against the marker. | The refreshed region equals the new full-composite slice byte for byte and every outside pixel keeps the marker (this also covers the deleted visibility-region path). | `pictura-render::an_rgb_region_patch_matches_the_full_slice` |
| Grayscale keeps one plane | Build a grayscale document with a layer; refresh the full cache; assert the whole one-plane composite equals the full composite's plane 0; change the gray layer value, then patch a region. | The composite keeps one colour plane; the whole stored plane equals the full grey plane, and the patched region equals the new full plane while the outside keeps the old plane. | `pictura-render::a_grayscale_patch_keeps_one_plane` |
| Banded composite is the patch reference | Build a document taller than two compositing bands; pin the banded full composite to the single-canvas composite; seed a marker, hide the top layer, recompute, and patch a region. | The patched region equals the new banded composite, the outside keeps the marker, and the banded composite equals the single-canvas composite. | `pictura-render::a_banded_composite_is_the_patch_reference` |
| Whole-document region replaces the composite | Seed the cache with a marker, hide a layer, then refresh a region equal to the canvas. | The whole-document region equals the new full composite and the seeded marker bytes are unchanged (no in-place mutation). | `pictura-render::a_whole_document_region_replaces_the_composite` |
| Region patch preserves a shared banded plane | Store the full composite, snapshot it, mutate the base layer, patch a sub-region, then read both. | The snapshot's bytes are unchanged, the patched region equals the new full slice, and the outside keeps the snapshot. | `pictura-render::a_region_patch_preserves_a_shared_banded_plane` |
| Layerless full refresh stores the embedded composite | Build an RGB document with no layers and a 3-channel embedded composite; refresh the full cache. | The result matches the old `store_composite(current_buffer(doc))` behavior: RGB becomes 4 channels with the colour planes equal to the embedded composite; a non-RGB document keeps its plane count. | `pictura-render::a_layerless_full_refresh_stores_the_embedded_composite` |
| Layerless region refresh is a no-op | Build an RGB document with no layers; refresh a region. | `doc.composite` is unchanged and the call returns no result (unreachable in practice). | `pictura-render::a_layerless_region_refresh_is_a_noop` |
| Rendered buffer is stored without recompositing | Store/patch a distinctive marker buffer that cannot be produced by compositing the stack; read the cache. | The cache matches the marker buffer exactly and no compositor runs. | `pictura-render::a_rendered_buffer_is_stored_without_recompositing` |
| Read-only render does not write the cache | Seed the cache with a marker, call `render` for a region, and read `doc.composite` before and after. | The returned region matches the true composite slice and the maintained composite still equals the marker. | `pictura-render::render_does_not_write_the_cache` |
| Size mismatch is not shape-valid | Give a document a composite whose dimensions differ from the document; ask the render cache whether it is shape-valid. | The cache reports not shape-valid. | `pictura-render::a_size_mismatch_is_not_shape_valid` |
| Non-RGB or non-four-channel is not shape-valid | Give an RGB document a non-four-channel composite, then a non-RGB document a four-channel composite; ask the render cache whether each is shape-valid. | Both report not shape-valid. | `pictura-render::a_non_rgb_or_non_four_channel_composite_is_not_shape_valid` |
| Plane expansion matches the `rgba_frame` helper | Store a rendered 4-channel buffer into a grayscale document and an RGB document. | The grayscale composite keeps one plane; the RGB composite is four channels; both match the `rgba_frame` expansion. | `pictura-render::store_expands_planes_like_rgba_frame` |
| Grayscale store keeps the red plane | Store a 4-channel buffer with distinct R/G/B values into a grayscale document. | The one-plane composite equals the rendered R plane. | `pictura-render::a_grayscale_store_keeps_the_red_plane` |
| Clipping region patch matches the full slice | Build a base layer and a clipping top layer; seed the cache with a marker, change the base colour, refresh the clipping region. | The patched region equals the new full composite and the outside keeps the marker. | `pictura-render::a_clipping_region_patch_matches_the_full_slice` |
| Edit path calls the cache once | Commit a bounded edit and a full edit through the app transaction with a test-only refresh counter. | Each commit calls the cache exactly once; the bounded outcome reports its damaged rectangle and the full outcome reports `None` (`crates/pictura-app/src/cxxqt_object/edit.rs:317-321`). | `pictura-app::one_commit_refreshes_once_through_the_cache` |
| Empty region edit rebuilds fully | Commit an `Edit::Regions` with an empty rectangle list and no hint. | The edit path upgrades it to a full rebuild (`crates/pictura-app/src/cxxqt_object/edit.rs:296-300`). | `pictura-app::an_empty_region_edit_rebuilds_fully` |
| Mask present leaves the composite unchanged | Start a mask stroke, seed the cache with a marker, present a display region through the read-only render path, and read the maintained composite before and after. | The returned region matches the true composite slice, and the maintained composite still equals the marker. | `pictura-render::render_does_not_write_the_cache`, `pictura-app::a_mask_present_leaves_the_composite_unchanged` |
| Job writers store/patch through the cache | Run the filter and image-adjust job paths against a cloned document and apply the pre-rendered buffer to the live document. | The live `doc.composite` is written through `store`/`patch` and equals a full recomposite. | `pictura-app::job_writers_store_and_patch_through_the_cache` |
| No second store/patch path | Delete the app helpers and run the `rg`/guard check in task 3.6. | No app-side definition of `store_composite`, `patch_composite_region`, `patch_buffer_region`, or `rgba_frame` remains. | manual: verified by deleting the app helpers and the rg/guard check in task 3.6 |
