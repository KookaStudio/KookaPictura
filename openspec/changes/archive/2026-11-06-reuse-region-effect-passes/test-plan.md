# Test plan

Coverage names below are implementation targets, not claims that missing tests
already exist. Proposal generation adds no test code. All rows are automated;
new tests are listed in tasks.md before their implementation tasks. Existing
tests remain in place and must retain their assertions.

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| A region pass equals the full pass | Generate every effect family; compare bounded passes and cold/warm region composites against full slices. | Exact pass samples and CPU output bytes for every family. | `pictura-render::region_pass_equals_full_pass_for_every_family`, `pictura-render::region_effect_families_match_cold_and_warm_slices` |
| A full composite still reuses its cached pass | Warm a non-pattern styled document, retain its pass Arc, composite whole again. | Same pass Arc, cache hit, no new pass construction. | `pictura-render::full_composite_reuses_ready_effect_pass` |
| A stroke present rebuilds only the dab and its reach | Warm a canvas-sized styled layer, edit its alpha as a dab, request a short present region; inspect transient bounds and compare full slice. | Prior pass rejected; grown build bounds and clipped output; exact current pixels. | `pictura-render::edited_styled_region_rebuilds_after_warm` |
| An overlay source is bounded by the region | Request cold short regions of canvas-sized gradient and pattern overlay layers; inspect generated source dimensions. | Source dimensions equal bounded pass dimensions and output equals full slice. | `pictura-render::cold_overlay_region_sources_stay_bounded` |
| A banded sub-region reuses one pass | Purge, composite a tall styled region in bands, inspect per-key build count, compare full output. | One whole-layer pass build, byte-identical output. | `pictura-render::banded_sub_region_reuses_one_pass` |
| A sub-region pass is not retained | Composite a short cold region; compare pass-entry counts before/after. | No retained region entry. | `pictura-render::sub_region_pass_is_not_retained` |
| rep_warm | Warm whole passes, request offset short regions crossing layer/effect edges, compare Arc identity, the per-key build count at the actual builder (including transient builds), and full slices. | Whole-pass reuse, no increase in the all-build count, exact pixels. | `pictura-render::warm_short_region_reuses_ready_effect_pass`, `pictura-render::region_effect_families_match_cold_and_warm_slices` |
| rep_cold | Purge; request a short non-pattern styled region before any full composite; repeat after eviction and over-budget removal. | Bounded transient passes, no new whole-pass entry, full-slice equality. | `pictura-render::cold_short_region_builds_transient_effect_pass`, `pictura-render::ready_pass_probe_misses_unavailable_entries` |
| rep_inflight | Hold a controlled same-key whole build in Building state; request the region before releasing the build; include probe Empty case. | Region finishes through transient passes while whole build is held; exact output; no publication under whole key. | `pictura-render::region_does_not_wait_for_inflight_effect_pass`, `pictura-render::ready_pass_probe_misses_unavailable_entries` |
| rep_edit | Warm old passes, edit channel then raster mask in separate presents; keep a second unchanged styled layer warm. | Edited layer builds bounded fresh passes; unchanged layer reuses; both results equal fresh full slices. | `pictura-render::edited_styled_region_rebuilds_after_warm` |
| rep_pattern | Composite with a referenced pattern, edit the document pattern pixels without changing style descriptors, composite another short region. | Both presents rebuild, no pass retention, changed pixels agree with current full slices. | `pictura-render::pattern_region_rebuilds_after_pattern_edit` |
| rep_profile | Run the ignored profile alone using design.md's fixed fixture and regions, one-worker rayon pool, three warm-up rounds and nine alternating-order measured rounds; sum adjacent 128-row times and compare with their exact 256-row union. Check pixels outside timed intervals. | Median summed-pair time divided by median union time is at most 4.0; four source-cache hits per warm short call include two pass hits, zero warm misses/decodes; exact full slices. Unit all-build counts separately prove zero warm builds. | `pictura-render::warm_bevel_region_replay_profile`, `pictura-render::warm_short_region_reuses_ready_effect_pass` |
| Probe cache accounting | Probe missing and ready keys and force eviction after a hit; inspect entries, bytes, LRU, and metrics. | Miss creates nothing; hit records reuse and refreshes LRU without changing resident bytes or reviving evicted content. | `pictura-render::ready_pass_probe_preserves_cache_accounting` |
