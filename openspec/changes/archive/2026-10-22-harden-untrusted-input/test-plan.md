# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `ui_psb_header` | Read a 300000² PSB with a tiny ZIP composite | Typed error; peak request under 4 MiB | `pictura-codec::a_psb_header_past_the_budget_is_refused_before_allocating` |
| `ui_composite_total` | Read a 56-channel 30000² PSD | Typed error before the image data | `pictura-codec::a_composite_over_the_document_total_is_refused`, `pictura-codec::the_document_total_is_bounded` |
| `ui_layer_rect` | Read layers 2³¹ wide (RLE, ZIP, mask, depth 1) and an `i32`-spanning rect | Typed error; peak under 4 MiB; extents saturate | `pictura-codec::a_huge_rle_layer_rect_is_refused`, `pictura-codec::a_huge_zip_layer_rect_is_refused`, `pictura-codec::a_huge_mask_rect_is_refused`, `pictura-codec::a_huge_bitmap_layer_rect_is_refused`, `pictura-codec::a_rect_spanning_the_whole_i32_range_is_refused`, `pictura-core::psd_rect_extent_saturates_instead_of_overflowing` |
| `ui_document_total` | Read 8 and 2 layers of 200² under a 64 KiB budget | 8 fails, 2 opens | `pictura-codec::layer_planes_count_against_the_document_total`, `pictura-codec::one_allocation_over_the_cap_is_refused`, `pictura-codec::an_overflowing_product_is_refused` |
| `ui_canvas_opens` | Read a layered 16000² RGB PSD with no merged image | Opens | `pictura-codec::a_canvas_class_document_header_still_opens` |
| `ui_group_depth` | Read 65 and 64 nested groups | 65 fails; 64 opens 64 deep | `pictura-codec::group_nesting_is_capped`, `pictura-codec::a_folder_without_a_divider_is_an_empty_group` |
| `ui_pdf_inflate` | Decode streams over the per-stream limit and the file budget; inflate an over-limit payload | Each decodes to nothing; under-limit ones decode | `pictura-codec::stream_inflation_is_bounded_per_stream_and_per_file`, `pictura-codec::an_embedded_payload_past_the_limit_is_refused`, `pictura-codec::a_bounded_read_refuses_more_than_the_limit` |
| `ui_pdf_numbers` | Huge `/Columns`, overflowing rows, `/Colors 4096`, `/N i64::MAX` with a negative offset, a 2⁶²+1-wide editing composite | Refused or skipped, no panic; sane values decode | `pictura-codec::hostile_predictor_parameters_are_refused`, `pictura-codec::hostile_object_stream_counts_and_offsets_are_harmless`, `pictura-codec::an_overflowing_composite_size_is_refused` |
| `ui_pdf_aes` | Decrypt AESV2 with `/Length 40`; AES-CBC with a 10-byte key | Unsupported; empty output | `pictura-codec::a_short_aes_key_is_unsupported`, `pictura-codec::an_aes_key_of_the_wrong_length_decrypts_to_nothing` |
| `ui_pdf_depth` | Parse 200 000 nested arrays, a 5 000-level page tree, a self-kid Pages node | Ends without overflow or hang; at-cap nesting reads | `pictura-codec::deep_nesting_does_not_overflow_the_stack`, `pictura-codec::deep_page_and_form_trees_end`, `pictura-codec::a_self_referential_page_tree_ends` |
| `ui_pdf_counts` | List images of a page drawing 520 | 500 listed | `pictura-codec::image_listing_is_capped` |
| `ui_pdf_render_size` | Scale a `u32::MAX` image; crop `u32::MAX`; wrap a −5-wide image | Within budget; empty; not wrapped | `pictura-codec::an_image_render_is_scaled_into_the_budget`, `pictura-codec::a_crop_over_the_budget_is_empty`, `pictura-codec::a_non_positive_image_size_is_not_wrapped` |
| `ui_png_decode` | Decode a `u32::MAX`-square PNG and a 1×1 with 1 MiB extra IDAT | Refused; one pixel decoded | `pictura-codec::a_header_over_the_budget_is_refused_before_inflating`, `pictura-codec::inflation_stops_at_the_rows_the_header_implies` |
| `ui_gs_timeout` | Run a fake `gs` that sleeps with a 200 ms timeout | Killed; error names the timeout | `pictura-codec::a_run_that_never_ends_is_killed` |
| `ui_gs_limits` | Fake `gs` writes 40 MB, or prints `ulimit -f` / `ulimit -v` | Output capped; both limits 8388608 | `pictura-codec::runaway_output_is_capped`, `pictura-codec::the_child_runs_under_resource_limits` |
| `ui_gs_version` | Fake `gs --version` prints 9.26, then 10.06.0 | Refused, then accepted | `pictura-codec::an_old_ghostscript_is_refused` |
| `ui_gs_separator` | Permit an input named `a:b.pdf` | Copy without `:`; arguments rewritten | `pictura-codec::a_path_holding_the_list_separator_is_read_through_a_copy` |
| `ui_gs_real` | File > Open a PDF whose content stream is `{ } loop` with real Ghostscript installed | After 5 minutes the open fails with "did not finish"; the UI stays responsive throughout | manual: the real 300 s timeout is too long for CI, and the fake-interpreter test covers the kill path |
| `ui_qt_decode` | Decode valid 29999×1, 30001×1, 1×30001 PNGs through Qt; read a file over a cap | Only 29999×1 decodes; capped read refuses | `tst_untrusted_input::qtDecodeRefusesSizesOverTheBudget`, `pictura-app::a_capped_read_refuses_a_larger_file` |
| `ui_thumb_unpack` | Unpack thumbnails declaring hostile sizes | None unpacked; a correct 2×2 is | `tst_untrusted_input::thumbnailUnpackRejectsHostileSizes` |
| `ui_fuzz` | Mutation passes over PSD, PDF, and PNG seeds | No panic; no allocation over 64 MiB | `pictura-codec::mutated_psds_never_panic_or_overallocate`, `pictura-codec::mutated_pdfs_never_panic_or_overallocate`, `pictura-codec::mutated_pngs_never_panic` |
| `ac_token_required` | Send `status` with no, wrong, short, then the session token | Three `unauthorized` with id; last ok | `tst_untrusted_input::controlRequestsNeedTheSessionToken` |
| `ac_token_file` | Listen over a planted token symlink; inspect the file; shut down | Regular 0600 file with the token; target untouched; tokens differ; removed on shutdown | `tst_untrusted_input::controlTokenFileIsOwnerOnly`, `tst_untrusted_input::controlTokenFileNeverFollowsAPlantedLink` |
| `as_planted_link` | Save over a path whose `.tmp` sibling is a symlink | Link target unchanged; path holds new bytes | `pictura-app::a_planted_temp_symlink_is_not_followed` |
| `as_replace` | Save over an existing file; draw two temp names | New bytes, no temp left; names differ | `pictura-app::an_atomic_write_replaces_the_target_and_leaves_no_temp_file`, `pictura-app::temp_names_are_unpredictable` |
