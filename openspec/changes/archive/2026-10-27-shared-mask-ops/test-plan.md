# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `msk_morph_radius_zero` | Dilate and erode a random plane at radius 0 with both borders | The plane is returned unchanged | `pictura-core::morph_radius_zero_is_the_identity` |
| `msk_morph_zero_edge` | Erode the all-selected plane with the zero border | Every border sample within the radius becomes 0 | `pictura-core::morph_zero_border_erodes_from_the_edge` |
| `msk_morph_clamp_edge` | Erode the all-selected plane with the clamp border | Every sample stays at full coverage | `pictura-core::morph_clamp_border_keeps_the_edge` |
| `msk_morph_random` | Dilate and erode random planes at radii 1, 3, 100 and both borders, including planes narrower or shorter than the radius | Every sample equals the naive square scan | `pictura-core::morph_matches_naive_at_every_radius_and_border` |
| `msk_morph_scale` | Run the full-document profile at radius 1 and radius 100 | Per-sample cost stays within a constant factor; the profile prints both timings | manual: wall-clock ratio printed by the ignored `pictura-select/tests/profile.rs` harness, not asserted in CI |
| `msk_median_sorted` | Median-filter random planes at radii 1, 4, 100 and radii larger than both dimensions, and compare each window with its sorted clamped window | Every sample equals the middle element | `pictura-core::median_matches_the_sorted_window` |
| `msk_median_radius_zero` | Median-filter a plane at radius 0 | The plane is returned unchanged | `pictura-core::median_radius_zero_is_the_identity` |
| `msk_median_majority` | Radius 1 on an isolated selected pixel and on a lone hole in a selected plane | The isolated pixel is removed and the hole is filled | `pictura-core::median_binary_majority_removes_and_fills` |
| `msk_median_scale` | Run the profile at radius 10 and radius 100 | Per-sample cost stays within a constant factor; both timings print | manual: wall-clock ratio printed by the ignored profile harness, not asserted in CI |
| `msk_flood_naive` | Flood random planes with random predicates and compare with a `VecDeque` breadth-first fill, including multi-seed inputs | The masks are identical | `pictura-core::flood_matches_the_naive_queue`, `pictura-core::flood_multi_seed_matches_the_naive_queue` |
| `msk_flood_boundary` | Seed inside a region whose neighbours fail the predicate | Only the connected accepted region is marked | `pictura-core::flood_stops_at_the_predicate_boundary` |
| `msk_flood_frontier` | Flood a uniform 1000×1000 plane and inspect the peak frontier | The mask is fully selected and the peak frontier is at most twice the plane height | `pictura-core::flood_frontier_is_bounded_by_spans` |
| `msk_flood_bad_seed` | Seed set with no in-plane source | The flood returns `None` | `pictura-core::flood_rejects_an_out_of_plane_seed` |
| `msk_similar_many_colours` | Similar on a synthetic image with thousands of distinct selected colours | The selection equals the per-colour reference scan | `pictura-select::similar_matches_the_per_colour_scan` |
| `msk_similar_zero_tolerance` | Similar with tolerance 0 | Only exact colour matches are added | `pictura-select::similar_zero_tolerance_selects_only_the_exact_colour` |
| `msk_similar_soft` | Similar with an intermediate-coverage selected pixel and an in-tolerance neighbour | Coverage is preserved and the neighbour becomes 255 | `pictura-select::similar_preserves_soft_selected_coverage` |
| `msk_similar_size_mismatch` | Run Similar with a selection and image of different dimensions | The call returns an error and the selection is unchanged | `pictura-select::grow_similar_size_mismatch_errors` |
| `msk_similar_empty_selection` | Run Similar on an empty selection | No pixel is added and the selection is unchanged | `pictura-select::similar_with_an_empty_selection_adds_nothing` |
| `msk_similar_scale` | Run the profile with 10 and with 10 000 reference colours | Per-pixel cost stays within a constant factor; both timings print | manual: wall-clock ratio printed by the ignored profile harness, not asserted in CI |
| `msk_site_selection` | Run the existing selection modify tests after the migration | Expand/Contract round-trip, the centred border band, the canvas-edge contract and inner band, and Smooth results are unchanged | `pictura-select::expand_contract_roundtrip`, `pictura-select::border_is_centered_band`, `pictura-select::contract_all_shrinks`, `pictura-select::border_edge_has_inner_band`, `pictura-select::smooth_removes_isolated_and_keeps_majority`, `pictura-select::expand_matches_imagemagick_dilate` |
| `msk_site_wand_grow` | Run Magic Wand in contiguous and global modes and Grow after the flood migration | Selections match the previous results and Grow preserves intermediate coverage | `pictura-select::magic_wand_contiguous_and_global`, `pictura-select::grow_is_contiguous_similar_is_global`, `pictura-select::grow_preserves_soft_selected_coverage` |
| `msk_site_filters` | Run the filter kernel tests and digest suite after the migration | Maximum/Minimum/Median outputs and their digests are unchanged | `pictura-filters::morphology_radius_zero_is_noop`, `pictura-filters::morphology_runs_over_the_alpha_plane_too`, `pictura-filters::median_removes_salt_and_pepper_and_keeps_step_edge`, `pictura-filters::row_parallel_kernels_keep_their_serial_bytes` |
| `msk_site_effects` | Run the layer-effect tests after the f32 migration | Spread and choke outputs match the retained pre-migration scan, and the exact-pixel effect tests pass | `pictura-render::spread_and_choke_mattes_match_the_pre_migration_scan`, `pictura-render::spread_dilates_the_shadow`, `pictura-render::spread_hardens_the_edge`, `pictura-render::spread_extends_and_hardens_the_glow`, `pictura-render::choke_narrows_the_inner_band`, `pictura-render::choke_strengthens_the_glow_toward_the_edge`, `pictura-render::parallel_composite_equals_sequential` |
| `msk_site_paint` | Run the bucket and selection-stroke tests after the migration | Fill masks and stroke bands are unchanged | `pictura-paint::a_contiguous_fill_stops_at_the_wall_and_a_global_one_does_not`, `pictura-paint::the_outside_band_stops_at_the_selections_edge` |
| `msk_parallel_deterministic` | Run each kernel in a one-thread and a many-thread rayon pool | The outputs are identical | `pictura-core::kernels_agree_under_one_and_many_threads` |
| `msk_perf_similar` | Run the 6000×4000 profile with 10 000 reference colours | The printed Similar time is under 100 ms | manual: the ignored profile prints the timing; wall-clock thresholds are reviewed, not asserted in CI |
| `msk_perf_smooth` | Run the 6000×4000 profile with Smooth at radius 100 | The printed Smooth time is under 1 s | manual: the ignored profile prints the timing; wall-clock thresholds are reviewed, not asserted in CI |
| `msk_perf_expand` | Run the 6000×4000 profile with Expand at radius 100 | The printed Expand time is under 300 ms | manual: the ignored profile prints the timing; wall-clock thresholds are reviewed, not asserted in CI |
