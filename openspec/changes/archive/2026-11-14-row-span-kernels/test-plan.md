# Test plan

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| `rk_pick` | Composite a plain 8-bit Normal layer with no mask, no Blend If, no text curve, and no native plane while reading the test-only kernel counters. | The row-span kernel runs, the general kernel does not, and the output equals the forced-general composite. | `pictura-render::common_layer_uses_the_row_span_kernel` |
| `rk_general` | Composite layers with an active Blend If, a text-gamma curve, a native source plane, a non-Normal mode, and a knockout canvas while reading the kernel counters and comparing bytes. | Each advanced layer takes the general per-pixel kernel and the output equals the pre-change bytes. | `pictura-render::advanced_attributes_keep_the_general_kernel`, `pictura-render::type_proxy_with_text_gamma_takes_the_general_kernel` |
| `rk_override` | Composite a clipping base whose proxy override changes mode/fill/mask, and a knockout layer that supplies a cover canvas, once through selection and once with `FORCE_GENERAL`. | Selection follows the effective state and the cover canvas forces the general kernel; both outputs are byte-identical. | `pictura-render::kernel_selection_follows_synthetic_overrides` |
| `rk_mask` | Composite a plain raster mask at density 255 and below, a feathered raster mask, a vector mask with invert on and off, a native mask combined with a vector mask, a masked grayscale layer, and masked layers at zero opacity and zero fill through the selected kernel and the forced-general path, while reading the mask-sample counter. | Every output byte matches, including the integer raster×vector combine and the f32 native product; the masked shape counter ran; the zero-content cases record no mask sample. | `pictura-render::kernel_masks_match_the_general_path` |
| `rk_opaque` | Composite an alpha-less full-canvas Normal layer at default opacity and fill over a transparent backdrop and over a partially transparent backdrop, once selected and once forced general, while reading the opaque shape counter. | Both outputs are byte-identical in both backdrop cases and the opaque kernel ran. | `pictura-render::opaque_kernel_matches_the_general_path` |
| `rk_unit` | Convert all 256 u8 samples through the shared table, its channel-plane call site (`source_unit`), and its mask-gate call site (`MaskGate::alpha`), comparing each with `sample as f32 / 255.0`. | Every pair is bit-equal. | `pictura-render::unit_table_matches_division`, `pictura-render::source_unit_uses_the_unit_table`, `pictura-render::mask_alpha_uses_the_unit_table` |
| `rk_parity` | Composite the full kernel matrix (alpha/no-alpha, each mask kind, grayscale, non-default opacity and fill, clipping, knockout, smart-object raster proxy, type raster proxy) with the selected kernel and with `FORCE_GENERAL`, while reading the per-shape counters. | `PixelBuffer::data` is byte-identical for every document and each intended shape counter ran. | `pictura-render::kernel_matrix_matches_the_general_path` |
| `rk_parity_paths` | Composite the same eligible stack whole-canvas parallel, banded, over a sub-region, and with `FORCE_SERIAL`. | Banded, sub-region, and serial outputs are byte-identical to the whole-canvas parallel output. | `pictura-render::kernel_parity_across_banded_region_and_serial` |
| `ck_legacy` | Evaluate random source and backdrop samples for every blend mode through the shared per-pixel kernel and the legacy per-pixel switch. | Every `Px` `f32` channel and final `u8` is bit-for-bit equal. | `pictura-render::ctx_kernel_matches_legacy` |
| `ck_callers` | Composite the pixel, group, adjustment, fill, smart-source, smart-filter, and type-source routes, including the smart-proxy and type-proxy pixel routes. | Each route keeps its pre-change bytes, and the selected kernels on pixel content match the shared kernel. | `pictura-render::ctx_route_callers_match_legacy`, `pictura-render::kernel_matrix_matches_the_general_path` |
| Switch composition (not a spec scenario) | Run a kernel-eligible document with `legacy_blend` and with `legacy_source` while reading `KERNEL_RUNS`, then with `FORCE_GENERAL` and `FORCE_SERIAL` together. | No row-span kernel runs under either legacy switch, and the forced-general serial output equals the whole-canvas parallel output. | `pictura-render::kernel_switches_compose_with_legacy_and_serial` |
| Profile protocol (not a spec scenario) | Run the ignored 4000² profile with a Normal alpha layer, an alpha-less Normal layer, a plain-raster-mask Normal layer, and Multiply; assert the opaque and masked shape counters for the same layer states in the unit-level profile test. | Prints one timing per scenario and both intended shape counters are observed. | `pictura-render::cpu_composite_profile_4000`, `pictura-render::profile_cases_use_the_intended_shapes` |
| Before/after timing (not a spec scenario) | Run the profile with `cargo test -p pictura-render --release --test composite_profile -- --ignored --nocapture` on `origin/master` and on the branch with the same machine and build profile. | A recorded before/after table in the PR body; no automated threshold because wall time is machine-dependent. | manual: wall time is machine-dependent and the change sets no fixed threshold |
