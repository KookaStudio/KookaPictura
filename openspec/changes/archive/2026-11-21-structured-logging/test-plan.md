# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `log_shared_stream` | Emit an application save outcome and nonfatal Qt messages through the production bridge. | The shared file records both sources with UTC timestamps, an event identity, and the expected level and category. | `tst_structured_logging::routesRustAndQtRecords` |
| `log_filtering` | Set an app Debug target override and disable a Qt category. Emit events on both sides of each filter. | The configured Rust Debug and allowed Qt events arrive. Both filtered events are absent. | `tst_structured_logging::appliesTargetAndCategoryRules` |
| `log_private_fields` | Send unique fixture paths, titles, layer names, text, and dependency strings into the relevant logging paths and enable History Log. | Persisted diagnostics keep the reviewed fields and contain none of the sentinels or History Log rows. | `tst_structured_logging::keepsPrivateFieldsOutOfFile` |
| `log_rotation` | Start two writers in the same state root, seed old files, advance the test clock across UTC midnight, and roll it back. | Application files outside the seven-date window are removed. Both writers leave attributable, parseable records and unrelated files survive. A writer can append again to its earlier date. | `pictura-app::diagnostic_rotation_keeps_seven_dates`, `pictura-app::diagnostic_rotation_reopens_its_own_previous_date` |
| `log_startup_modes` | Spawn the built app with an explicit state root and in self-test, MCP stdio, theme dump, and GPU probe child modes. | Only editor and isolated self-test state receive their designated logs. The self-test tokens and machine-readable outputs remain valid. | `tst_structured_logging::isolatesStartupModes` |
| `log_sink_failure` | Refuse setup, inject post-start write errors, and stall a writer while flooding its queue. | Each failed sink emits a single notice and falls back to stderr. Flooding never blocks the producer. | `pictura-app::diagnostic_writer_failure_and_saturation` |
| `log_shutdown` | Exit one child normally after logging, stall another writer through the two-second deadline, and emit a Qt fatal message in a third child. | The healthy child flushes its last event. The stalled child stops waiting at the deadline and exits with a stderr-only incomplete-drain notice. The fatal child writes its marker to stderr and terminates abnormally. | `tst_structured_logging::flushesAndPreservesFatalExit` |
| `history_log_preferences` | Open General with fresh state, cancel the forced file chooser, accept valid settings, and restore a new session. | Defaults and cancellation match the spec. The accepted toggle, destination, verbosity, and path persist. | `tst_history_log::preferencesPersistAndCancelCleanly` |
| `history_log_off` | Enable Both, commit an edit, disable it, commit another edit, and save an image with existing history. | Both outputs contain only the enabled edit. XMP preserves the pre-existing text. | `tst_history_log::disablingStopsNewRecords` |
| `history_log_verbosity` | Run the same start, open, stroke, parameterized filter, close, and quit sequence at each setting. | Lifecycle, one label per edit, and available filter parameters appear at their specified levels. | `tst_history_log::verbosityFollowsCommittedActivity` |
| `history_log_committed_edits` | Cancel a preview, refuse an edit, commit a stroke, then undo or clear the History panel and save. | Exactly one edit row remains. Log capture creates no extra undo state. | `tst_history_log::capturesOnlyCommittedEdits` |
| `history_log_destinations` | Seed a log file and XMP, run a fresh edit and save for each destination, and try an image or FIFO as the text destination. | The selected destinations get the new row. Both baseline contents survive, an image destination is protected, and a FIFO does not block validation. | `tst_history_log::routesSelectedDestinations`, `tst_history_log::refusesImageAsTextLog`, `pictura-app::text_destination_checks_the_open_file`, `pictura-app::text_destination_rejects_fifo_without_opening_it` |
| `history_log_text_failure` | Make the selected text path unusable under Both, then commit and save. | A failure notice appears and the saved XMP still includes the edit. | `tst_history_log::failedTextSinkKeepsMetadata` |
| `history_log_text_queue` | Stall the writer, fill its queue, and commit additional edits. Separately close and immediately quit with a healthy writer, then repeat with a stalled drain. | Each rejected or undrained row is identifiable by ID and destination through bounded batched notices. Editing and metadata capture continue. The healthy file contains close before quit. The stalled process exits after the two-second drain. | `tst_history_log::reportsTextQueueAndDrainsOnQuit` |
| `history_log_xmp_roundtrip` | Seed prior history and unknown XMP, save and reopen PSD, PSB, JPEG, and TIFF, then edit and save again. Use JPEG APP1 without APP13 and exercise both TIFF byte orders in codec coverage. Exercise escaped History in element and attribute forms. | File Info shows multiline history with each new edit once and decoded XML text. The unknown XMP bytes survive. The codec imports standard container XMP independent of Photoshop resources. | `tst_history_log::reopensHistoryAcrossFormats`, `pictura-codec::standard_raster_xmp_round_trips`, `pictura-codec::history_round_trips_entities_and_rejects_unreadable_length` |
| `history_log_save_snapshot` | Hold a native save in flight, commit a newer edit, and exercise failed and copy saves followed by a successful source save. | Snapshot contents are correct and later records remain eligible. The final source file has each expected entry once. | `tst_history_log::saveSnapshotsKeepPendingRecords` |
| `history_log_file_info_conflict` | Hold a save in flight while rewriting unrelated File Info with equal History. Repeat with History replacement, removal, and change then restoration, capture a later edit, then save again. Undo and redo an explicit History edit after a save. | Equal History preserves saved rows once with unrelated edits. Effective changes make the current History value win over older rows, and later rows survive; undo and redo retain their selected History values. | `tst_history_log::fileInfoEditsDuringSave`, `tst_history_log::undoExplicitHistoryPreservesRestoredValue` |
| `history_log_xmp_limits` | Try appending to an APP1 packet near the JPEG limit, to XMP with an unsupported property shape, and beyond the reader's History value limit. Retry eligible records on compatible metadata. | Image saves preserve prior encodable packets, report the omitted append, and retain entries for a later eligible save. | `tst_history_log::metadataAppendFailureKeepsImageSaveable`, `pictura-codec::history_round_trips_entities_and_rejects_unreadable_length` |
| `history_log_web_metadata` | Export JPEG, PNG-8, and PNG-24 at all metadata levels, then save the open document. | Only All and All Except Camera Info carry history. The subsequent document save contains each pending record once. | `tst_history_log::webExportHonorsMetadataChoice` |
| `history_log_web_overflow` | Export ordinary and sliced JPEG with full XMP at the APP1 boundary where pending history overflows, then save the source in a compatible format. | Every JPEG retains its existing encodable XMP. The export reports the omitted append, and the source save contains each pending record once. | `tst_history_log::webJpegOverflowKeepsSourceRecords` |
| CS6 File Info inspection | Open an emitted PSD with multiline history in a licensed CS6 instance and inspect the History field. | CS6 can display the saved entries as readable text. | manual: requires a licensed Photoshop CS6 installation and its File Info UI |
