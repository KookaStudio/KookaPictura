# Test Plan — save-for-web-slices

One row per spec scenario. Coverage names the automated check; every test named
here is created or extended by this change.

| Scenario | Steps | Expected result | Coverage |
|---|---|---|---|
| ImageMagick reads our GIF and WBMP | Reduce a colour field with a clear corner to 64 Selective colours with diffusion; encode GIF plain and interlaced and WBMP; decode with ImageMagick | Every GIF pixel is its palette colour or transparent; every WBMP pixel matches its bit | `pictura-codec::magick_decodes_our_gifs_exactly`, `pictura-codec::magick_decodes_our_wbmp_exactly` |
| sfw-custom-palette | Quantize a field to 16 colours with one locked colour absent from the reduced table, then map a clear table entry | The locked colour is in the palette, the table has at most 16 entries, and every pixel uses a table entry; an opaque matte-coloured pixel stays opaque unless transparency is mapped | `pictura-codec::locked_palette_survives_reduction`, `pictura-codec::custom_palette_maps`, `pictura-codec::custom_clear_entry_does_not_catch_opaque_white` |
| sfw-color-budget | Lock 20 colours in a 16-colour reduction, then add a locked colour to a table already holding 256 locked colours | The first table has 20 entries and keeps every locked colour; the second add is refused; locked colours plus a clear slot fit 256, and a full 256-locked table drops transparency instead of a colour | `pictura-codec::locked_palette_over_budget`, `pictura-codec::locked_palette_reserves_the_clear_slot`, `pictura-codec::locked_palette_full_drops_transparency`, `tst_save_for_web::colorBudget` |
| Optimise, resize, save, remember | Open the dialog, read the default GIF, switch formats and settings, halve the size, pick JPEG Low, save, choose PNG-24, Done, reopen | the GIF decodes with its clear corner; JPEG quality 10 < 100; PNG-8 keeps its table; PNG-24 lays the corner over white; WBMP header; 32 x 24; preset sets JPEG 10; saved bytes are the optimized bytes; reopen shows PNG-24 | `tst_save_for_web::formats`, `tst_save_for_web::sizePresetsSaveAndDone` |
| sfw-dialog-surfaces | Open the dialog and select GIF, PNG-8, JPEG, PNG-24 in turn | Color Table present only for GIF/PNG-8; Metadata menu present for all; all four tabs enabled | `tst_save_for_web::dialogSurfaces` |
| sfw-four-up | Switch to 4-Up, click the second optimized pane, lower its JPEG quality | That pane's size shrinks; other panes unchanged; Save writes the lowered-quality JPEG | `tst_save_for_web::fourUp` |
| sfw-repopulate | Invoke Repopulate Views with GIF 128 colours active, then again with a custom colour table | The three optimized panes are regenerated with <=128 colours and sizes no larger than the active pane; the lowered panes drop the custom table | `tst_save_for_web::repopulate` |
| sfw-color-table | Reduce to 16 colours, shift one swatch to red, save the GIF | Decoded pixels that used that swatch are red | `tst_save_for_web::colorTableEdit` |
| sfw-color-transparency | Map a swatch to transparency and save the GIF | Pixels using that swatch decode transparent; one transparent entry | `tst_save_for_web::colorTableTransparency` |
| sfw-color-unmap | Map a swatch to transparency, then unmap it, and save the GIF | The entry stays in the table at its RGB, no entry is transparent, and pixels using it decode opaque | `tst_save_for_web::colorTableUnmap` |
| sfw-color-sort | Sort by luminance, save `.act`, load it again | Loaded colours match the sorted table in order; a 16-colour opaque table and a 16-colour table with transparency both round-trip; encoding is visibly unchanged | `tst_save_for_web::colorTableSortAct`, `pictura-codec::act_roundtrip` |
| sfw-metadata | Save a document with EXIF/IPTC/XMP as JPEG with Metadata All and with None | All carries EXIF APP1, XMP APP1, IPTC APP13; None carries none (at most a minimal EXIF copyright) | `tst_save_for_web::metadataAllNone`, `pictura-codec::metadata_levels` |
| sfw-metadata-formats | Save the same document with Metadata All as PNG-24 and GIF | PNG has an XMP `iTXt` chunk; GIF has no metadata block | `tst_save_for_web::metadataFormats`, `pictura-codec::png_xmp_chunk` |
| sfw-metadata-remember | Choose All, click Done, reopen the dialog | Metadata menu shows All | `tst_save_for_web::metadataRemember` |
| slice-images | Save a 64 x 48 document with two user slices as GIF with HTML and Images | `images/<doc>_01.gif` and `_02.gif` exist, decode to their slice sizes, and hold the matching composite regions | `tst_save_for_web::sliceImages` |
| slice-overlap | Save a document with two overlapping user slices as GIF with HTML and Images | The written images do not overlap, together they cover the canvas, and the later-created slice owns the overlapping region | `pictura-render::overlapping_slices_export_disjoint` |
| slice-images-size | Halve the document through Image Size and save | Non-zero slice images are half size (rounded), zero-area slices are omitted from the images and layout, and the remaining slices still cover 32 x 24 without gaps | `tst_save_for_web::sliceImageSize`, `pictura-codec::zero_area_cells_are_omitted` |
| slice-html-table | Export a 4 x 4 grid with an L-shaped arrangement of rectangular slices (one tall slice spanning two rows plus two short ones) as HTML | Cells plus spans cover the canvas exactly; each image path names a written file | `pictura-codec::html_table_grid`, `pictura-codec::html_table_spans_a_tall_slice`, `tst_save_for_web::htmlTable` |
| slice-html-escape | Save a document whose name contains `&"<>` as HTML with HTML and Images | The title and attribute values escape `&`, `<`, `>`, and `"`, image paths are URL-encoded, CSS ids replace other characters with `_`, and a digit-leading id gets the `s_` prefix | `pictura-codec::html_escaping`, `pictura-codec::css_id_prefixes_a_leading_digit` |
| slice-html-only | Save the same document with Format HTML Only | HTML is written with the same table and paths; no `images/` files | `tst_save_for_web::htmlOnly` |
| slice-css | Export a sliced document with the CSS layout | No table; one positioned div per non-zero slice at its left/top/width/height; each img path names a written file | `pictura-codec::html_css_grid`, `tst_save_for_web::cssLayout` |
| slice-save-formats | Save as HTML and Images, then Images Only, then HTML Only | HTML+Images writes HTML and images; Images Only writes images only; HTML Only writes HTML only | `tst_save_for_web::saveFormats` |
| slice-save-cancel | Open Save Optimized As and cancel | No file is written; document pixels, path, modified state, and history are unchanged | `tst_save_for_web::saveCancel` (drives the Save Optimized As dialog only; `saveForWebFromView` needs its modal and is not driven here) |
| slice-unsliced | Save a document with no user slices | One optimized image is written; no HTML file or images folder | `tst_save_for_web::unslicedSave` (drives the dialog's `saveTo`; the command path opens a modal and is not driven here) |
