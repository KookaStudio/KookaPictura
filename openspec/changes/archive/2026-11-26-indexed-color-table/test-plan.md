# Test plan

| Scenario | Steps | Expected result | Coverage |
| --- | --- | --- | --- |
| An RGB document | Open an 8-bit RGB document and inspect the Mode menu. | Current mode and depth are checked. Conversion availability is unchanged and Color Table is disabled. | `tst_image_mode::menuChecksTheModeAndDimsUnavailableTargets` |
| An indexed document | Convert a test image, refresh the menu, and open Color Table. | The action is enabled and its dialog contains current palette entries. | `tst_image_mode::indexedColorTableCancelKeepsDocument` |
| Indexed preview then cancel | Preview a layered document in the Indexed Color dialog and cancel. | The original layers, mode and history are restored. | `tst_image_mode::indexedPreviewsCancelsAndFlattens` |
| Convert using forced colors and transparency | Convert opaque and clear pixels with forced black and white. Write and reopen a PSD. | Both opaque forced colors exist, the clear pixel uses the designated index, and the reopened image retains alpha. | `pictura-render::forced_indexed_transparency_round_trips` |
| Convert without transparency | Convert the same pixels with Transparency cleared. | The clear pixel becomes white and the table has no transparent index. | `pictura-render::indexed_conversion_without_transparency_uses_white` |
| Change and undo a palette | Change a palette RGB value and assign an index to transparency. Accept and undo. | Retained indices stay the same. Working RGB and alpha update, then the original table and appearance return. | `pictura-render::color_table_replacement_preserves_indices`, `tst_image_mode::colorTableCommitCanBeUndone` |
| Cancel a table edit | Change the transparency indication in the dialog, then cancel. | The table, canvas and history are unchanged. | `tst_image_mode::indexedColorTableCancelKeepsDocument` |
| Forced colors at the transparency capacity boundary | Convert a clear source with 255 distinct forced colors; request conversion with 256 on a fresh document. | The first retains all colors and the clear entry; the second fails atomically with history unchanged. | `pictura-render::forced_indexed_transparency_capacity_boundary` |
| Exact availability follows conversion options | Select Exact, then choose forced colors or Transparency that make the union exceed 256; submit an invalid direct Exact request. | The dialog switches to Local Adaptive; the direct request fails with document and history unchanged. | `tst_image_mode::exactFallsBackWhenOptionsExceedCapacity`, `pictura-render::invalid_exact_request_is_atomic` |
| Exact fits at capacity | Convert a source whose distinct opaque inputs, forced colors and required clear entry total 256. | Exact remains available and preserves every required color and the clear entry. | `pictura-render::exact_indexed_conversion_fits_capacity`, `tst_image_mode::exactRemainsAvailableAtCapacity` |
| Interpolate a palette range | Interpolate between two entries, accept, and inspect table and pixels. | Intermediate entries are interpolated; indices remain unchanged and appearance follows the table. | `tst_image_mode::colorTableInterpolatesRange` |
| Load and save an ACT table | Save a short table with a nonzero transparent index to ACT and load it into a compatible indexed image. | Entries, active count and transparent index round trip; pixel indices stay unchanged. | `tst_image_mode::colorTableActRoundTrip` |
| Reject an ACT table that omits a used index | Attempt to load a table shorter than an index used by the image. | Load fails and the dialog table, document and history remain unchanged. | `tst_image_mode::colorTableRejectsShortAct` |
| Accept an unchanged table | Open Color Table and accept without changes. | Table, pixels and history are unchanged. | `tst_image_mode::colorTableUnchangedAcceptance` |
| Indexed metadata round trips through PSD and PSB | Save and reopen an indexed image with a short table and nonzero transparent index in each native format. | Both preserve count, transparent index, pixel indices and corresponding alpha. | `pictura-codec::indexed_metadata_round_trips_psd_and_psb` |
