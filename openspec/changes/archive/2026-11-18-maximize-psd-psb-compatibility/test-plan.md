# Test plan

| Scenario | Steps | Expected result | Coverage |
| --- | --- | --- | --- |
| `psd-compat-preference` | Start with an empty settings store, choose Ask and then Never across restarts, and load a store with an invalid value | Empty and invalid stores start at Always. Each valid choice persists and reopening settings reflects it | `tst_psd_compatibility::preferencePersists` |
| `psd-compat-write` | Save matching nonuniform layered PSD and PSB fixtures with Include and Omit. Include detached working RGB and native high-depth cases. Inspect image data and reopen both | Include carries the rendered pixels. Omit has no real merged image, is smaller on the controlled fixture, and preserves layer pixels and native mode and depth | `pictura-app::native_save_respects_merged_output_choice` |
| `psd-compat-restore` | Reopen omitted PSD and PSB, edit a layer, save with Include, then decode the merged image | Decoded real composite matches the edited layer stack. Layer content and editability survive | `pictura-app::native_save_restores_merged_image` |
| `psd-compat-protected` | Request Omit for flat and layered-with-saved-channel cases in both containers and reopen | Flat pixels and all channel samples survive. Layered documents still have their layers | `pictura-app::native_save_preserves_required_image_data` |
| `psd-compat-ask` | Exercise Save, Save As, and Save a Copy for eligible PSD/PSB with Ask. Accept Include and Omit on successive saves, cancel with an existing target on Save As and Save a Copy after selecting an ICC option, and try Ask on a protected document | Ask repeats for eligible saves and applies its answer to that write. Cancel preserves target bytes and open document state and ICC save setting. Protected saves retain required data without offering omission | `tst_psd_compatibility::asksPerSaveAndCancels` |
| `psd-compat-copy` | Copy a dirty layered native document with the opposite output choice | Copy has the chosen image data. Original path, modified state, history, and pixels are identical | `tst_psd_compatibility::copyPreservesDocument` |
| `psd-compat-other` | Select Ask or Never and try raster Save As, recovery, an internal Smart Object edit save, pathless and explicit-path control-server saves, and Action replay | No compatibility prompt. The raster pixels, recovered layers, applied Smart Object edit, and noninteractive native output policies are correct | `tst_psd_compatibility::otherSavesBypassPreference` |
| `psd-compat-photoshop-opens` | Open the Kooka Always and Never fixtures for each container in CS6 and current Photoshop CC. Toggle a layer, save a copy, and reopen it in Kooka. Record application versions | Each of the eight combinations preserves the expected picture and editable layers, including the edit after return to Kooka | manual: requires installed licensed Photoshop CS6 and current Photoshop CC |
| `psd-compat-kooka-opens` | Produce Always and Never PSD and PSB files in CS6 and current CC. Open each in Kooka, edit a layer, save, then reopen in the source Photoshop release. Record application versions and any omitted-image placeholder and metadata | Each combination opens with equivalent pixels and editable layers. The edited file reopens in its source release | manual: requires both Adobe applications to author and reopen the fixtures |
| `save-options-native` | Save As PSD and PSB under Always and Never. Resolve WebP and PDF format options and verify they are outside native compatibility | No native compatibility prompt is shown. WebP and PDF have no raster format options dialog | `tst_psd_compatibility::nativeModesDoNotPrompt`, `tst_save_format_options::formatKindForSuffix` |
| `save-options-jpeg` | Resolve the options kind for `.jpg`, `.jpeg`, `.jpe` | JPEG Options | `tst_save_format_options::formatKindForSuffix` |
| `save-options-png` | Resolve the options kind for `.png` | PNG Options | `tst_save_format_options::formatKindForSuffix` |
| `save-options-bmp` | Resolve the options kind for `.bmp` | BMP Options | `tst_save_format_options::formatKindForSuffix` |
| `save-options-tiff` | Resolve the options kind for `.tif`, `.tiff` | TIFF Options | `tst_save_format_options::formatKindForSuffix` |
| `save-options-gif` | Resolve the options kind for `.gif` | GIF Options | `tst_save_format_options::formatKindForSuffix` |
| `save-options-eps` | Resolve the options kind for `.eps` with the EPS filter | EPS Options | `tst_save_format_options::formatKindForSuffix`, `tst_save_format_options::filterHintChoosesEps` |
| `save-options-dcs` | Resolve the options kind for `.eps` with the DCS filter | DCS Format | `tst_save_format_options::filterHintChoosesDcs` |
| `save-options-eps-dcs-hint` | Choose DCS, type `.eps`, reopen | DCS Format seeded from the DCS settings | `tst_save_format_options::filterHintChoosesDcs` |
| `save-options-raw` | Resolve the options kind for `.raw` | Photoshop Raw Options | `tst_save_format_options::formatKindForSuffix` |
| `save-options-tga` | Resolve the options kind for `.tga`, `.vda`, `.icb`, `.vst` | Targa Options | `tst_save_format_options::formatKindForSuffix` |
| `save-options-cineon` | Resolve the options kind for `.cin` | Cineon Options | `tst_save_format_options::formatKindForSuffix` |
| `save-options-cancel` | Reject each options dialog through the test hook | No file, no state change | `tst_save_format_options::cancelWritesNothing` |
| `save-options-unknown-suffix` | Save to an unregistered suffix and to a path with no suffix | Failure and no file | `tst_save_format_options::unknownSuffixRefused`, `tst_save_format_options::missingSuffixRefused` |
| `psd-compat-adobe-fixture` | Open a generated fixture with the Photoshop 2021 Never placeholder and Version Info marker, edit a layer, save Always, inspect pixels and merged metadata | Output matches edited layers and metadata describes the real composite | `pictura-app::native_save_restores_adobe_omitted_fixture` |
| An edited depth-16 layered document saves at 16-bit with native samples | Edit and save a layered 16-bit RGB document with Include | Native composite contains samples beyond 8-bit widening | `pictura-app::native_depth_save_regressions` |
| Alpha and extra channels are preserved | Save an edited high-depth layered document with extra channels | Alpha and extra samples and count remain intact | `pictura-app::native_depth_save_regressions` |
| A clean open→save is byte-identical | Open and save a clean 16-bit PSD under the existing policy | Bytes match the existing behavior | `pictura-app::native_depth_save_regressions` |
| A no-layer document is not refreshed | Edit and save a layerless high-depth document | Existing composite survives | `pictura-app::native_depth_save_regressions` |
| A converted-mode document is not refreshed | Edit and save a converted 16-bit CMYK document | Source planes and existing depth behavior survive | `pictura-app::native_depth_save_regressions` |
| `native-depth-restore` | Save RGB and Grayscale 16-bit and 32-bit layered PSD and PSB with retained native layer samples with Never, reopen clean and edited variants, then save Always | Header depth and decoded native samples match layer-derived samples | `pictura-app::native_save_restores_missing_native_composite` |
| `dss_stored_composite` | Inspect matching, absent, empty and mismatched composites through core and render | Shared stored-composite results agree | `pictura-render::stored_composite_queries_agree_with_document` |
| `dss_composite_roles` | Inspect grayscale, RGB and detached layered working composites | Shape and retention decisions remain distinct | `pictura-core::composite_roles_and_output_policy_are_independent` |
| `dss_merged_output` | Save detached Include and resident Omit inputs and exercise direct codec preconditions | Output follows policy; direct preconditions remain; any placeholder matches fixture evidence | `pictura-app::native_save_respects_merged_output_choice`, `pictura-app::native_save_codec_preconditions` |
