# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| A pan repaint does not resample the document | Pan a document canvas at fit zoom and render twice | The canvas presents the same level pixels and does not build or sample the full-resolution document | `tst_present_cache::panPresentsWithoutResamplingTheDocument` |
| `cvda_zero_copy_level` | Paint a document at a zoom that selects a stored level; capture the level view and the canvas | The level view shares the level's storage (no viewport copy) and the rendered canvas matches a direct level draw | `pictura-render::a_stored_level_view_shares_the_level_bytes`, `tst_present_cache::storedLevelIsDrawnFromALevelView`, `tst_present_cache::storedLevelViewMatchesTheCropDraw` |
| `cvda_level0_crop_reused` | Paint a level-0 canvas twice at the same document rectangle | The second paint reuses the cached crop; no second full crop is built | `tst_present_cache::level0CropIsReusedAcrossPaints` |
| A zoom change invalidates the cache | Zoom from level 0 to level 1 across the boundary and paint | The next paint presents level 1 (the selected level changes) | `tst_present_cache::zoomChangeSelectsTheNewLevel` |
| Cached present matches the transform draw | Render a level-0 canvas through the present path and through a direct full-resolution draw with the same sampling | The two rendered images are pixel-identical | `tst_present_cache::level0PresentMatchesTheTransformDraw` |
| A coarse-level present is a single reduction | Paint at a zoom that selects a level below 0 | The canvas draws that level's pixels and never the full-resolution document | `tst_present_cache::storedLevelIsDrawnFromALevelView`, `tst_present_cache::largeDocumentPresentsThroughALevel` |
| A document past the former cache bound still presents through a crop | Create a document whose scaled present exceeds 64 MP, paint at a high zoom | The paint presents a level and does not fall back to the transform draw | `tst_present_cache::largeDocumentPresentsThroughALevel` |
| The C++ blit path is exercised | Refresh a region of an active document while a canvas listens | The canvas receives `regionDamaged`, `regionBlitted` does not fire, and the next paint shows the change | `tst_present_cache::documentRefreshArrivesAsDamage` |
| A filter commit presents through damage | Commit a filter that lands a clipped region on a document canvas | The canvas receives `regionDamaged` at the clipped filter rectangle, no 1×1 marker `regionBlitted` fires, and the next paint shows the filtered region | `tst_present_cache::filterCommitPresentsThroughDamage` |
| `cvda_pixel_blit_fallback` | Call `blitRegion` on a canvas that holds its own image | The region is drawn at the given origin and the canvas repaints | `tst_present_cache::nonDocumentCanvasBlitsPixels` |
| The on-screen canvas after a region refresh matches a full recomposite | Refresh a region, render the canvas, force a full recomposite, render again | The two renders are pixel-identical | `pictura-app::paint_commit_region_patch_equals_a_full_recomposite`, `tst_present_cache::documentRefreshMatchesFullRecomposite` |
| image() rebuilds from the composite only when dirty | Call `image()` after a region refresh and again after a full recomposite | Both calls build from the cached level-0 frame and are byte-identical | `pictura-app::region_refresh_reuses_the_level0_frame_when_it_matches` |
| sample_argb reads the current composite | Refresh a region, then sample a changed pixel | The sample is the document composite's pixel, not a stale displayed value | `pictura-app::sample_argb_after_a_region_refresh_reads_the_composite` |
| The existing M31/M32 canvas-equality checks still hold | Run the C++ self-test canvas-equality checks after a region refresh | The compared canvas is byte-identical to a full recomposite | manual: the checks live in `runSelfTest()`, which the test-plan checker cannot name; they stay green in `scripts/test-report.sh` |
| image() builds the full image on demand | Call `image()` for an open document | The image comes from the current level-0 frame and equals a full recomposite | `pictura-app::image_after_region_refresh_matches_a_full_recomposite` |
| No persistent full-resolution QImage is held | Open a document and inspect the canvas without consuming `image()` | The canvas holds no full-resolution `QImage` | `tst_large_document::aDocumentCanvasHoldsNoImage` |
| The repaint path does not depend on image() | Repaint at several zooms before any caller consumes `image()` | The paint presents pyramid level pixels and never builds the full image | `tst_present_cache::presentDoesNotBuildTheFullImage` |
| `cvda_gpu_zoom_level` | Paint while a GPU stroke is live at a zoom that selects a stored level | The canvas presents that stored level | manual: needs a live GPU adapter; the level rule is covered by `tst_present_cache::idlePresentLevelIsZoomSelected` and the GPU self-test check |
| `cvda_gpu_dab_in_pyramid` | Apply a GPU dab and inspect every stored level over its rectangle | Every stored level is repaired before the present | `pictura-app::level0_region_update_matches_a_rebuild` |
| `cvda_gpu_idle` | Paint with no stroke live | The present level is the zoom-selected level | `tst_present_cache::idlePresentLevelIsZoomSelected` |
| `cvda_patch_matches_crop` | Crop the damage rectangle from level 0 and compare it with that rectangle of the cached crop (Rust positional premise); then patch the cached crop in place through the canvas and compare it with a fresh crop (Qt byte identity) | The damage-rect crop equals the same rectangle of the cached crop, and the in-place patched crop bytes equal the fresh crop | `pictura-app::a_level_zero_damage_crop_matches_the_cached_crop_rect`, `tst_present_cache::level0PatchMatchesFreshCrop` |
| `cvda_patch_outside` | Send a damage rectangle outside the cached document rectangle | The cached crop bytes are unchanged | `tst_present_cache::damageOutsideCacheChangesNothing` |
| `cvda_patch_level_change` | Send a damage while a preview selects another level | The cache is discarded and the next paint presents the selected level | `tst_present_cache::damageForAnotherLevelDiscardsCrop` |
| `vp_view_shares_bytes` | Request a shared level handle for a stored level | Its bytes equal the level's pixels and its data pointer is the level's own storage (no copy) | `pictura-render::a_stored_level_view_shares_the_level_bytes` |
| `vp_view_copies_on_write` | Hold a shared level handle, update the level, then request another handle | The held handle keeps its bytes; the new handle shows the update | `pictura-render::an_update_copies_a_level_a_live_view_holds` |
| `vp_view_update_in_place` | Update a level with no live handle | The level's storage pointer is unchanged and no second buffer is allocated | `pictura-render::an_update_without_a_view_writes_in_place` |
| `vp_view_no_level0` | Request a shared level handle for level 0 | The view reports no stored buffer instead of exposing the planar source | `pictura-render::level_zero_has_no_borrowed_view` |
| Per-frame brush present at fit zoom (issue acceptance) | Profile a 500 px brush on a 6000×4000 document at fit zoom with `PICTURA_METRICS=1`, GPU on and off | `cxx_paintEvent` per frame stays O(dab), target under 5 ms | manual: profiling run via `scripts/profile-tools.py --metrics`, not a unit test |
