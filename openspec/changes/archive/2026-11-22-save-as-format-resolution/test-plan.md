# Test plan

This change has no spec scenarios (`skip_specs: true`). The rows below map the
issue's acceptance criteria and the design risks to runnable checks. Verification
ran after the rebase onto `origin/master` at `d593663a9`. The CMake/Ninja build,
all 6,855 Rust tests, the new catalog suite, both headless self-test invocations,
and the scoped guards passed. The aggregate gate's only failures are
`PresentCacheTest::frameBoundedPaintMatchesCpu(gpu)` and
`check-milestone-names.py --self-test`; both reproduce on a clean checkout of the
same `origin/master` commit. The preserved cases passed without edits.

|---|---|---|---|
| One catalog supplies every format fact [saf_catalog_facts] | Read the 14 catalog rows and query each ordinal id/name, wire code, alias set, canonical extension, route, and flag set through the bridge | Ids are unique ordinals 0..13 and differ from the wire codes where expected (DCS 10/7; PSD, PSB, WebP, PDF code 0); DCS has no alias; aliases and canonicals resolve case-insensitively | `pictura-codec::save_format_catalog_matches_wire_codes`, `pictura-codec::save_format_suffix_aliases_are_case_insensitive`, `pictura-codec::dcs_has_no_suffix_alias`, `pictura-app::save_format_queries_match_the_catalog` |
