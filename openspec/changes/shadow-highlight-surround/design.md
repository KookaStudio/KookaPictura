# Design

The CPU kernel shares its math across 8-bit and native stores. It measures luminance over the full layer using the existing Gaussian approximation with replicated edges. The two bands use smooth weights: width 0 restricts each to its tonal extreme, width 50 places the split near middle gray, and width 100 includes midtones without affecting the opposite extreme. Increasing width expands the affected range toward and into the midtones. Each band uses its own radius. Apply shadow lift, highlight pull, mode-specific correction and midtone contrast, then stretch luminance using optional histogram endpoints. Positive Color Correction increases chroma in adjusted color areas, negative values decrease it, and zero leaves chroma unchanged; positive grayscale Brightness lifts luminance and negative values darken it. Use stored coverage only to blend the output into the target. Preserve alpha. Reject invalid settings before writing. A flat or collapsed histogram keeps its original range.

Pictura keeps the original four-byte `shdH` path and algorithm for saved settings. Expanded settings use the distinct `shd2` key with an explicit version and fixed big-endian fields, so older decoders cannot interpret them as legacy amounts. Reject unsupported versions and malformed lengths without applying or rewriting them as `shdH`; preserve unknown data where the existing container supports it. Only the expanded path appears in new dialogs. Amounts, widths, radii, Brightness, Color Correction and Midtone Contrast are encoded in whole-unit increments; the encoder rejects values that cannot be represented exactly. Radius is 0–500 px, with zero using the source luminance. Clip percentages are stored in hundredths across 0–10%, using the scaled adjustment-page field for display and edits; other clip values are rejected by the encoder. The factory dialog opens at shadow amount 35%, highlight amount 0%, widths 50%, radii 30 px, color correction +20, and clipping 0.01% at each end. The kernel limits nonzero color correction to adjusted areas.

Reuse the generic dialog preview and adjustment-page fields. Split the existing control widget into basic and advanced pages for this command. Show Brightness in Grayscale and Color Correction otherwise. Retain menu history and action behavior. Block the expanded operation at 32 bpc. The existing mask projection uses the grayscale mapping.
