# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `ds_one_slot` | Start a healing gesture on a small pixel layer, then attempt to begin a paint stroke. | The paint begin returns false, the healing gesture remains active, and the document and history are unchanged. | `pictura-app::a_second_session_is_refused` |
| `ds_update_begin` | Update a filter preview and a mode preview twice; begin a magnetic lasso, then call `begin_lasso` to attach its points. | Exactly one filter session, one mode session, and one selection gesture remain live; the updates take effect and no second session is created. | `pictura-app::update_begins_keep_one_session` |
| `ds_replace_target` | Begin a Free Transform on layer A, then begin one on layer B. | The session on A ends without adding history, exactly one session is live on B, and only B's pre-trim change is present. | `pictura-app::a_transform_on_another_target_replaces_the_session` |
| `ds_transform_mode_switch` | Begin Free Transform on a path, then begin Skew, Distort, or Perspective on the same path. | The first session ends, exactly one session is live in the new mode, and no history state is added. | `pictura-app::a_transform_mode_switch_replaces_the_session` |
| `ds_failed_transform_begin` | Force a transform begin to trim the target and then fail its preview or rect lookup. | The layer's pre-trim rect is restored, no session is live, and no history state is added. | `pictura-app::a_failed_transform_begin_leaves_the_layer_unchanged` |
| `ds_replace_cancels` | Start each session kind, put it in a dirty state, then Revert, New, and Open a document. | The installed document contains none of the outgoing session's pixels, no session is live, and no handler can commit into it; the C++ entry points reach the cancel path. | `pictura-app::replacing_a_document_cancels_every_session`, `tst_document_session::replaceEntryPointsCancelTheSession` |
| `ds_replace_clears` | Set a mask edit target, a saved active path, a ruler, pending previews, a canvas proxy, and PDF options, then Revert or New. | Every outgoing pointer, preview, and cache is cleared and `document_generation` changed. | `pictura-app::replacement_clears_outgoing_state` |
| `ds_pdf_password` | New or Duplicate after a protected PDF; open and Revert a protected PDF. | New and Duplicate clear the stored password; PDF open and Revert install the incoming password. | `pictura-app::pdf_password_follows_the_incoming_document` |
| `ds_reselect_after_replace` | Select all, deselect, replace with a same-size document, then query and apply Reselect. | The query reports no prior selection, applying it changes nothing, and the new document has no selection. | `pictura-app::reselect_is_unavailable_after_same_size_replacement` |
| `ds_replace_history` | Install a document through Open/Revert, New, and Duplicate in turn. | History contains exactly the incoming Open/Revert state, one New state, or one Duplicate state, and that single state is the initial state. | `pictura-app::replacement_installs_incoming_history` |
| `ds_stale_async` | Call the install guard with a generation/request id that no longer matches; optionally run the Qt open-delay path. | The late install is dropped; the installed document, history, and session state are unchanged. | `pictura-app::a_stale_async_install_is_discarded` |
| `ds_replace_signals` | Spy on `changed` and `region_blitted` while Open/Revert, New, and Duplicate install a document with no live session. | Each entry point keeps its current signal count, and replacement adds no second capture or notification. | `tst_document_session::replacementSignalsMatchTheEntryPoint` |
| `ds_undo_cancels` | For each session kind, start it, change pixels or selection, then call Undo; include a pending opacity/fill/mask-refine preview. | Session and pending previews are cleared; document and selection equal the undo target; history index is that target. | `pictura-app::undo_cancels_every_session` |
| `ds_redo_cancels` | Undo an edit, start a live session, then call Redo. | The session ends, the redo target is installed, and no session state remains. | `pictura-app::redo_cancels_every_session` |
| `ds_jump_cancels` | Open a filter preview, then jump to an earlier history state. | The preview and pending preview flags are discarded, the target state is installed, and the preview baseline is gone. | `pictura-app::jump_cancels_a_filter_preview` |
| `ds_snapshot_cancels` | Start a paint stroke or transform, then restore a named snapshot. | The session ends, the snapshot's document and selection are installed, and no session state remains. | `pictura-app::snapshot_restore_cancels_the_session` |
| `ds_inplace_handlers` | In a Qt Test, start a Pen anchor, Path Selection drag, content move, Move/Alt-clone, and Type edit in turn; Revert or Undo; then release the pointer. | The handler clears its press/gesture/polygon/move/clone/typing state and the release commits nothing into the restored document. | `tst_document_session::inPlaceRestoreResetsToolHandlers` |
| `ds_cancel_restores` | Cancel a paint stroke, mask stroke, selection move, lifted transform, shape-layer path gesture, Path Selection drag, filter preview, and mode preview. | The document and selection equal their pre-session values, no session is live, and history count/index are unchanged; the Path Selection document is restored. | `pictura-app::cancelling_every_session_restores_state`, `tst_document_session::pathSelectionCancelRestoresShapeLayer` |
| `ds_cancel_no_history` | Cancel after a stroke dab or an applied preview changed pixels or coverage. | The dirty flag is unchanged and no history label is added. | `pictura-app::cancelling_records_no_history` |
| `ds_cancel_noop` | Cancel with no live session. | The returned change is empty and the document, selection, history, dirty flag, and display are unchanged. | `pictura-app::cancelling_without_a_session_is_a_noop` |
| `ds_tool_switch_cancel` | In a Qt Test, start a healing, lasso, magnetic, transform, and selection-move gesture in turn and switch tools. | Each gesture is cancelled, the document is restored, and the new tool starts with no session. | `tst_document_session::switchingToolsCancelsCancellableGestures` |
| `ds_tool_switch_commit` | In a Qt Test, start a Brush, Pen, Path Selection, and Type gesture in turn and switch tools. | The outgoing handler commits exactly its documented state, the Rust slot is cleared, and the new tool starts with no session. | `tst_document_session::switchingToolsCommitsCommitOnDeactivate` |
| `ds_report_region` | Cancel a paint stroke and inspect the returned change; spy on `changed` and `region_blitted`. | The change is bounded regions with no notify flag; the region blit(s) are emitted and `changed` is not. | `pictura-app::a_region_change_does_not_notify`, `tst_document_session::regionBlitDoesNotEmitChanged` |
| `ds_report_region_notify` | Commit a healing, patch, red-eye, or layer-opacity/fill batch change and inspect the change and signals. | The change is bounded regions with the notify flag; the region blit(s) and exactly one `changed` are emitted. | `pictura-app::a_region_change_can_also_notify`, `tst_document_session::regionBlitCanAlsoEmitChanged` |
| `ds_report_notify` | Abort a Work or Saved path gesture and inspect the change and signals. | The change has no display region and a notify flag; `changed` is emitted without a region blit. | `pictura-app::a_notification_only_change_emits_no_blit`, `tst_document_session::notifyOnlyEmitsChanged` |
| `ds_report_shape_path` | Abort a path gesture that edited a shape layer. | The change requests a rebuild or a bounded region plus notification, not notification-only. | `pictura-app::a_shape_path_abort_requests_a_rebuild` |
| `ds_report_rebuild` | Cancel a mode preview and inspect the change and signals. | The change requests a rebuild with notify; the adapter rebuilds from the restored composite and emits `changed`. | `pictura-app::a_full_change_requests_a_rebuild`, `tst_document_session::rebuildEmitsChanged` |
| `ds_headless_session` | Construct a session, replace its document with a known history, and undo within that incoming history, all without a QObject. | Every step runs and the document, selection, and history match the expected values. | `pictura-app::a_session_runs_without_a_qobject` |
