# Test plan

| Scenario | Steps | Expected | Coverage |
|---|---|---|---|
| `cbt_cache_contents` | Save a successful master tree, then start a compatible PR run and inspect the restored paths. | Corrosion, generated headers, moc/autogen, FetchContent, Ninja state, app, and Qt Test executables are present. | manual: requires GitHub Actions cache and a full Qt build |
| `cbt_source_same_key` | Record the restore prefix, change one ordinary source file, and run CI again. | The prefix is unchanged and the matched key identifies the prior master entry. | manual: requires two CI runs and cache-key output |
| `cbt_pr_no_save` | Run `qt-headless` on a pull request and inspect cache actions. | Restore can occur, but no save action runs. | manual: requires a pull-request workflow run |
| `cbt_master_save` | Run all steps successfully on `master` and inspect the cache API and saved key. | One unique save is submitted under the stable prefix; quota acceptance or refusal is recorded without changing the build result. | manual: requires a default-branch workflow run |
| `cbt_single_writer` | Inspect the job graph and run log for configure, build, test, manifest, and save ordering. | One non-matrix job owns `build/`; no overlapping writer appears. | manual: requires workflow inspection and a CI run |
| Cache extra: missing Qt Test executable | Create a valid fake manifest, delete its registered test executable, and invoke restore. | Restore exits nonzero and names the missing executable. | `ci_build_cache::self_test_missing_qt_executable_rejected` |
| `cbt_stale_generated` | Create a valid fake manifest, delete a generated header, and invoke restore. | Restore exits nonzero, names the missing output, and CI's caller discards the tree. | `ci_build_cache::self_test_missing_generated_rejected` |
| `cbt_stale_digest` | Change a generated file without updating its manifest digest and invoke restore. | Restore exits nonzero and names the changed generated output. | `ci_build_cache::self_test_changed_generated_rejected` |
| `cbt_stale_identity` | Invoke restore with a different fingerprint. | Restore exits nonzero before source timestamps are changed. | `ci_build_cache::self_test_identity_mismatch_rejected` |
| `cbt_mtime_normalization` | Save a source manifest, change one tracked file, give all files fresh mtimes, then restore. | Unchanged files and directories become older than outputs; changed files stay newer. | `ci_build_cache::self_test_source_times_normalized` |
| `cbt_warm_no_work` | Restore a compatible tree with byte-identical sources and run the normal build. | Ninja records zero edges and no output is recompiled or relinked. | manual: requires a real restored CI build tree |
| `cbt_changed_target` | Run separate warm PRs with a Rust edit, shell-header edit, bridge-file edit, and Qt Test edit. | Each run records only its affected Ninja edges and keeps the same prefix. | manual: requires four real CI rebuild measurements |
| `cbt_forced_cold` | Dispatch the workflow on `master` with `force_cold` enabled. | Restore is bypassed, configure and every target build, and normal tests run. | manual: requires a manual GitHub Actions run |
| `cbt_key_invalidation` | Change a lockfile hash in the helper fixture, then change a lockfile, toolchain, Qt version, compiler, profile, configure flag, or build-graph input in controlled CI runs. | The fixture digest changes and each incompatible CI change produces a new restore prefix and a cold build. | `ci_build_cache::self_test_identity_changes_with_build_input`; manual: external toolchain changes require CI |
| `cbt_no_pch_gpu` | Toggle the fixture's PCH policy and invoke restore, then inspect the real configure command, cache, compile commands, and app manifest after cold and warm runs. | The fixture rejects PCH; real runs keep PCH off, inject no PCH include, and still enable `gpu`. | `ci_build_cache::self_test_configure_policy_rejected`; manual: built-tree and GPU inspection require CI |
| `cbt_qt_junit` | Run the reporter self-check and a complete CTest pass, then remove one expected report in a fixture. | The self-check detects the missing report; the real run emits one report per entry. | `report_tests::run_self_check`; manual: complete CTest registration requires CI |
| `cbt_measurements` | Parse a sample Ninja log with the helper, then inspect warm, forced-cold, and stale-rejection job summaries and JSON artifacts. | Edge count parses correctly and each run records its state, sizes, restore, validation and upload times, hit rate, and Build duration. | `ci_build_cache::self_test_build_summary`; manual: real cache timings require CI |
